# 判断方法：先定大势，再定题材，再辨认核心

## 1. 描述与预判分开

题材处于高潮是当前结构的描述；高潮后是否延续是另一个预测问题。每次保留 `state_now` 与 `expected_transition`；后者有明确条件和下次检查时间。

市场、题材、股票三个层级分别取证。市场允许参与、题材在启动、某股是核心不应互相替代。三层串联正确率要单独考核。

## 2. 情绪：三个面板

| 面板 | 数据和算法 | 解释与误读 |
|---|---|---|
| 指数/流动性 | 沪深300、上证、深成、创业板日线与分钟；沪深合格股票成交额合计/过去20日均值 | 不把重叠指数成交额相加；成交额增长不等于资金净流入 |
| 全市场赚钱效应 | 上涨家数占比、收益中位数、跌停/大跌家数、指数低点后修复 | 指数可能被少数权重抬高，广度同样重要 |
| 接力生态 | 非ST涨停数、炸板率、首板/2板/3板+梯队、最高连续板、昨日涨停组的中位超额收益、晋级率、高标亏损 | 3天2板不是3连板；最高板独舞可能掩盖后排衰竭 |

历史比较仅使用当时已结束的窗口。v1阈值是待验证的规则，不是普遍规律。后续开发可用滚动分位数表达高低，先冻结后检验。

- **不做/观察**：指数和广度同时恶化、跌停扩散、昨日涨停组亏损扩大；或市场不弱但题材零散、没有可解释梯队。缺数观察的理由是证据不足。
- **允许研究候选**：至少一个题材呈现可解释的集体强度，接力生态没有普遍恶化；这不是买入授权。
- **分歧期**：指数稳但高标/后排分化，或市场回落而少数核心维持。区分局部题材分歧与全市场退潮。
- **亢奋期**：广度、晋级、封板同时高，一字加速或补涨泛化。当前热度与次日溢价分开预测。

不能把情绪低必然推导为明日差：低位可能修复，高位可能转弱，状态与变化方向都要看。

## 3. 题材结构与主线候选

### 归因先于评分

KPL `lu_desc` 为每日主归因，`theme` 是多概念标签。概念成分接口 `name/ts_code` 是概念，`con_name/con_code` 才是股票。

建立宽行业→当期产业事件/子题材→公司受益路径三层归因。相同宽行业不等于同一波主线，不同名称也可能属于同一产业链。合并/拆分以当时新闻与成员重合为依据，记录 `theme_id`、`valid_from`、理由和证据，不事后并入赢家。

主归因不是已核实的公司受益事实。对高度候选核对KPL主归因、多标签、涨停表现中的原因以及当时公司新闻；发生冲突时保留原字段并降低代表性置信度。历史标签变更另列，不用次日标签重写前日判断。新闻检索补充事件主体和公司名称，避免只有行业词时漏掉招股书、订单方等催化；命中仍需语义阅读。

把市场注意力、经济受益路径和价格角色分别判断。主营、控股子公司、参股基金、共同控制方不可混同；澄清的主体与范围也不可扩大。经济敞口较小的股票仍可能是情绪高标，旧行业描述也可能漏掉已并表的新业务。具体核验与候选规范见[题材归因与核心角色](attribution-and-roles.md)。

v1只做芯片→半导体、机器人概念→机器人、智能电网→电网三个静态映射，尚未验证完整层级归因；其主线成绩是KPL主归因宽度预测。

### 结构指标

- 宽度：主归因涨停去重数；另列全体成员上涨比例。只有前者不能证明全体成员集体走强。
- 高度/梯队：最高连续板、首板/2板/3板+数量；10%与20%股票分别列示，两板涨幅不同。
- 新增/延续：新首板、旧成员晋级、过去5日出现次数、宽度变化、最近分歧及高点位置。
- 封板质量：涨停/(涨停+归因明确炸板)、首封分布、末封与首封间隔、开板次数、封单/自由流通市值、封单/成交额、收盘封单/最大封单。
- 归因缺口：炸板主归因缺失时，用当日概念匹配及过去主归因辅助；多主题与无法归因保留未知。

封单比率比绝对金额更可比较；最大封单是峰值，不等于可成交买盘。封单弱也可能是换手充分，应结合规模、价格路径和板上持续时间。

### 新闻逻辑评分卡

逐条保留来源、发布时间、原文或ID。以下是待验证的LLM语义层，v1关键词数未实现它。

| 维度 | 要回答的问题 | 反证 |
|---|---|---|
| 新颖性 | 相对市场已知信息增加了什么？ | 旧闻重发、预期已兑现 |
| 可信度 | 原始发布者、事实确认状态是什么？ | 匿名传闻、无法溯源 |
| 影响强度 | 是否改变收入、成本、供需或资本开支？ | 仅概念相关、经营敞口很小 |
| 持续性 | 数日内是否有可观察里程碑？ | 一次刺激，无后续增量 |
| 扩散性 | 同一因果链是否覆盖多家独立公司？ | 单家公司独立事件 |
| 价格验证 | 反应是否早于消息、是否已过度一致？ | 把上涨后的解释当成催化 |

每项给强/中/弱及依据，无证据则未知。若转数字，权重须在开发期冻结，检验加入新闻前后的增量贡献；主观90分不等于90%概率。

### 排序

比较结构、催化、持续性、拥挤、市场适配五列，列前3候选。差距小、归因重叠、新闻缺口时保留并列，明确没有唯一主线。top1、拒判、覆盖率仍按全样本报告。

新题材初始宽度可能不大。启动至少应有同一逻辑的多家独立公司响应，新信息足以持续；当日涨停最多仅是参照基线。

## 4. 生命周期状态机

| 状态 | 必看轨迹 | 确认与失败 |
|---|---|---|
| 萌芽 | 新催化、少数先行者，未形成梯队 | 增加独立公司才考虑启动；独舞继续观察 |
| 启动候选 | 宽度扩大、先手清晰、后排响应，价格匹配催化 | 次日集体强度及首板补充确认；仅高标兑现则失败 |
| 发酵/延续 | 梯队完整、晋级与新增并存，核心相对强 | 核心稳定可继续观察；核心/后排同时变差降级 |
| 分歧 | 炸板增加、宽度缩减、高低位分化，逻辑未失效 | 分别检查核心与原成员修复；同一时段共振才支持一致性增强 |
| 分歧转一致候选 | 昨日确有分歧，今日核心转强且集体同步 | 单股高开或尾盘脉冲不够；重复跌回原区间撤销 |
| 高潮候选 | 宽度/高度/一字加速在过去窗口高位，补涨泛化 | 看次日承接；识别高潮不是买入依据 |
| 退潮 | 核心破坏、后排亏损、晋级消失、修复失败 | 核心止跌只是观察条件，不自动是二波 |
| 二波候选 | 已有首波高点和回撤，有新催化/兑现，重新组织梯队 | 连续截面有集体确认；不能用后来新高给前日补名 |

状态可以不确定，也可启动后直接失败。状态机限制叙事，不强迫每个题材走完一生。状态与转移准确率分别考核，独立盲标缺失时不能宣称已验证。

宽度连续几天较低后突然增加，仅是检索启动案例的条件。确认生命周期时，还需回看此前20日的同事件轨迹；旧强势方向的修复、同一行业的新分支、全新催化分别记录。固定原成员池的反馈与新增成员扩散并列，避免用行业名字仍活跃掩盖原核心和原群体已走弱。

### 分歧与修复的分层观察

研究D分歧后的T日，冻结分歧前P日名单，保留D已经掉出涨停榜的股票；D实际下跌成员可以另作子群体。不要只用D仍涨停的幸存者检验修复。若名单仅含P已涨停股，注明未覆盖全产业成员。

分别输出：宽度是否回升；原成员相对当日参考前收是否反弹；逐股累计收益是否收复P基准；D下跌子群体恢复多少；核心身份及强弱；多数成员是否在同一时段同步。群体中位数恢复不等于每只股票恢复，也不等于当日多数上涨。累计收益先逐股复合再求中位数，不能复合每日群体中位数。

高度候选在10%/20%制度内分别找至少2连板的最高者并保留并列；全是首板时高度角色空缺，但仍可研究先手、容量等角色。逐个核心保留路径，多个核心的平均或中位数可能掩盖分化。

核心与群体可以先后转强，不强制核心先动，也不把不同时间的单项转强拼成共振。要求同一截面相互印证，记录持续与撤销；“连续3分钟”等具体长度只是待验证参数，跨午休、缺报价不能视作连续确认。结合全市场修复幅度及原成员超额表现，区分普涨、独立强势与分支更替。

## 5. 相互作用与轮动

市场成交额比、题材涨停份额HHI、同时形成梯队的题材数及核心分布共同解释环境。

- 放量共存：多个独立题材宽度和成员中位收益同时增强，市场成交额扩张；不能只是共享同一批股票。
- 缩量竞争：成交额收缩，一个题材份额增加而旧主线下降，旧核心溢价转负。份额变化仍不证明资金直接从A流向B。
- 进攻/防御：科技、金融、资源、消费、医药的角色随事件变化；不可固定说科技涨则医药必跌。先看去重成员收益与指数超额，再结合新闻解释。
- 回流：检查旧核心与原成员是否共同恢复；若是新核心或新分支，应单列，不能用旧主题总名掩盖领涨切换。价格先后本身不能证明带动。

过去20日去重成员收益相关性只能描述共振。分钟领先/跟随关系需要稳定的事前名单；相关不证明因果。

## 6. 龙头：角色、代表性与带动

最高板、后续收益最高、最有板块代表性的核心分别记录。比较：

1. 催化受益直接性、主营/订单证据、概念纯度，公告可见日期不得晚于判断。
2. 启动先后、连续高度、分歧抗跌与修复顺序、对后排的分钟领先关系。
3. 自由流通市值、换手结构、相对封单、开板回封、同题材公司比较。
4. 过去5/10/20日均线、量能、突破承接，按截至当日复权或收益链计算。
5. 是带动集体的核心，还是独立重组/股权转让事件。一字强不等于可成交，不自动是题材龙头。

启动龙、分歧修复龙、二波龙的候选来自当时成分、公司事实与动态行情，不可用未来涨停名单。v1仅测试D已涨停池中的延续强者。

收盘输出1个主候选、最多2个替代候选及角色；证据不足时可无主候选。盘中观察核心与成员转强顺序、同一时段的共同强度、价格保持程度、量能同步。小篮子两股大涨不足以改判全市场主线。

## 7. 事前预期与失效条件

例如：D时点A分歧、B启动候选。若T 09:45 A核心修复且固定篮子多数同步走强，继续观察A延续；若A核心走弱而B有独立成员持续跟随，提高B排序；两边均弱且市场广度恶化则观察。

先冻结这些条件，再看盘中。每次更新仅引用此前记录，事后保留原文、版本及出错原因，以区分事前理解与事后解释。

对新闻敏感的题材，在盘后初稿、次日06:00、开盘前分别更新催化与反证。后一时点的信息只能修改后一版判断；不可倒写前稿。一次09:45或10:30的确认允许被后续截面撤销，分别评价当前识别和对剩余区间的预测。
