# 五套理论统一分析方法

## 1. 共同事实层与多周期顺序

五套理论必须读取同一份、同一截止时点的数据。先形成不带理论标签的事实：

- **长期背景**：250、120、60日涨跌和最大回撤；价格相对MA60/120/250的位置及均线斜率。
- **结构**：60至120日主要区间、已经确认的摆动高低点、收盘是否突破或跌破。
- **近期行为**：最近20日突破、跳空、涨跌停候选、长实体与长影线。
- **量能**：实际成交量相对5/20/60日均量，放量后价格是否继续、停滞或反向。
- **位置**：收盘在当日振幅、20/60/120/250日区间中的位置。
- **时点约束**：摆动点只有在右侧确认K线已经出现时才可使用，不允许事后把尚未确认的高低点补回当日判断。

静态阅读固定使用“月线 → 周线 → 日线”的顺序：

- **月线**：判断主要趋势、3至5年历史高低点、长期平台、历史密集区与上方空间。月线未完成时，只使用 `as_of` 前已经发生的交易日，并标明“本月未完”。
- **周线**：判断中级趋势、主要波段、平台突破/跌破、套牢成交区以及日线结构在大级别中的位置。当前周未完成时同样标明。
- **日线**：判断短期节奏、事件K线、量价结果、均线抵扣和次日/未来5至20日触发条件。
- **周期关系**：分别写明同向共振、逆向反弹或大级别压力下的小级别突破。日线转强不自动改写周月下降结构。
- **级别化价位**：每个支撑、压力、目标和失效位必须标记来源周期。若多个周期价位接近，合并为价格带并提高结构权重；不要把日线和月线价位当成同等强度。

## 2. 威科夫：事件序列和努力结果

按“背景—事件—测试—结果”组织证据：

1. 判断此前处于上涨、下跌还是交易区间。
2. 在区间内寻找候选SC/AR/ST、Spring、SOS/LPS或UT/UTAD，但不因形态相似便定名。
3. 对每个候选事件检查：所处位置、价差、收盘位置、成交量、下一段价格结果。
4. 比较努力与结果：巨量却涨幅有限可能是供给；缩量回踩且不破关键位可能是供给收缩；同一现象需要结合区间位置判断。

候选判据：

- **SOS候选**：收盘有效离开区间上沿，实体和成交量显著扩张，随后未迅速跌回区间。
- **LPS候选**：SOS后回踩，成交量收缩、回撤受控，并守住突破区或更高低点。
- **Spring候选**：短暂跌破支撑后快速收回，之后出现向上结果；只有下破当天不能确认。
- **UT/失败突破候选**：上破压力但收盘弱、后续回到区间，且高位出现供给证据。

输出当前最可能阶段、支持证据、反证、确认条件和失效条件。阶段不清楚时写“交易区间内，阶段未定”。

## 3. 道氏理论：确认后的摆动结构

- 用确认后的摆动高点和低点定义高高点/高低点或低高点/低低点。
- 区分主要趋势、中级修正和短期波动，避免用五日反弹推翻半年下降趋势。
- 以收盘有效越过结构位，并有后续保持作为确认；长影线刺穿只算试探。
- 对A股连续涨跌停和跳空单独标注，因为价格发现可能不连续。
- 结构失效点优先使用最近一个同级别确认低点或高点，而不是任意百分比止损。

## 4. 均线系统：趋势状态和成本区

同时报告：

- 价格相对MA5/10/20/30/60/120/250的位置；
- 短中长期均线排列及每条均线的近期斜率；
- 均线密集、发散、扭转和价格乖离；
- 回踩均线时成交量和收盘结果。

均线是价格的平滑结果，天然滞后。多头排列不能单独证明后续上涨，金叉也不能替代对结构位、成交量和失败条件的检查。

## 5. 波浪理论：候选计数而非唯一叙事

- 从已确认的同级别枢轴开始计数，不从视觉上最顺眼的位置随意起算。
- 每次至少提供一个主计数和一个备选计数。
- 为每个计数写出失效价格；未失效只表示该计数仍可能成立。
- 涨跌停、跳空和极端波动会压缩内部子浪的可辨认度，应降低置信度。
- 如果无法可靠区分五浪推动和三段调整，使用“第1/2/3段”描述，不强行赋予浪级。

## 6. 缠论：先固定算法与级别

正式缠论结论依赖可重复的包含处理、分型、笔、线段、中枢和级别递归算法。分析必须声明：

- 基础周期；
- 包含关系处理规则；
- 分型、笔、线段和中枢的实现版本；
- 背驰使用的力度指标及比较区间。

仅有普通OHLCV和视觉图时：

- 重叠交易区写“类中枢”；
- 离开后回踩不进入重叠区写“候选三买结构”；
- 突破后重新进入重叠区写“离开失败”；
- 无严格递归和力度比较时不得命名正式背驰、一买、二买或三买。

## 7. 合并结论

把证据分成三类：

- **独立证据**：例如长期摆动结构改善和实际成交量供给收缩。
- **同源重复**：例如“站上MA20”“道氏短期突破”“波浪三浪启动”都来自同一根突破K线。
- **冲突证据**：例如短期均线多头，但长期仍处于下降结构；放量上破，但第二日跌回区间。

置信等级只用高/中/低，并说明理由。未经校准的模型输出不要伪装成精确概率。
