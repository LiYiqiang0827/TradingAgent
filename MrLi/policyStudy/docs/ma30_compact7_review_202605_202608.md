# MA30回调再启动：7%均线粘合条件与图册

本轮在已经冻结的2026年5–8月样本上增加用户提出的条件：
`100 × (max(MA5,MA10,MA20) / min(MA5,MA10,MA20) − 1) <= 7`。
分母用最小均线，因此三条均线的任一两条间距均不超过7%。

## 信号与完整分母

均线截至信号日收盘，模拟买入发生在下一交易日开盘，不使用买入日收盘的均线。
原来有107个MA30每日匹配日期，91个通过7%条件。先筛日期、再按同股同类型相隔
10市场交易日去重，得到81次候选。不能先拿旧90次首次候选再过滤，否则会漏掉
旧首次不符合、随后符合的日期。

旧90次中78次通过，重新去重多出3个后来符合的信号日。图册以旧90次与新81次的
并集93个案例展示，逐例标明间距及是否进入新候选。原始文件保留不变。

探索样本不构成独立验证，负收益尾部仍很大，不能据此认为已稳定盈利。

## 图册内容

每个案例三张独立图，共279张：

1. 截至筛选日的日线，含MA5/10/20/30/60/120、实际成交量、首波涨停与均量基准。
2. 日线买卖回放，向前1年、向后1个月，含MA5/10/20/30/60/120/250、成交量和模拟买卖标记。
3. 15分钟买卖回放，买入前1个自然月至卖出后7自然日，含15分钟MA与成交量、开盘价标记。

15分钟09:45首根K线的开盘价对应09:30，不能把该根完整收盘信息视为09:30已知。
复权因子参考日期截至展示终点。93个案例已展示的数据中每交易日均为16根K线，
分钟首根开盘价计算的区间涨跌幅与日线代理价一致，最大差仅为浮点精度误差。
这些核对不验证挂单成交或盘中止损。

PPT包含294页：5页口径和统计、10页完整交易总表、279页案例图。表格为可编辑
PowerPoint对象，附每例起始页码。筛选图页不展示未来卖出日期或收益，后续回放页
单独显示结果。原始图片保留完整分辨率，PPT内仅重编码JPEG压缩，未裁剪数据。
总表末列页码可点击跳到案例，每张案例页的“返回总表”跳回对应目录页。
筛选图的前峰日期兼容CSV整数，峰值标记取自图中前复权价格，避免因复权单位不同
漏标或标到错误价位。

## 文件与复现

本地输出根目录为 `outputs/rising_ma_reactivation/ma30_compact7_review/`：

- `review_episodes.csv`：93例并集。

- `MA粘合7以内_重新去重交易表.csv`：仅保留新81次候选。

- `charts/`、`charts/buy_sell_replay/`、`15min_replay/`：三类图片。
- `presentation/`：最终图册。构建和验证报告在隐藏的`.ppt_build*`目录。
