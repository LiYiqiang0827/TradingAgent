# 二进三题材龙头打板试验：2026 年 6—8 月

**结论：目前不能证明“强题材 + 同题材同步启动”会大幅提高二进三龙头的可实现平均收益。** 仅用二板日已知的题材强度筛选，6—7 月有小样本改善，8 月没有延续；二进三当天要求至少两只同题材股票同步触板后，样本进一步缩到个位数，8 月结果反而更差。涨停价买入没有封单队列数据，以下涨停价收益只是纸面参照。

![二进三题材龙头回测图](../../outputs/one_min_limit_up_pilot/two_to_three_leaders_202606_202608/two_to_three_leaders.jpg)

## 判断时点和样本

把二板日记为 D-1，尝试三板日记为 D0，计划卖出日为 D1。

1. 从 KPL 主归因涨停事件中取 D-1 **准确标记为“2连板”**的股票；`3天2板` 等非连续形态不算。剔除 ST 板块、ST 摘帽、次新股、北交所、名称含 ST/退、以及 D0 涨停价相对前收不超过 7.5% 的股票。D0 涨停价和前收都是开盘前可知的信息。
2. “龙头”只能机械地称为**二板日题材高度/先锋候选**：同题材没有更高板；若多个股票同为二板，按首次封板时间早、封单金额/自由流通规模大、代码稳定排序选一只。另用项目每日复盘已有的“近20日人气 + 封板时点 + 封单 + 成交额”龙头评分独立复核。两个定义有 35 个题材日的候选不一致/无法选出连续二板；不能把任一个称为事后确认的真正龙头，也不用 D0 的最终板位或收盘归因回选。
3. D-1 “强题材”：在至少 3 只涨停、热度分至少 50 的题材中，按 D-1 的热度排前 3。D0 盘中的同题材股票池只包含此前 20 个交易日已在 KPL 主归因涨停记录中出现的成员；**没有使用 D0 收盘才形成的题材归因**。龙头首次触及三板价的分钟结束时，若此前 30 分钟内至少另有两只这个已知题材的股票首次触板，记为“同步”。另行记录只看 D-1 活跃涨停成员的更窄版本。
4. D0 首触及同伴首触直接从当日 1 分钟 OHLC 与涨停价重算，不由 D1/D2 数据质量决定。第一次能按同步信号下单是龙头首触后的下一分钟。下一分钟高价再次到涨停且有成交，只说明**当时能递交涨停价委托**，不能说明排队成交。纸面收益按 D0 涨停价买、D1 09:32 卖，计入买卖各 0.10% 滑点、各 0.03% 佣金及卖出 0.05% 印花税。D1 09:32 跌停或零成交时不假定能卖出，并从已卖收益中分列排除。

D-1 合格二板共 520 个股票日，其中按上述定义的题材龙头候选 264 个；D0 分钟确实触到三板价 110 个，且 110 个均通过既有 D0/D1/D2 分钟质量检验。6—7 月为 44 个交易日，8 月为 21 个交易日。**8 月并非真正未见测试**：本窄口径是在看过较宽口径 8 月结果后提出，只能算时间顺序复核，不能用于优化后宣称样本外胜率。

## 二进三结果

以下平均收益和正收益比例均为 D0 买入、D1 09:32 卖出的模拟净收益；“n”是有计划卖价且计入统计的笔数。

| D-1/D0 条件 | 6—7 月 n / 净均值 / 正收益 | 8 月 n / 净均值 / 正收益 |
|---|---:|---:|
| 所有连续二板尝试三板 | 108 / -0.42% / 51.9% | 81 / +0.33% / 51.9% |
| 仅题材高度/先锋龙头候选 | 59 / -1.34% / 47.5% | 49 / +0.84% / 51.0% |
| 改用项目每日复盘的综合龙头评分选第一 | 55 / -1.19% / 47.3% | 43 / +0.25% / 53.5% |
| 上一日同时为强题材 | 14 / +0.42% / 64.3% | 5 / +0.40% / 40.0% |
| D0 另有至少两只近 20 日同题材股同步触板，且下一分钟仍可报涨停价 | 7 / -1.04% / 57.1% | 4 / -0.42% / 25.0% |
| 强题材且同步，下一分钟仍可报涨停价 | 6 / +0.74% / 66.7% | 2 / -4.87% / 0% |
| 首触后下一分钟在涨停价以下开盘的成交代理 | 25 / -1.24% / 40.0% | 7 / -0.91% / 42.9% |

表中前三行“首触涨停价买”是**更乐观的纸面基准**。同步条件直到首触分钟结束才可判断，因此后两行要求下一分钟仍观察到涨停价交易，但仍不知道限价单能否成交。最后一行相对容易按价买入，然而买到的是涨停打开/回落后的路径，不能被当成成功封板时的打板收益。

强题材在 6—7 月将龙头候选 D0 的触板率从非强题材的 45/151 提到 14/27，封住三板的候选占比从 28/151 提到 10/27；这更像是**延续概率筛选**，不是确认买入收益提高。按交易日整块重抽样，“强题材龙头减其他龙头”的纸面均值差在 6—7 月为 +2.30 个百分点，95% 区间 [-1.69，+6.19]；8 月为 -0.49，区间 [-6.47，+6.09]。两个区间都跨零。同步筛选相对其他龙头的均值差及区间分别为 -0.37 [-6.28，+5.15] 和 -2.06 [-7.84，+5.78] 个百分点。没有可重复的“显著增益”。

在最严的“强题材 + 同步”中，6—7 月仅 6 笔，8 月仅 2 笔。8 月的城地香江、红四方两笔分别约 -3.58%、-6.15%；另一个海鸥股份虽然首触纸面为正，但首触后下一分钟**没有再观察到涨停价**，不能把它算作在确认同步后仍可尝试涨停价买入的样本。这正说明时点约束会改变结论。

## 可执行性和解释边界

- 龙头候选 6—7 月 178 个，仅 59 个 D0 触板；8 月 86 个，仅 51 个触板。触板股下一分钟在涨停价以下开盘的机会仅 25 和 8 个，其中 8 月有一笔 D1 计划卖出受阻，因此最后一行只计 7 笔。不能用仅有收益的股票代替所有候选，也不能把涨停价纸面均值当作策略收益。
- D0 首触所在分钟可能先触板后回落，分钟 OHLC 没有逐笔顺序和封单队列。下一分钟“高价到涨停”也不能证明排队买到。二板 KPL 最终榜单缺首发发布时间存档；此试验假设 D-1 结果在 D0 入场前可见，尚未审计每一天的实际发布时刻。
- 6—7 月分钟数据主要是 `tdx_with_csv_fallback`，8 月是 TDX，月份与数据源变动同时出现；样本小、题材和日期集中，不能把两段差异完全解释为行情状态变化。卖出被跌停/零成交阻挡的样本未纳入已实现均值，纸面统计存在乐观偏差。
- A 股买入后不能在同日卖出，D0 买入才计划 D1 出场；参见[上交所 2026 年交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20260424_10816492.shtml)。

因此，这轮可以保留的判断是：**D-1 强题材可能提高二板候选冲三板的概率，值得作为观察过滤器；不能据此把“龙头二进三打板”升格成正期望交易规则。** 下一轮需冻结一个清晰的龙头标准与同步阈值，用统一来源的更长分钟样本和带时间戳的 KPL 首发版本复核；若要证明涨停价真实成交，还需逐笔/订单簿及排队位置。
