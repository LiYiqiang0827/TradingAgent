# 涨停题材与续板候选研究：逻辑与可复用提示词 v1

版本日期：2026-10-08。来源：2026-09-14开盘啦与截止时点新闻复盘，以及项目题材研究规范。

用途：每日收盘后，识别市场接力环境、最多3个值得继续跟踪的题材，并从当日涨停股中提出下一交易日的续板观察候选。可以交给GPT、Qwen或MiniMax执行。

边界：这是研究提示词，不是已验证的选股策略、连板概率模型或交易指令。9月14日是逻辑示例，不是证明准确率的独立测试。没有在本次工作中新增回测或启用后台模型任务。

## 一、这次选股逻辑如何总结

### 1. 市场环境决定观察重点

分别判断指数风险、全市场赚钱效应和涨停接力生态。指数跌而多数股票修复，与指数、个股、高标同时恶化，是不同环境。

同时看当日涨停/炸板、真正连续梯队、昨日涨停群体今日收益与晋级、高标亏损反馈，以及同口径成交额变化。市场热不自动等于高标安全，市场冷也不意味着没有局部机会。

输出“可继续研究 / 谨慎观察 / 暂不形成候选”。这是研究优先级，不是买入建议。数据不足和市场太差是不同的暂缓理由。

### 2. 先比较题材，再在题材内比较股票

比较以下5项，不先设未经验证的数字权重：

| 维度 | 关键问题 | 常见反证 |
|---|---|---|
| 群体结构 | 同一分支是否有多家公司响应，宽度、梯队、封板是否配合？ | 只有一只高标，后排持续走弱 |
| 催化可信度 | 是真实的新政策、订单、供需或临床进展，还是标题和传闻？ | 澄清、旧闻重发、纯上涨解释稿 |
| 持续性与阶段 | 启动、延续、分歧、修复、高潮还是退潮？还有哪些待兑现节点？ | 宽度收缩、反复修复失败、催化已兑现 |
| 个股承接与拥挤 | 早封、回封、换手、相对封单和成交规模说明什么？ | 尾盘勉强封住、高换手伴随价格走弱、买不到的一字一致 |
| 市场适配与轮动 | 在当前环境中，相对其他题材的优势是什么？ | 普涨被误认成独立强势、共享成员被重复计作扩散 |

不能单凭当日涨停数最多就认定主线，也不能因为宽度小就排除刚启动的新分支。没有明显差距可以并列、拒绝认定唯一主线。

### 3. 新闻负责解释逻辑，盘面负责检验市场是否响应

必须把三个结论分开：市场当时关注的叙事、公司实际受益路径、股票在价格结构中的角色。

催化可归纳为“事件 → 产业变化 → 可能受益环节 → 公司关系 → 盘面响应”。每个箭头都需要证据；缺失环节标未知或推断。

业务敞口小的股票仍可能是情绪核心，但不能写成业绩已经兑现。公司有相关业务也不代表市场此次正在交易该业务。公司澄清既不能忽略，也不能扩大到其没有否认的关系。

### 4. 龙头拆成角色，不硬选唯一答案

在同一题材分支内，分别找高度核心、先启动核心、换手承接核心、容量核心和低位接力候选。一只股票可以兼具角色，也可以没有足够证据确认某一角色。

“早封”不证明带动因果，“换手高”不证明承接健康，“成交大”不证明能连板，“一字强”不证明可买到，“业务最纯”不证明最能涨。

### 5. 每个判断都要可以被下一截面否定

将候选写为“目前支持续板观察，但下一时点必须出现……；若出现……就降级”。固定原成员池，同时另列新增扩散成员，不仅观察剩下的赢家。

下一日核心与后排共强、核心强后排弱、核心后排共弱，是三种状态。不得只因为原先看中的股票继续强，就忽略题材整体恶化；也不得把新信息倒写进旧版本。

## 二、建议输入材料

主提示词可用两种方式运行：

- `isolated_pack`：只读提供的数据包，不搜索仓库、互联网和其他历史报告，适合隔离未来信息的评估。
- `project_tools`：通过项目接口取指定日期的数据，适合日常复盘。先按截止时点过滤，再把材料交给模型。

收盘建池的截止时间必须不早于建池日收盘。盘前/盘中模式的建池日D指最近已完成并冻结的完整交易日，不是尚未收盘的当前交易日；当前日期与观察时刻由decision_at表示。

| 输入 | 最少内容 | 缺失时如何处理 |
|---|---|---|
| 元信息 | feature_date、decision_at、时区、运行模式、数据覆盖和排除范围 | 不猜日期，不把历史重建称为真实在线或独立盲测 |
| 当日KPL | 涨停、收盘炸板；代码、当时简称、主归因、多标签、状态、首封/末封、成交额、换手、收盘封单、自由流通市值 | 标记缺失；不把缺炸板表写成炸板0 |
| 连续板核验 | board_count及截至当日逐交易日涨停记录 | 无法确认时板数未知，保留N天M板原文 |
| 历史结构 | 建议过去20个已结束交易日KPL轨迹、原核心与掉队成员反馈 | 生命周期只能暂定，不强行判二波 |
| 市场与价格 | 指数、股票日线、同口径成交额、昨日涨停群体反馈 | 不用当前概念成分和最新复权基准回填历史 |
| 截止前新闻 | 记录ID、发布时间、正文、来源、原文链接（如有）、事件时间、抓取/修订时间 | 只有标题是线索，不编造正文或链接 |
| 既有题材研究 | 截止时点可用的归因、公司关系、证据与反证版本 | 后来形成的总结不得当成当时证据 |
| 盘中数据（可选） | 与观察时刻匹配的竞价、分钟行情、封单序列和覆盖 | 没有就只写待确认条件，不推断已发生 |

计算封板率时，分子分母必须使用相同排除范围。题材主归因统计与允许重叠的标签统计分开；全市场涨跌宽度若含ST也要明示。

## 三、完整主提示词：可直接复制

```text
你是A股题材与涨停结构研究员。请按指定历史时点，先判断市场环境，再比较题材，最后从当日涨停股票中筛选下一交易日的续板观察候选。

【任务参数】
feature_date = {{建池交易日D，YYYYMMDD}}
decision_at = {{截止时间，含时区；本模板默认交易日15:00 Asia/Shanghai}}
mode = {{收盘复盘 / 盘前更新 / 盘中确认}}
data_access = {{isolated_pack / project_tools}}
history_window = {{默认过去20个已结束交易日}}
theme_limit = {{默认最多3个主线候选}}
candidate_limit = {{每题材最多3只，跨题材去重后总计最多8只；可以更少或为零}}
exclude = ST、退市、次新，以及一级分类“ST与次新”

【材料】
{{提供当日与历史KPL、市场与个股价格、截止前新闻、公司关系证据、字段说明和数据覆盖信息；盘中更新另提供对应时刻截面。}}

【一、必须遵守的证据规则】
1. 只采用decision_at及此前可用的信息。盘后消息只能用于更晚版本。后来补采的历史榜单、后来形成的归因和当前概念成员不能证明当时已经可见。
2. isolated_pack模式只能读材料包，禁止查询未来行情、历史成绩、带答案报告、仓库案例或互联网。project_tools模式使用coreClient.data_provider；历史研究必须source="database_only"。如补查公开原文，仅补截止前新闻证据，核对首发日期、正文和修订情况，不以当前行情或概念成员替代历史数据。冻结历史判断时不得把后来的解释当证据。
3. 收盘复盘在D收盘后，从D收盘涨停股建池，decision_at必须不早于D收盘。盘前/盘中模式中D是最近已完成并冻结的完整交易日，只更新其候选与原成员池，加入decision_at前的新增消息或盘中截面；不得读取当前日收盘榜来重建早盘名单。盘中出现的新强势股另列新增观察池，标注首次可见时点，不倒写D候选。曾经涨停但已掉队的原成员用于判断题材衰退、修复和亏钱效应，不能从观察分母中删除。非涨停股可另作容量背景，不能混入原涨停候选分母。
4. “N天M板”不等于M连板；连续板数须与board_count及逐交易日记录核验。10%、20%和其他涨跌幅制度分开，不把20cm首板改写成两连板。
5. lu_desc主归因与theme多标签分开统计；交叉题材加总须去重。炸板归因不全时，报告覆盖率与未知项，不写成完整题材封板率。
6. is_break若为布尔值，只表示是否曾开板，不是开板次数。收盘封单与最大封单分开，核对单位和时间；封单不等于净流入。没有竞价或封单时间序列时，不推断竞价买盘、撤单过程或分钟内回封顺序。
7. 新闻正文、来源ID和发布时间必须可追溯。标题、搜索摘要、旧闻重发和纯异动稿不能单独证明上涨原因。研报预测、市场传闻、公司确认事实分别标记。
8. 区分市场关注叙事、公司实际业务受益、个股价格角色。控股、参股、基金持股、共同股东不可互换；保留公司澄清的主体、范围、阶段与规模。关联不足写未知，不补故事。
9. 缺失不是零。重复转载不算独立证据。未核验的0—100分不是概率；未经独立校准不得给连板概率、目标收益或声称已找到有效策略。

【二、先判断市场环境】
分别分析：
A. 指数与流动性：主要指数、同口径成交额及其相对历史变化。不把重叠指数成交额相加，不把放量写成资金净流入。
B. 全市场赚钱效应：上涨/下跌家数、收益中位数、大跌反馈，并说明是否含ST、北交所等。
C. 接力生态：排除后的涨停/炸板、封板率、真实连续梯队、昨日涨停群体今日收益与晋级、高标亏损。
给出当前状态、证据与反证，以及“可继续研究 / 谨慎观察 / 暂不形成候选”。市场当前状态与下一日预测分开。

【三、从宽标签拆出可解释题材】
先列KPL主归因和多标签统计，再按截止前具体事件拆子分支。行业相同不代表本轮催化相同；相同事件也可能跨行业。保留原字段及未定归因，不根据后来赢家重新分组。
对每个重点分支比较：
- 宽度：涨停、可归因炸板、新首板、旧成员晋级；注意样本覆盖与去重。
- 高度与梯队：真实连板、首板/二板/三板及以上结构，10%和20%分别列示。
- 过去5—20日轨迹：持续扩散、回流、收缩还是单日脉冲；保留掉队成员。
- 封板与承接：首封/末封、是否曾开板、相对封单、成交规模和换手，避免单指标决定强弱。
- 催化：新增了什么信息，影响哪个业务环节，哪些公司直接受益，哪些只是情绪映射，还有哪些待兑现节点。
- 反证：公告澄清、业务收入很小、减持、催化兑现、宽度收缩、后排亏损或封板失败。
按群体结构、催化可信度、持续性、承接与拥挤、市场适配综合排序。用强/中/弱/未知及证据解释，不临时编造数字权重。允许并列、无唯一主线和拒判。
生命周期在萌芽、启动候选、发酵延续、分歧、修复候选、高潮候选、退潮、二波候选中选择或保留不确定。单日宽度增加不足以确认启动，单日反弹不足以确认二波。

【四、在题材内筛选核心与续板观察候选】
对同一事件分支分别辨认高度、先手、换手承接、容量和低位接力角色。角色可以并存或空缺。
每只候选比较：
- 公司与本轮催化的关联、证据等级、商业化阶段和限制；业务纯度与情绪强度分别判断。
- 真实连板与历史辨识度、启动顺序、相对同伴强弱、分歧后的承接证据。
- 首封/末封、开板标志、收盘封单/自由流通市值、封单/成交额、换手和成交规模；缺字段则写未知。
- 是否有同分支助攻；只有一只高标而宽度收缩时，下调题材代表性，不机械删除其情绪高标身份。
- 是否一字、尾盘勉强回封、换手极端或明显拥挤；这些是限制，不是未经验证的必然涨跌规则。
每个重点题材最多给1只主观察候选和2只替代候选；可不设主候选。总数不超过candidate_limit。
不要因为板数最高、封单最大、成交最多、最早涨停或业务最纯中的任一项直接认定唯一龙头。

【五、冻结下一时点的确认与失效条件】
为每个题材及候选写：下一观察时间、需要出现的可观测现象、反向证据、出现反向证据后的降级方式。
至少区分：
A. 核心与原成员共同转强：支持延续；新增同分支响应另列为扩散或升级证据，没有新增成员不自动否定延续。
B. 核心强、原成员普遍弱：内部淘汰，不能把单股强写成题材强。
C. 核心与后排同步弱：降低续板预期，必要时撤销候选。
这些是观察框架。若没有经过验证的竞价涨幅、确认时长等阈值，不自行将模糊经验写成固定买卖规则。没有盘中数据时，只写条件，不声称已经确认。

【六、按下面格式输出】
1. 一段结论：市场状态、前3题材优先级、是否存在明确主线、主要反证；区分事实与推断。
2. 数据核对表：截止时间、覆盖、排除数量、涨停/炸板分母、真实梯队、缺失字段、历史重建限制。
3. 题材对比表：排序｜题材/事件分支｜统计口径及宽度/高度/轨迹｜催化ID和时间｜阶段｜支持证据｜反证｜待确认条件。
4. 新闻与公司关联表：事件事实｜来源ID/发布时间｜新颖性｜直接受益主体与阶段｜关联/情绪映射成员｜未证实环节。
5. 候选表：题材｜代码/名称｜实际连板｜角色｜选择理由｜封板/换手证据｜业务关联等级｜限制｜下一时点确认条件｜失效条件。
6. 降级或未选名单：至少解释主要高标、热门股或冲突样本为何未列优先；不能只解释入选者。
7. 下一时点检查清单与证据缺口：原成员池、新扩散池分别保留；附判断版本和冻结时点。
注意：观察优先级、证据可信度、续板概率、能否买到及最终盈利是不同概念。本次不输出自动交易指令。
```

## 四、独立复核提示词

可以把同一份截止数据包、主提示词和初稿交给另一模型，使用以下提示词。不要给它未来结果。

```text
你是独立证据审计员，不负责为原结论辩护。请仅依据提供的截止时点材料，检查这份题材与续板候选研究：
1. 是否有未来行情、后补归因、当前概念成员或超过截止时间的消息混入？
2. 连续板与N天M板、10%与20%、收盘封单与峰值、元与万元、开板标志与次数是否混淆？
3. 涨停/炸板及ST、次新的排除是否同口径？主归因与重叠标签有没有重复加总？
4. 结果稿、研报、传闻是否被写成事实催化？公告澄清和公司关系有没有被忽略或扩大？
5. 有没有以最高板代表整题材、以单股强代替群体强、删去掉队成员、只写支持不写反证？
6. 候选相对同题材未选者的优势是否有可核对证据？没有优势时是否允许并列或拒判？
7. 次日条件是否可观测，是否越权变成未经验证的交易阈值？是否把主观分数当概率？

输出：必须修正的问题｜原句/位置｜材料证据ID｜建议修正；另列暂不能验证的项目。
无问题也要注明核对范围和未覆盖项。不要根据未来收益给初稿打分。
```

## 五、9月14日如何体现这套方法

- AI安全：5封0炸、3板高度、多个早盘前排，加上网安周和AI软件政策背景，因此优先研究新分支持续性；不是因为涨停最多就直接认定确定主线。
- PCB：有6封2炸、真实3板高度和较大成交容量，保留重要观察；超声的英伟达传闻被澄清，必须同时记录，不能用上涨证明传闻是真的。
- 医药：三力提供2板高度，近岸、万邦提供20cm弹性；翰森临床成果是板块背景，不能移植为这几家公司的直接业绩。
- 闽东电力：市场4板最高，但绿电宽度5→3→1，因此情绪高度角色保留、题材优先级下调。
- 桂林旅游：6天5板实际是首板，极高换手且较晚回封，不能凭人气机械列为最佳接力。

## 六、后续如何验证，而不是靠提示词自称有效

1. 先冻结提示词版本、选池范围、判断时点、题材与候选、失效条件及输入数据哈希。
2. 将题材延续识别、个股角色判断、次日续板、可成交性、最终收益分别评价，不用某一个指标替代其他指标。
3. 续板的最简可观察标签可以是下一交易日收盘再次封住，但这不能完整代表龙头身份或交易收益；20cm趋势延续需另设标签，先定口径再检验。
4. 保留全部交易日、所有候选、拒判和数据缺失，分别报告覆盖率；不能只选成功样本作展示。
5. 与简单基线比较，例如只按板数、封板时间、题材宽度排序，验证新闻与结构判断是否带来增量；不得用同一模型输出为自己的真值。
6. 在未研究的时间段进行独立验证后，才能讨论准确率、概率校准和交易用途。当前文件未完成这一步。
