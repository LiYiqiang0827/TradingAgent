# 日线和15分钟均线回调策略草案

日期：2026年10月5日。本文将用户本轮策略写成按时间推进的规则，供样本形态核对、参数开发和后续成交回放使用。核心假设是：热门题材中的核心股已经形成日线趋势，15分钟充分回调后重新转强，日线支撑与同题材反馈共同确认，再用16根K线检验上涨预期，分批卖出和恢复仓位。

当前完成的是规则草案、因果信号诊断和目标仓位状态程序。参数尚未按收益优化；题材核心身份和盘中共振尚未完成逐例核验；程序没有成交账本或收益结果。样本是否符合某项均线条件，可以直接核对；这些条件是否能盈利，需要另行评价。

## 研究样本和日期

用户确认样本属于2026年：近岸蛋白9月，精智达4月与6月，京东方A6月，山东赫达8月，万向德农8月，康龙化成8月，共7个股票月份。证券代码分别为688137.SH、688627.SH、000725.SZ、002810.SZ、600371.SH、300759.SZ。

雷科防务12月的年份另待确认。当前日期尚未到2026年12月，不读取未来月份，也不自动改成旧研究中的2025年12月。样本都是用户已经选出的参考案例，属于开发材料。

## 时点和数据

日线观察池只使用前一完整交易日的信息。15分钟信号使用已经完成的K线。今天的日线形态可以用截至当前15分钟的开、高、低、收聚合，但必须标为未完成日K；没有后半天的数据，也不能写成已经确认的收盘形态。

行情由coreClient.data_provider读取。日线、复权因子和交易日历使用database_only，15分钟接口本身只读本地。指标价格为原始价格乘当日因子，日线和分钟使用相同尺度，实际成交量不复权。缺K线保留其物理时槽并打断指标、金叉链和连续确认，不能删除缺口后把两段行情接起来。

每个样本保存原始输入、规则、代码和输入哈希、日线入选记录、逐根条件判定、候选证据以及配对图。图中复核时刻由条件覆盖程度选择，只用于阅读；选图时刻不进入信号计算，右侧行情不进入该时刻的条件。

## 阶段顺序

1. 题材此前集体活跃，个股具备当时可识别的核心身份。
2. 日线趋势达标，记录入选时间和MA30上升段。
3. 15分钟进入MA10至MA120空头排列的回调。
4. 密集金叉、站上MA120和抵扣推演同时满足，记录启动观察时刻。
5. 此后再次回踩MA30，核对截至此刻的日线支撑、反转形态与题材共振，形成正式买入许可。
6. 成交后16根内验证预期；通过后进入分批管理，否则发出退出。
7. 分批卖出后依据恢复条件买回；彻底退出后必须等待新的完整入场序列。

阶段4的“启动观察”与阶段5的“正式买入许可”分开保存。已出现的启动观察不能因为后来上涨就提前补成买点。

## 日线趋势入选

用户明确要求MA30连续上升para_ma30up_period日。MA5、MA10、MA20、MA30应在MA30上升且价格连续上升的阶段保持多头；MA60、MA120可在这个上升段中完成金叉。

草案将相邻关系定义为MA5大于MA10、大于MA20、大于MA30、大于MA60、大于MA120。MA30与MA60、MA60与MA120在上升段起点已经多头，或在该段内完成金叉且入选时保持多头，均可达标。这里对“60和120完成金叉”的解释有待用户核对。

“连续上升段必须多头”保存三种解释，不以收益挑选解释：

| 解释 | 短均线要求 | 用途 |
| --- | --- | --- |
| 上涨日子段 | MA30上升段内，所有收盘高于前收的日子均满足短四线多头 | 当前草案主解释 |
| 整个MA30上升段 | 该段每一天都满足短四线多头 | 更严格的字面解释 |
| 当前入选日 | 入选当日满足短四线多头 | 较宽解释，仅作覆盖对照 |

主解释在入选日要求收盘高于前收，没有擅自增加“收盘必须连涨若干天”的参数。若用户要求一个明确的收盘连涨长度，应另行增加。

日线首次或再次达标时记录selected_at。进入回调后，MA30仍上升且数据完整即可保留观察资格，短均线失序不会立即删除它。MA30不再严格上升或日线缺失时取消新开仓观察资格；这个取消条件是草案的操作选择。已经持有的仓位继续按退出规则管理。

15分钟回调开始时必须已经入选。后来日线达标不能倒写为回调前已入选。数据预热必须覆盖整个被判定的MA30上升段；若金叉前均线尚无有效值，就保留证据不足，不声称已观察到金叉。

## 15分钟回调与启动观察

回调要求MA10小于MA20、小于MA30、小于MA60、小于MA120。MA5不放进回调排列，允许最短均线提前反应。持续根数是参数，草案起点为1根；每次新的空头排列段重建金叉链，缺失K线取消旧链。

启动观察要求下列三项在同一完成K线同时成立：

1. MA5分别上穿MA10、MA20、MA30，三次金叉均属于本次回调之后的序列，并落在同一个短窗口内，当前MA5仍高于三者。草案允许交叉先后次序不同。
2. 当前收盘价高于MA120。
3. 恒价推演支持MA10、MA20、MA30在短期内逐根上升，并在该窗口中出现MA10大于MA20大于MA30。

抵扣推演对N周期简单均线采用：

    MA_N(t+1) = MA_N(t) + [C(t+1) - C(t-N+1)] / N

若未来h根均收在当前价C_t，则在h不超过N时：

    MA_N(t+h) = MA_N(t) + [h*C_t - sum(C(t-N+1), ..., C(t-N+h))] / N

下一根MA10、MA20、MA30的抵扣价分别是序列中的C(t-9)、C(t-19)、C(t-29)。程序保存每一步实际将移出的历史收盘，不用一条抵扣价趋势线代替重算。

抵扣价下降不足以保证均线上升：若当前价仍低于将移出的价格，均线仍会下降。三条均线都上升也不足以保证短期交叉，因此必须同时重算排列。恒价是假设，不是未来价格预测。

草案对“抵扣价下降”采用每条将移出序列非递增且至少一步下降；较宽解释为序列末值低于首值。两个解释分开保存。MA10在恒价追加10根后已经全部由相同价格构成，因此严格连续上升的推演窗口不能超过10根。

启动观察后，等待后续K线回踩MA30。草案要求最低价在MA30上下容差内，收盘回到MA30之上；启动观察那一根自身的触线不能算“再次回踩”。超过等待期限或重新收盘失守MA120，取消这次启动观察。

## 日线支撑与反转确认

在MA30再回踩时，回看本次15分钟回调开始以来的已完成日K及今天的已观察部分，找到截至当前的最低点。逐项保存最低点与当时日线MA5、MA10、MA20、MA30、MA60、MA120的距离。

附近存在多条均线时保留全部命中均线，最近的一条只作距离标签，不能强行把它写成唯一的回调级别。若距离超过容差，则本次没有清晰的日线均线支撑。

草案允许两类反转证据：触及日线均线附近的长下影线；前一根阴线在均线附近得到支撑，下一交易日阳线且收盘高于前日收盘。长下影暂定义为下影不小于实体两倍，收盘位于全幅上部35%；极小实体使用振幅5%作为比较下限，避免零实体自动通过。以上数字是候选定义，不是用户已指定或已校准的阈值。

当前日K的部分形态可以成为盘中观察证据，但仍可能在下午变化。若要求正式的日线收盘确认，则只能在收盘后产生许可，并等待下一交易时点成交；不能既要求当天完整阳线，又按早盘价格买入。

草案暂要求“日线支撑附近且已有反转证据”。另可比较反转证据仅用于分层、无需作为硬门槛的版本，但须记录差异。

## 16根预期确认

用户指定成交后16根15分钟K线内出现“均线连续上升且多头排列”。草案将实际成交所在15分钟K线作为第1根，完成第16根时先判断是否已经达标，再判断是否超时。以实体时槽计数，跨午休和隔夜只增加新的交易K线。

暂用MA5、MA10、MA20、MA30作为期望组，并要求各自严格连续上升3根、同时多头排列。慢组MA60、MA120另作观察列。把六条均线全放进16根硬确认会明显改变策略，应作为另一个明确版本，而非悄悄增加条件。

一旦在16根内达标，进入持仓管理。16根从未达标则发出退出，不附加“还必须跌破MA20”等旧规则。若窗口内缺K线，记录确认未知，不能把缺数写成已经观察到失败；执行层需要另设数据故障处理。

MA120彻底退出信号从买入后始终有效，包括16根确认期间。用户未提供独立的初始结构止损，这一缺项保留为待研究问题，不把旧策略的固定3%止损混入本版。

## 分批卖出和买回

暂以本轮原始目标仓位为100%，分为A份额25%、B份额50%、保留份额25%。卖出或恢复只作用于对应份额；成交未完成时以真实股数为准，不能按信号当作已经卖出。

| 条件 | 目标动作 | 恢复条件 |
| --- | --- | --- |
| MA5、MA10、MA20粘合且收盘低于MA20 | A份额减去原目标的25% | MA30仍上升，近期回踩MA30，快速回到MA30及下一步MA10、MA20抵扣价上方，恢复A份额 |
| MA5、MA10都低于MA30并连续3根未收回 | B份额减去原目标的50% | MA5、MA10重新同时高于MA30，恢复B份额 |
| 收盘价低于MA120 | 剩余仓位全部退出 | 本轮不再恢复，等待新一轮完整入场许可 |

粘合暂用三条均线最大值除最小值减1，百分比不超过1%。A份额的快速恢复暂定4根内。B条件暂以两条均线均在MA30下方的持续状态表示“死叉且三根不收回”，不要求同一根同时死叉；恢复也允许两条金叉先后完成。

每份额每次减少后只允许一次对应恢复，恢复之后可以再次出现新的卖出事件；不能每根K线都乘剩余仓位的四分之一或一半。同一根可以满足A与B两个减少条件，这时减少原目标的75%。MA120退出优先于所有买回；同一根减去的份额不能同一根恢复。若用户的“减仓1/2”是剩余仓位的一半，应修改份额合同并另作对照。

题材退潮时先冻结买回。退潮是否直接清仓、减多少和等待几根尚无用户明确数字，当前程序只记录退潮证据和冻结恢复，不擅自添加固定减仓动作。恢复后再次走弱的实际收益、错误买回次数和费用必须单独统计。

## 题材证据合同

题材应贯穿选股、进入和退出三个时点。只拿股票当前概念标签或后来涨停复盘归因，不能证明当时已经满足用户的题材条件。

| 时点 | 需要冻结的证据 | 当前诊断状态 |
| --- | --- | --- |
| 首波及日线入选前 | 历史热点窗口，多股涨停的广度与梯队，事件分支和来源，个股高度或先手或容量或换手核心角色 | 待逐例核对，不能从本月赢家反推核心 |
| 回调中 | 固定首波成员池的共同回撤，核心与群体结构仍可修复，新闻逻辑未观察到失效 | 待逐例核对 |
| 买点时 | 截至当前的同题材成员陆续转强、广度和相对表现恢复，个股与群体在同一截面互相印证 | 待分钟时点核对；不能使用当天最终涨停榜 |
| 持有和卖出 | 固定成员及核心衰弱、修复失败、新闻反证等退潮证据 | 待定义行动幅度并核对 |

成员覆盖缺失标未知。股价上涨的群体分母应保留首波后已经走弱的成员，不能只统计今天又涨停的幸存者。来源发布时间、首次可见性、后来抓取时间分开；历史KPL回填无首发存档时披露局限。

当前程序输出的是技术候选，formal_entry保持unknown_theme_evidence。题材核对未完成时不报告正式交易次数、胜率或策略净收益。

## 暂定参数和开发顺序

用户已经明确的16根预期窗口、3根未收回、A与B分批比例优先固定。其他参数先用少量邻近值核对形态覆盖，再考虑交易收益。

| 参数 | 草案起点 | 可考察的邻近值 |
| --- | --- | --- |
| MA30连续上升日数 | 10日 | 5、10、20日 |
| 空头排列持续 | 1根 | 1、2、4根 |
| 三次金叉窗口 | 4根 | 4、8根 |
| 恒价抵扣推演窗口 | 4根 | 4、8根 |
| 再回踩最大等待 | 8根 | 4、8、16根 |
| 15分钟MA30触线容差 | 1% | 0.5%、1% |
| 日线均线距离容差 | 3% | 1%、2%、3% |
| 期望组连续上升 | 3根 | 2、3、4根 |
| 短三线粘合 | 1% | 0.5%、1% |
| A份额快速恢复窗口 | 4根 | 4、8根 |

这些起点是为了把自然语言变为可检查的程序，没有数据支持其最优性。当前没有执行这个表的笛卡尔积搜索。

先用用户样本核对每一步是否读懂：日线入选日期、回调开始、金叉时刻、抵扣路径、启动观察、再次触线、日线证据、题材反馈。记录所有排除原因；需要调整时按结构解释升级版本，保留旧判定。

随后为这些股票每个同时点抽取同题材、相近日线趋势和回调深度的普通或失败样本；完成该候选窗口的全部信号扫描，包含无信号与未成交。以这些资料开发参数，而不是只让几只赢家都被抓住。

收益优化必须保留未参与调参的日期或题材周期。2026年多个区间在此前研究中已被看过，新规则即便逐根因果，也不能称为完全未见盲测。可用按时间和题材周期分组的交叉验证诊断稳定性，最终仍需要新增时段或前瞻记录。

对照至少包含相同入场的整仓MA120退出、分批但不买回、分批加买回，以及技术候选与题材核对通过候选。分开报告净期望、亏损尾部、上涨段保留程度、买回的增量和成本、最优案例贡献及各保护规则实际触发覆盖。

## 成交回放的后续要求

完成K线才可判定，信号后下一可交易时点才尝试成交；不能按刚刚触及的MA30反填价格。正式回放须使用原始成交价格、各批实际股数、可卖日期、费用、现金、跳空、涨跌停和未成交记录。

卖出意图与实际卖出是两种状态。当日新买或买回的股票不能假设当天再次卖出；旧仓可卖数量与新仓分开。交易规则规定买入证券在交收前不得卖出，实行回转交易的品种除外。[深交所交易规则2026年修订第3.1.4条](https://docs.static.szse.cn/www/lawrules/rule/trade/W020260424690713155663.pdf)

如果MA120退出发出时仍有不可卖新仓，该轮的退出意图持续保留并等待执行，不因为后来金叉就取消。本轮彻底退出后不能用旧卖点立即买回。信号状态程序中的target是目标比例，不是实际持仓、账面收益或T+1执行证明。

空头数量只统计所指月份；回调也可能始于前两个月的预热区间，扫描保留这种阶段顺序。日线达标天数不是交易数，精智达6月严格版虽然本月没有新达标日，仍保留了此前入选的观察资格。

严格的上涨日子段多头解释在7个所指月份均无新日线入选，严格的未来抵扣序列逐根下降解释在这2352根K线均无完整抵扣许可。这里的严格解释是程序草案，不是用户已经确认的唯一含义。

对照五种组合：原严格版；仅将日线改为入选当日多头；仅将抵扣改为序列总体下降；同时改这两项并用4根金叉与推演窗口；同时改这两项并用8根金叉与推演窗口。其余等待8根、触线1%等暂定值不变。五种组合在7个样本月份均无完整技术候选。

较宽解释并非没有启动观察。近岸蛋白在8根版本的9月21日09:45通过三项15分钟证据，随后8根最低价相对MA30的最小距离仍约5.61%，没有等待到1%内的再回踩。精智达在4根版本的6月15日10:30通过三项证据，随后8根的最小距离约2.92%，同样没有触线。这里用其后已发生行情解释等待结果，没有把未来距离加入启动信号。

康龙化成8根版本在8月4日09:45与10:00两个相邻截面通过三项15分钟证据，但当时尚无按该解释建立的日线观察资格；两个截面也不能算作两笔交易。之后月份内出现日线达标，不能倒补8月4日的入选状态。

这些结果首先说明自然语言与暂定硬门槛存在覆盖差异。下一轮应明确“多头排列覆盖哪个日线子段”“抵扣价下降是每一步下降还是总体下降”“启动观察之后是否必须再触MA30及等待多久”。本次没有依据赢家后续涨幅选出参数，没有产生正式成交、退出、买回或收益结果。
