# 日线首波回调与15分钟极致粘合启动

本规则由2026年9月30日的用户要求组合而成，属于开发期结构筛选与执行研究。原始日线和15分钟研究的收益不能直接当作本组合的收益。规则固定后才评分；不调用模型，不自动下单。

本页保留v1初版及其冻结结果。当前命令默认使用下文的v2澄清版；两版不能混称为同一回放。

## v1初版的结构

1. 首波启动为连续2—4板；也接受3天2板，分开记录，不能把间隔板写成两连板。其他间隔类型，例如4天2板，本版尚未纳入。
2. 首波高点创几个月新高，阶段涨幅不超过100%。日均线基本多头，覆盖MA5、10、20、30、60、120。
3. MA60或MA120至少一条连续上升20日，MA20或MA30至少一条连续上升20日。回踩的均线也必须持续上升。
4. 回调整理后波动率逐步降低，回踩日线MA20、MA30或MA60，再等15分钟买点。
5. 15分钟粘合：第一组close+MA5/10/20/30≤1.0%，第二组第一组+MA60≤2.0%，同根同时通过。
6. 粘合后第2或第3根收完时出现放量中大阳或连续阳线启动，且MA5>MA10>MA20>MA30>MA60>MA120，各线都上升。
7. 买后16根内跌回启动点：形成退出请求；T+1不可卖时保留请求，下一可卖时点执行。
8. 加速趋势出现第一根大阴或跌破MA20退出；正常趋势跌破MA30退出；从持仓高点回撤5%且收盘未收回退出；始终不拉升的横盘失去多头排列或约32根后退出。

## 首版工程定义

以下数值解释尚未量化的词，不是已校准概率，也未根据收益调参。

| 项目 | 固定实现 |
|---|---|
| 板型来源 | KPL `status`；连续2—4板或明确3天2板，不把5天2板计成两连板 |
| 近期首波 | 前60个交易日内最近一次符合板型的事件；只读取决策前一日及以前 |
| 阶段起点 | 该事件前30个交易日的最低价；最低价时点即阶段起点 |
| 阶段高点 | 该事件日至前一日的已观察最高价；不使用未来右侧拐点 |
| 阶段涨幅 | 100×(复权高点/复权起点低价−1)≤100% |
| 几个月新高 | 高点突破此前完整120个交易日的最高价 |
| 日线多头 | 首波高点、买点前最近完整日线均要求MA5≥10≥20≥30≥60≥120；允许数值相等 |
| 连续上升 | 每个相邻交易日均线增加，不是20日内多数上涨；缺失日打断历史，不压缩时间 |
| 回踩均线自身上升 | 本版把“持续”固定为至少20个交易日；与长、中均线两组的OR约束同时满足 |
| 回踩附近 | 粘合时点价格距离前一日已完成MA20/30/60之一≤3%，且该线自身上升20日；不使用当日完整日K |
| 回撤 | 前一完整日收盘相对已观察高点至少回撤5%；高点距前一日≤35个交易日 |
| 波动收敛 | 高点以后至前一日的整理段至少9根日K，等分为3个连续段，平均TR%严格逐段降低 |
| TR% | 100×max(high−low, abs(high−昨收), abs(low−昨收))/昨收；价格用当日已知复权因子 |
| 成交量 | 沿用前面日线要求：首波平均量、回调平均量各≥阶段起点前20日平均量的1.5倍；成交量不复权 |
| 中大阳 | 实体≥1%，实体/振幅≥60%，收盘位于振幅上部70%，量≥前8根均量1.5倍 |
| 连续阳线 | 粘合后2或3根全部阳线、收盘不降低，累计涨幅≥1%，总量≥粘合前同等根数总量1.5倍 |
| 启动突破 | 最终收盘突破粘合第一组上沿0.1%，前80根高低范围≤10%，最后一根六线严格多头且上升 |
| 其他15分钟前置条件 | 保留既有起涨来源、慢回调、长均线趋势、粘合前多头历史条件，未只保留两组宽度 |
| 启动点 | 单根确认用该根开盘价；连续阳线确认用序列第一根开盘价；不是事后最低点 |
| 快速上行与横盘 | 持仓已观察最高收盘比入场价涨幅不足3%，归为尚未快速上行；单根上影不算持续拉升 |
| 加速 | 后4根收盘涨幅≥3%，且至少是前4根正涨幅的2倍；一旦观察到便切换MA20/大阴退出分支 |
| 大阴 | 实体跌幅≥1%、阴实体占振幅≥60%；只能在这根收完后知道 |
| MA跌破 | 已完成15分钟收盘价低于对应MA；没有把盘中影线最低价当作已成交退出价 |
| 高点回撤5%未收回 | 持仓中已完成K线的最高价为基准；15:00收盘仍比高点低至少5%，才形成请求 |

首波“阶段起点”的定义对100%上限很敏感。本版用30日前置低点；如果用户指的是某次涨停前平台边缘或第一根涨停前收盘，必须另立规则版本比较，不能事后为某只模板改起点。

## 退出顺序与可成交性

程序逐根读15分钟K，记录价格、持仓高点、持仓根数、是否加速、是否横盘以及退出原因。多个条件同时成立，依次处理启动失败、横盘失序、横盘32根、加速大阴、加速跌破MA20、普通跌破MA30、收盘回撤5%。首个退出请求保留，不因随后反弹而事后撤销。

普通入场及可当日执行的退出，在15分钟决策收完后至少等60秒，使用随后一分钟开盘作成交代理。买入当日不卖；当日已经形成的退出请求在下一交易日9:30或此后首个可卖分钟执行。15:00才知道的收盘条件不能按同一15:00价格卖出。跌停、无量、缺失数据、复权因子变化均保留状态，不按止损线虚构成交。入场后第一根15分钟K的高低价只保留入场之后的1分钟区间，避免把买入前高点计入移动止盈。

用户此前允许涨停信号按涨停价可买，本版另列该假设；同时输出不接受涨停成交假设的代理结果。净收益扣双边滑点、佣金和卖出税，合计约0.31%；不含实际排队、订单规模、冲击、最低佣金或真实账户仓位。

T+1约束依据交易规则中证券交收前不可卖出的规定：[上交所交易规则第3.1.4条](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)。分钟开盘仍只是代理，不能证明委托一定成交。

## v2：启动阶段与日线粘合的澄清

用户指出近岸蛋白8月7日20cm首板是本轮启动，9月11日回踩持续上升的MA30，9月14日日线转强，再看9月16日盘中粘合。原程序的30日前低点、回调期六线严格排序、每次新板重置首波，以及要求分钟价格在启动时再次回到日均线附近，都可能错过这种多日顺序。v2单独保存，v1输入、信号和结果均不覆盖。

### 已明确的口径

- 20cm涨停可以提供等效2板的研究资格，也适用于科创板。实际KPL连板数、间隔板标签仍原样保存。20cm双连板记等效4板，不能把一个20cm交易日写成实际两连板。
- 只有KPL涨停记录且当日收盘等于离线涨停价、涨停价相对当日前收盘约20%，才采用20cm等效计数。缺涨停价不猜测，不能根据后来表现判断首板性质。
- 首波100%上限从**首个启动涨停收盘**计算，另报告从涨停当天最低价或之前平台起算的差异。这个选择不等于整个建仓成本区的涨幅。
- 日线粘合组为**MA5、MA10、MA20，不含收盘价与MA30**，跨度≤7%。这一条件只打开放宽分支，不替代其余日线门禁。
- 放宽分支的15分钟组为**close+MA5/10/20/30，跨度≤2%**，MA60不参与宽度约束。启动时仍要求MA5>MA10>MA20>MA30且四条上升，MA60/120也上升。
- 日线回踩可以先于盘中确认发生；回踩当天仅入观察，不能因为后来阳线把买点倒填到回踩日。

### 可配置工程解释

这些设置用于把“首波、基本多头、逐渐缩小”程序化，属于开发定义，并未由收益寻优得到。

| 项目 | v2实现 |
|---|---|
| 启动事件归组 | 相邻合格板事件间隔不超过10交易日，且首个事件距今未超过60交易日，归入同一阶段；连续板向前定位首板，3天2板向前定位3日窗口首日 |
| 新阶段和旧阶段 | 前60交易日内仍可见的阶段分别检查；新涨停不抹掉旧阶段的回踩观察。多个阶段合格选最近起点；均不合格只输出失败最少项供诊断，不生成信号 |
| 首波日线多头 | 高点日短四线顺序向上、位于MA60/120之上，两长均线当日上升；不要求MA60已先于MA120完成金叉 |
| 回调期日线排列 | 短线仍在两长线以上、MA60≥MA120；日短组三线粘合≤7%时允许短线互相穿插，其他情况下仍用六线排序 |
| 持续上升 | 长线与中线OR条件仍各连续20日；被回踩均线在触碰当天及当前完整日都连续上升20日 |
| 日线波动下降 | 保留TR三段原始值供审计；门禁改为整理段的14日平均TR%整体斜率<0，末3个ATR值平均小于最前3个，整理段仍至少9日；不要求每根K线的振幅单调缩小 |
| 回踩记忆 | 最近5个完整日内，日K高低区间与上涨中的MA20/30/60的±3%附近相交；分钟确认时不要求股价再次碰日MA |
| 分支同时点约束 | 粘合时、启动时各自的前一完整日均已经符合日线粘合分支，不能使用尚未收盘的当日日K |
| 15分钟前置背景 | 放宽分支采用20cm首波与日线趋势作大背景，保留已观察放量起涨来源、MA60≥MA120且都上升，价格不低于MA120附近1.5%；原分支保持原15分钟完整门禁 |
| 未放宽项目 | 粘合后第2/3根、中大阳/连续阳线、放量、突破，以及前80根15分钟高低范围≤10%仍保留；不能在观察到大涨后悄悄删除 |
