# 光力科技：纯15分钟MA250上穿回放

用户提出的买点：MA250长期下跌时价格上穿MA250，MA5>MA20>MA30，MA5分别上穿MA20与MA30均发生在最近16根内；若未来16根价格恒定，MA20应在此期间上穿MA250。卖点：冻结MA5/MA20金叉交点止损、16根未兑现MA20/MA250金叉退出，价格开始上涨后跌破MA30退出。

本研究不加入题材、新闻或日线条件，不按收益调参。未进行实盘交易。

## 运行入口

从项目根目录运行：

```bash
.venv/bin/python -m unittest discover -s policyStudy/policy/题材涨停研究/scripts -p test_ma250_reclaim.py -v
.venv/bin/python policyStudy/policy/题材涨停研究/scripts/replay_ma250_reclaim.py
.venv/bin/python policyStudy/policy/题材涨停研究/scripts/review_ma250_reclaim.py
```

计算与执行规则在 `policyStudy/policy/题材涨停研究/scripts/study_ma250_reclaim.py`。首次运行通过统一 `coreClient.data_provider` 接口读取TDX原生15分钟数据、交易日历、日线、复权因子和每日涨跌停价格；其后复用冻结快照。修改规则或输入必须使用新的输出目录。复核脚本核对代码及输入哈希、真实信号截断重算、改动未来行情后信号不变、现金账和T+1顺序。

## 本轮固定口径

- 测试区间2025-10-02至2026-10-02，实际行情截至2026-09-30；取2025-07-01以来数据预热。测试241交易日、3856根；每日16根，09:45至15:00，保留午间和隔夜边界。
- “长期下跌”量化为MA250最近80根总体下跌、至少80%的斜率向下、当前斜率向下。32根、160根及连续80根下跌只作预先声明的定义敏感性对照。
- 主口径在价格**当根上穿**MA250时全部条件同时满足。上穿后最多再等15根的解释差异单独保存，不作为主口径。
- 简单移动平均按截至当前的价格乘当日复权因子计算，不使用未来复权基准。本轮所有复权因子相同，没有跨除权持仓；程序遇到测试期因子变化会拒绝宣称现金回测完成。
- 金叉交点按交叉前后两根MA5和MA20做线性插值确定，买入时冻结。主止损用完成柱收盘跌破；影线触及的对照也在完成柱后执行，不按名义止损价假设成交。
- 16根期限从信号柱之后起算，真实金叉在第16根发生仍合格。若买入后有一根完成收盘高于实际买价，启用MA30退出；任一退出触发后指令保持至可卖，不能用之后的反弹撤销。
- 下一根开盘代理成交，100股一手，30万元单股满仓现金复投；滑点每边0.05%、佣金万三最低5元、卖出印花税万五、过户费每边十万一。T+1禁止同日卖出；涨停开盘买单视为未成交，跌停开盘卖单延后。期末未出现退出则标记持仓、不强制平仓。

恒价推演同时重算两根均线：

`MA_N(t+h) = MA_N(t) + (h*C_t - sum(C[t-N+1:t-N+h]))/N`，其中N=20、250，h=1…16。

该计算是一种条件路径，不能将数学金叉时间解释为上涨概率。A股T+1约束见[深交所交易规则第3.1.4条](https://docs.static.szse.cn/www/lawrules/rule/trade/current/W020260424690713155663.pdf)。普通15分钟OHLC无法验证订单排队和确切成交，下一开盘仍属于成交代理。

两次信号全部成交并卖出，均由收盘跌破MA30触发。30万元复投后361,276.60元，净收益20.43%，按15分钟收盘权益计算最大回撤5.89%。严格连续80根下跌与32/160根定义的对照均得到相同两笔；“上穿后等16根内条件满足”的不同解释得到4笔、净收益41.35%，不能混用两个分母。

本股票919根符合长期下跌，4根发生价格上穿，其中3根符合短均线多头、2根符合近期双金叉；这2根抵扣预测均达标，因此该样本并不能证明抵扣筛选的增量价值。利润98.29%来自8月一笔，持仓仅90/3856根。同期股票简单买入持有价格涨幅61.04%，策略盈利不能直接解释为优于基准。

两笔均盈利，不足以估计真实胜率；未遇到金叉超时、止损或T+1被迫等待的真实交易。合成边界测试不等于止损尾部已验证。本轮只验证了给定股票历史上的计算与规则行为，尚未作独立股票/未来日期检验。
