## 生命周期研究怎样做

覆盖2025-10-30至2026-08-31，共205个交易日。按开盘啦原始 `lu_desc` 归因，研究137个活跃题材、793段行情、80个反复活跃题材及678只龙股。原始同义标签不主动合并，与我们少量题材别名归并的处理不同。

- **活跃题材**：当日至少3只封住涨停，或至少2只且其中有连板股。
- **行情分段**：零涨停或极端梯队断档形成退潮边界，再次活跃形成新段。极端断档具体指只剩不超过2只高位股、没有首板和2—3板中间梯队。
- **题材排序**：宽度40%、高度深度30%、梯队20%、封板质量10%；每日展示活跃题材前五及其他达到10家涨停的题材。
- **龙1/2/3**：固定按板数、封住优先、封板时间、封单金额、成交额排序。它们是可复算的结构角色。
- **三套角色日期**：段首龙位、首次进入展示集合时的冻结龙位、逐日更新的当日龙位，分别服务跨段、前瞻结果和段内换位分析。
- **实现龙头**：整段结束后，以最高板数等选出的事后赢家，单独作为结果标签。

方法和公式见[完整说明书](/Users/nickzhang/.codex/worktrees/mrwu-review/TradingAgent/docs/research/mrwu_theme_lifecycle_20260921/deliverables/RESEARCH_METHOD_AND_DATA_MANUAL_v0.2.md)。

| 问题 | 报告结果 | 应怎样理解 |

| 昨日第一题材还能保持第一吗 | 55/204，26.96% | 需要保留候选与下一时点确认；这是相邻日排名转移，非三日主线预测准确率 |
| 题材再启动是否仍由旧龙领涨 | 后续段前三槽位中，67.8%是该题材此前段首前三未出现过的股票 | 旧题材回流与旧龙回归应分开判断；分母是槽位，不是独立股票或交易日 |
| 相邻两段前三能保留多少 | 281/1,854，15.2% | 不能将上一轮前三直接视作新一轮固定名单 |
| 冻结时能覆盖后来走出的结构龙头吗 | 冻结龙1对应实现龙头229/407，56.3%；前三覆盖302/407，74.2% | 这是特定规则角色与整段事后标签的匹配，不是GPT选股成绩 |
| 单轮多日题材内是否容易换位 | T+1原龙1仍第一4/10，仍前三6/10；新股占15/25个前三槽位 | 样本仅10个题材，T+2只剩3个，不足以形成普遍规律 |
| 中军走弱能否单独预告退潮 | 70段可精确映射中军；weak后次日仍活跃67.86%，strong后60.55% | 关系不单调，且覆盖受限，不能直接写成“中军弱就退潮” |

报告另列冻结龙1的后续终值收益中位数约9.79%、正收益比例72.77%，但只覆盖224个有相应窗口的样本。行情段的结束由后续走势界定，因此该统计不是预先确定退出时点的可执行交易胜率。

**不能把56.3%、74.2%或72.77%与我们刚完成的19.0%直接比较。** 我们19.0%考核的是当日已涨停池中未来两日超额收益冠军；吴老师56.3%考核的是整段最高板等定义的实现龙头，窗口、候选与目标均不同。后续应在同一输入和日期上并列评估两套预先冻结的目标，保留原成绩。

## 前一轮策略发现做了什么

- **早封板**：裸0—5分钟早封、次日买入、约持有3日，1,287笔闭合样本平均净收益−1.211%。叠加前日板块资金参与、上涨广度与相对活跃度后，111笔平均+0.943%，日期等权仅+0.161%。
- **市场成交状态**：用成交额的相对水平与变化，区分扩张、收缩、平稳高量、平稳低量。进一步切出的收缩子样本36笔/18日表现较强，平均+4.042%，但属于同一开发期的事后分层，只列为待验证线索。
- **分钟机制**：研究旧龙休息、次龙接力、双锚确认、午后二次扩张等。实际触发稀少；代表机制20笔/6日，平均+0.028%、日期等权−0.426%，没有形成稳定结果。
- **跌停等待反弹**：572个暴露、155个去重簇；等待的平均改善很小，极端亏损扩大，不支持无条件等待反弹。
- **GPU排序和新闻**：8个模型跨时间窗口不稳；新闻标题/短文本的有效样本和发布时间认证不足，尚无可交易结论。
- **研究反省**：明确指出“把策略发现做成机械回测”“局部零件未串成完整逻辑”“代理指标不能代表原始想法”“缺少退出与统一账户”等问题。另有编排事故复盘，说明长期运行的大模型任务、重复上下文和轮询造成的资源浪费。

## 与我们的工作如何衔接

最值得吸收的是“行情分段＋三套龙位时钟＋新旧龙更替”这套结构，而不是直接复制某个收益或准确率。

1. 把题材历史拆成连续行情段，记录截至当日的段龄、梯队、原成员留存和核心更替。
2. 同时保存段首候选、前日候选与今日候选，解释究竟是旧龙修复、次龙晋级还是新龙出现。
3. 将结构龙头与未来收益冠军作为不同目标，分别评分；再加入新闻验证事件归属与催化延续。
4. “反复题材”“单轮题材”是完整区间的事后分类，盲测时不能直接作为当日已知标签；只能使用截至当时已经发生的历史。
