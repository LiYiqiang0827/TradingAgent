## 1. 背景与目标

### 1.1 项目目标

只做多，交易不必多；买错了尽早认错、亏小钱，买对了拿住吃大波段；胜率五五开也可以，靠赔率实现可持续复利。

### 1.2 李老师的因果链

1. 日线连续上升、均线连续上升，说明股票有趋势。
2. 等回调。事先不知道回调到日线MA20、MA30还是MA60。
3. 用15分钟的反转形态和均线去试。
4. 15分钟均线重新回到多头排列并上升，就是“判断对了”的准则。
5. 用试错博取后面的大幅上涨：对了拿住，错了就走。
6. 抵扣价告诉我们守住什么价格均线就能恢复；跌破这个价格，就是不行了。
7. 具体参数由AI通过历史数据统计和回测得出。

### 1.3 策略成立的条件

```
单笔期望 = P(恢复) × 恢复后平均收益 − P(未恢复) × 未恢复时平均亏损 − 成本
```

| 环节 | 问题 |
| --- | --- |
| A 恢复有价值 | 15分钟恢复多头以后出现大涨的比例，是否明显高于没恢复的 |
| B 认错够便宜 | 没恢复时，按规则离场的平均亏损是否够小 |
| C 恢复比例够高 | 恢复的比例，是否足以让等式为正 |

未恢复的单也可能微赚，所以核对等式时用“有符号的条件平均收益”：恢复组和未恢复组各自的平均净收益（可正可负），乘以各自比例相加，应等于总平均净收益。

### 1.4 以往研究的教训（必须读）

1. 不能用牛股的样子找牛股。要估计的是 P(大涨 | 当时信号)，不是 P(信号 | 后来的牛股)。
2. 多条均线同向，往往是同一段涨价的重复编码，不是多份独立证据。
3. 在同一段行情上反复调参，测试就不再是样本外。
4. 平均数常常被少数赢家和个别月份撑起。
5. 旧版二启回放因预查未来数据而结果作废。防止偷看未来是第一优先级。

## 4. 规则框架

所有日线条件只用 D−1 及更早的完整日K。15分钟指标只用已完成的K线（4.4节的P*除外，它不含未来信息）。价格统一前复权，成交量用未复权实际量。

### 4.1 日线趋势池

**事件库用的宽松版本**【定】：

- MA30连续上升 ≥ 10个交易日；
- 近20个交易日中，MA5>MA10>MA20>MA30 的天数占比 ≥ 60%；
- MA60 > MA120（之前已在上方的也算）【李】；
- 近60个交易日内至少一次自身涨停（判定见3.4节）；
- 放量：第一波均量和回调均量相对基准量的倍数，事件库只记录不过滤。

**策略规则用的严格版本：**

| 条件 | 规则 | 标注 |
| --- | --- | --- |
| MA30连续上升天数 | 由S2的分布决定 | 【统】 |
| 多头排列占比 | 由S2的分布决定 | 【统】 |
| 收盘连涨 | 第一波内至少一次连续3天收盘上涨（每天收盘都高于前一日收盘） | 【定】 |
| 涨停 | 第一波内至少一次自身涨停 | 【李】 |
| 放量 | 第一波均量、回调均量都不低于基准量的1.5倍 | 【李】要求放量；【定】标准 |
| 题材 | 记录题材、热度、是否龙头（4.10节）。作为分组标签和S4的过滤选项 | 【李】要题材；【定】用法 |

### 4.1.1 第一波的唯一算法【定】

以回调事件的开始日为锚。锚定后在该事件内不再移动。

| 量 | 定义 |
| --- | --- |
| 回调开始日 D_pb | 该事件第一根满足15分钟空头排列（4.2节）的K线所在交易日 |
| 峰值日 P | 在 [D_pb−20, D_pb−1] 这20个交易日内，前复权最高价最高的一天；并列取最近的一天 |
| 起点日 S | 在 [P−60, P−1] 内，前复权最低价最低的一天；并列取最近的一天 |
| 第一波 | 起点日次日至峰值日，即 [S+1, P] |
| 基准量 | 起点日之前20个交易日 [S−20, S−1] 的日均量 |
| 第一波均量 | [S+1, P] 的日均量 |
| 回调均量 | [P+1, D−1] 的日均量，D 为决策日（买入日）。区间为空时记为缺失，放量条件不成立 |
| 连涨3天 | [S+1, P] 内存在连续3天，每天收盘都高于前一日收盘 |
| 第一波涨停次数 | [S+1, P] 内自身涨停的天数 |

数据不足（S之前不够20个交易日、P之前不够60个交易日）时，相应量记为缺失，严格池条件不成立。

**示意（数字为虚构，只说明取法）：** 某股回调事件的第一根空头排列K线在2019-03-11。往前20个交易日内，最高价在03-05和03-07都是12.80元，并列取最近，P = 03-07。在03-07之前60个交易日内，最低价最低的一天是01-31（8.10元），S = 01-31。第一波 = 02-01至03-07；基准量 = 01-31之前20个交易日的日均量；若在03-14买入，回调均量 = 03-08至03-13的日均量。

### 4.2 15分钟回调事件

- 股票处于宽松趋势池时，15分钟 MA10<MA20<MA30<MA60<MA120 连续出现，记为一次回调。
- 事件库记录所有连续 ≥ 16根的回调和实际持续长度。策略规则要求 ≥ 48根【李】，并报告32根、64根的敏感性。
- 事件结束：日线收盘跌破MA60、或回调开始后40个交易日、或该事件的交易已平仓，以先到者为准【定】。
- **事件结束只停止新的买入，已有持仓照常按卖出规则管理。** 该股票持仓平仓之前，不开始新事件【定】。
- 同一股票的事件不重叠。一个事件内可以多次进入“就绪”，但最多成交一笔【定】。

### 4.3 回调结束（就绪状态）

以下全部满足，进入“就绪”：

1. 12根K线内，MA5先后上穿MA10、MA20、MA30，顺序不限【李】。上穿：上一根MA5 ≤ MAx，本根MA5 > MAx。
2. 三次上穿完成后，至少一根收盘在MA120上方【李】。完成第三次上穿的那根K线本身可以同时满足此条。
3. 当前收盘满足守住价条件（4.9节的可行集合判定，用上一根完成K线的数据）【李】。

满足就绪的那根K线收盘后，从下一根K线开始接受回踩买入。

**就绪失效：**

- 就绪后W根内没有回踩，作废。W取S2中成功事件（L25=1）回踩等待时间的80%分位，上限48根【统】。
- 就绪后、买入前，收盘低于 MA30 × (1 − tol)，作废【迭】。
- 15分钟重新形成空头排列，回到回调状态，可以再次就绪。

### 4.4 买入

- 回踩价 P* = 前29根15分钟收盘的平均值。推导：实时MA30 = (S29 + p) / 30，p ≤ MA30 等价于 p ≤ S29 / 29。P*在该根K线开盘前已知。
- 就绪后，某根K线最低价 ≤ P*，且 P* 满足守住价条件（用上一根完成K线算出的可行集合），即成交。开盘价已 ≤ P* 时按开盘价成交，否则按P*成交【李】立即买入；【定】成交规则。不另加“成交价 ≥ H”的过滤【定】。
- 守住价在买入时冻结为 H_entry（买入前一根完成K线的 H_inf 及其开闭标记）。
- 一次买满，每笔等额【李】。
- 涨停封板（最高价等于最低价等于涨停价）不可买，如实记录。
- 挖掘期用15分钟成交。考卷和已看过时段另报1分钟成交版本，用1分钟数据确定实际触价的分钟【定】。

### 4.5 日线确认（记录项，另设变体）

- 回调级别：回调期间（D_pb 至 D−1）日线最低价碰到的最深均线：未碰MA10、MA10、MA20、MA30、MA60、跌破MA60，容差1%【李】。只作分组。
- 长下影线：下影线 ≥ 实体的2倍，且 ≥ 当日振幅的40%【定】。
- 阴后阳：阳线涨幅 ≥ 前一日阴线跌幅的70%，上影线 ≤ 实体的1/3【李】幅度；【定】上影线标准。
- 当天碰日线均线：买入K线之前、当天已完成的15分钟K线中，有最低价进入日线关键均线（MA10、MA20、MA30、MA60）上下1%以内。日线均线的盘中值 = (前N−1日收盘之和 + 当前价) / N。买入K线是当天第一根时，此项为否【李】含义；【定】时点。
- V3（当天碰日线均线）是S4的过滤选项之一。

### 4.6 卖出

所有信号按15分钟K线判断，在信号K线收盘价卖出【李】。另报“下一根开盘卖出”作对照【定】。买入那根K线记为第1根。

**两个阶段**

- **认错阶段：** 从第1根开始，到期望状态开始或第T根结束为止。
- **持有阶段：** 期望状态开始后。期望状态一旦开始，进入持有阶段，之后即使均线再度走坏，也不回到认错阶段。

**认错阶段的规则**

| 规则 | 内容 | 标注 |
| --- | --- | --- |
| 时间窗口T | 李老师定16根；S3在12、16、20、24根中找高原。16根落在高原内就保留16 | 【李】锚点；【迭】 |
| 守住价离场 | 收盘不再满足 H_entry 的可行条件，全部卖出 | 【迭】用不用 |
| 时间止损 | 第T根结束时期望状态仍未开始，全部卖出 | 【李】 |

### 4.9 守住价H【定】

**定义：** 在第t根（已完成），取k根（候选4、8、16，由S2的区分力决定【统】，是否用于离场由【迭】决定）。假设后面k根收盘都等于同一价格p。p的可行集合是使下面两件事都成立的全部p：

1. MA10、MA20、MA30在这k根里每一根都不下降；
2. 第k根时 MA10 > MA20 > MA30（严格大于）。

条件1是“≥”，条件2是“>”，所以可行集合的下边界可能是开的，“最低价”一般不存在，只有下确界 H_inf。

**k = 4、8 的边界：** 记C为15分钟收盘价，S_N 为最近 N−k 根实际收盘之和（第 t−N+k+1 根到第 t 根）。

```
H_扣 = max{ C(t+j−N) : j = 1..k, N ∈ {10, 20, 30} }      # 闭边界：p ≥ H_扣
B1 = (S20 − 2·S10) / k                                    # 开边界：p > B1（MA10 > MA20）
B2 = (2·S30 − 3·S20) / k                                  # 开边界：p > B2（MA20 > MA30）
H_inf = max(H_扣, B1, B2)
可行 ⇔ p ≥ H_扣 且 p > B1 且 p > B2
```

**k = 16：** MA10的抵扣会用到假设价p本身，不能把 N−k = −6 代入上式。记 U4 = 最近4根收盘之和，U14 = 最近14根收盘之和，D30 = 最近30根收盘的最大值：

```
可行 ⇔ p ≥ D30 且 p > U4/4 且 p > (2·U14 − 3·U4)/16
H_inf = max(D30, U4/4, (2·U14 − 3·U4)/16)
```

**用法：**

- 判定（就绪条件、买入时 P* 的检查、守住价离场）一律用上面的精确谓词，不加 epsilon，不改成非严格不等式，不用格点。
- 展示（图上的虚线、报告里的距离）用 H_inf。
- 守住价离场：收盘不再满足 H_entry 的谓词即离场。

**测试要求：** 用暴力逐根模拟与上述谓词比对，随机 ≥ 3000 组，必须包含边界恰好相等的人工构造用例（例如 p 恰好等于 B1）。

## 8. 打分方式【定】

### 9.1 六个过滤选项【定】

### 9.2 选择规则【迭】

用S3选出的卖法，对每个过滤计算：

1. **保留率：** 2018–2022年合计，过滤后成交笔数 ÷ F0成交笔数 ≥ 30%。
2. **逐年：** 5年中至少3年，过滤后的单笔平均净收益高于F0（该过滤无成交的年份算“不高于”）。
3. 同时满足1和2的过滤为入选。F0总是入选。
4. 在入选者中，取5年合计单笔平均净收益最高的为“最佳”。按日期分块重抽样（20个交易日一块，2000次，种子固定）求最佳者的标准误。均值落在最佳者一个标准误以内的入选者中，取最简单的。
5. 选中的记为 F*。

### 10.2 高原

- 候选组合按5年合计单笔平均净收益排序。
- 高原：最佳组合及其相邻取值的组合，与最佳者的均值差距不超过最佳者均值的30%；且每个组合都满足：5年中至少3年为正，并且去掉表现最好的一年后，其余年份的单笔平均净收益仍为正。
- 选高原中心，不选单点最高。最高点孤立时，报告并选次优高原。

### 10.3 交替迭代的收敛

- S3（卖法）→ S4（过滤）→ S5（重查卖法）→ 卖法变了再查过滤……
- **收敛：** 新一轮的参数仍在上一轮高原之内，且5年合计单笔平均净收益提升小于0.2个百分点。
- **摆动：** 连续两轮在不同高原之间来回跳：选逐年表现最稳定的高原，继续，并在报告中标记。
- **上限：** 5轮仍不收敛：同上处理，继续，并标记。
- 每一轮改了什么、分数多少，全部写入试验台账。

## 14. 执行与资源规则

### 14.1 防止token失控（9月20日事故的教训）

1. **计算交给本地脚本，AI只看摘要。** 统计、回测都由电脑上的Python进程完成。AI只读几KB以内的摘要文件，不读原始数据，不读长日志。
2. **不轮询。** 长任务在后台运行，结束时写完成标记文件；AI在任务完成后再读结果。
3. **一个总控。** 子任务串行，或最多2个同时进行。每个子任务写明输入、输出和完成标准。
4. **分阶段换上下文。** 每个阶段结束时写一份状态文件（不超过3KB）。下一阶段开新的上下文，只读状态文件和本文。
5. **先校准，再定预算。** S0开头先用2到3个典型工作包实测用量，缓存输入、新增输入、输出分开记录。据此重估S1–S8的预算，写进S0报告。之后某阶段的新增用量（新增输入加输出）或总用量（含缓存输入）任一超出实测预算的150%，自动暂停，通知吴俊捷；未超支时不需要任何确认。
6. 自行调试：每个工程问题最多换3种做法、累计5次尝试；研究路径每个问题最多3条。
7. 不使用 Luna Max。

### 14.2 自行调试与多路径尝试

| 尝试的对象 | 规则 |
| --- | --- |
| 工程问题（报错、安装失败、性能不够） | 自行调试。仍不能解决就标为“阻塞”，写入问题记录，先做不依赖它的模块；只有关键路径被阻塞时才暂停通知 |
