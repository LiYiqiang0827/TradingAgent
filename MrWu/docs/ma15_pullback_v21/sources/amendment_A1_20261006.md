## 0. 结论

1. **硬停有效，处理得当。** Astra 没有豁免预热年、没有放宽阈值、没有换数据源，证据完整。按规则停下是对的。
2. **授权：只做S0数据诊断与修复。** 不开始S1，不读考卷做策略计算。
3. **0.5%和1%两个门槛不放宽。** 要修正的是“不一致”的定义：把有交易所规则依据、并经数据验证的口径差异，和真正的数据错误分开。修正后的定义和启用条件写在本文第3节，**在看到诊断结果之前就定下来**。
4. 诊断满足第3节条件，就按修正口径重做S0全部年份，然后继续S1，**不再停**。不满足，维持硬停，报告后由 Claude 决定下一步。
5. 执行计划v1.1已核对，与审阅决议一致，S1开始前不需要另行修正。唯一的补充是本文第4节的策略侧规则。

**责任说明：** 原门槛“任一OHLC相差超过0.5%”是 Claude 定的，当时没有考虑A股开盘集合竞价和上交所旧收盘价规则这两个已知口径差异，写得太粗。门槛本身起了作用：它把这两个差异暴露了出来，否则它们会悄悄影响开盘成交价和涨停判定。

## 1. 对S0数字的解读

| 现象 | 数字（2017） | 最可能的解释（待验证） |
| --- | --- | --- |
| 开盘价不一致占绝大多数 | 65,494个；其中仅开盘不一致59,185个 | 分钟数据第一根K线不含09:25开盘集合竞价那一笔成交。交易所开盘价是集合竞价价，分钟首根开盘价是09:30以后的第一笔连续竞价成交价 |
| 最高价、最低价不一致 | 6,268个、8,057个 | 同一原因：集合竞价价恰好是当天最高或最低时，分钟数据里没有这个价 |
| 收盘价不一致很少 | 2,209个（0.30%） | 上交所在2018-08-20实行收盘集合竞价之前，官方收盘价是最后一分钟的成交量加权平均价，不是最后一笔成交价；深交所早已实行收盘集合竞价 |
| 低价股 | 未单列 | 股价低于2元时，1分钱（一个最小价位）就超过0.5% |
| 分钟有、日线缺 | 55,806个，全部16根零成交量 | 停牌日被分钟数据用平价K线填充。**这个比价差更危险**：若不剔除，会混进均线和“连续48根”的计数 |
| 名称缺失 | 90,097个股票日（约12%） | 按现规则“ST未知不新开仓”，会白白排除约12%的股票日 |

所以，这次硬停多半不是“数据坏了”，而是“两边对开盘、收盘的定义不同”。但“多半”不够，下面先验证，再改口径。

## 2. 预先登记的诊断（限S0、只输出质量统计）

范围：2017年全年，加2018年全年（只用于第H3项的收盘规则对照，2018属挖掘期，S0质量访问已获授权）。只读，只输出汇总和极少量样本证据。

| 编号 | 假设 | 检验方法 | 预先写定的判定 |
| --- | --- | --- | --- |
| H0 | 两个样本日能说明问题 | 600483.SH 2017-03-21、002085.SZ 2017-08-21：并排列出交易所OHLC、15分钟首末根、1分钟首末根（含成交额、成交量） | 只作说明，不作判定 |
| H1 | 分钟数据不含开盘集合竞价 | 在“最高价不一致”的股票日中，统计交易所最高价等于交易所开盘价的比例；“最低价不一致”同理（最低价等于开盘价）。另抽样核对1分钟首根开盘价与15分钟首根开盘价是否相同 | 两个比例都 ≥ 80%，且1分钟与15分钟首根开盘价一致率 ≥ 99%：H1成立 |
| H2 | 开盘价差异属于正常幅度 | 开盘价不一致的幅度分布（0.5–1%、1–2%、2–5%、5%以上）和正负号分布，按交易所、价格档分列 | 只报告。超过5%的占比若高于开盘不一致总数的5%，在报告中重点说明 |
| H3 | 上交所旧收盘价口径 | 2018年分两段：01-02至08-17、08-20至12-28。分别统计沪市和深市的收盘价不一致率。若1分钟数据有成交额，另算沪市2017年收盘不一致日中，交易所收盘价与最后一分钟加权均价（成交额÷成交量）相差不超过1分钱的比例 | 沪市后段比例 ≤ 前段的20%，且深市后段与前段之比在0.5到2之间：H3成立。有成交额时，上述1分钱比例 ≥ 90% 作为加强证据 |
| H4 | 低价股的最小价位 | 不一致的股票日中，差额恰为1分钱的占比，按价格档分列 | 只报告 |
| H5 | 剩余不一致没有异常聚集 | 按第3节修正口径算出“无法解释的不一致”，列出：按股票、按日期的集中度，前20只股票及其不一致率，幅度分布 | 若一半以上的剩余不一致集中在不到1%的股票上，报告这些股票，作为“数据不可靠股票”候选 |
| H6 | 停牌填充 | 全天各根成交量都为0的股票日，与停牌接口逐日核对（抽样即可） | 一致率 ≥ 95%：按第4节R3剔除 |
| H7 | 名称变更表能补判ST | 在CSV名称已知的股票日上，用名称变更表（起止日期）推出当日名称，比较是否同为ST或同为非ST | 一致率 ≥ 99%：按第4节R4启用 |

诊断必须在新的上下文中进行（见第5节），AI只读汇总文件。

## 3. 修正后的日线对账口径（D01-R）

### 3.1 定义

对每个双方都有有效值的股票日，用**未复权原价**比较（两边都是未复权价，最小价位是0.01元）：

1. **开盘注入（仅在H1成立时）：** 用交易所开盘价代替分钟首根开盘价，并令合成最高价 = max(分钟最高价, 交易所开盘价)，合成最低价 = min(分钟最低价, 交易所开盘价)。
2. **收盘参照：** 上交所股票在2018-08-20以前：H3成立时，这部分收盘价不进入门槛计算，单独报告（1分钟数据有成交额时，改与最后一分钟加权均价比较并计入门槛）。其他情况与交易所收盘价比较。
3. **容差：** 差额 > max(参照价×0.5%, 0.01元) 才算不一致。比较用“分”为单位的整数。
4. **门槛：** 每一年，注入后的最高、最低、收盘中任一项不一致的股票日，占共同有效股票日的比例 ≤ 1%。**任一年超过1%，仍是数据硬停。**

### 3.2 必须同时报告

- 原口径（v2.1第3.2节）的逐年不一致率，照旧报告，不隐藏。
- 开盘价的原始差异分布（H2）。
- 被“上交所旧收盘口径”排除的股票日数。

### 3.3 启用条件

- H1不成立：不做开盘注入。此时按原口径的H、L、O判定，硬停维持，报告后由 Claude 决定（例如查原始CSV、用同一供应商的1分钟库重建15分钟K线）。
- H3不成立：上交所旧收盘不排除，按交易所收盘价比较。
- H5发现聚集：门槛仍按全部股票计算，不能先剔除再算。数据不可靠股票另列，是否剔除由 Claude 根据报告决定。

### 3.4 范围

D01-R 先用于2017。通过后，S0其余检查（D02–D11）和2018–2026-09-18逐年对账按同一口径完成。任一年不通过即硬停。

## 4. 策略侧规则修订【定】

| 编号 | 规则 | 生效条件 |
| --- | --- | --- |
| R1 开盘注入 | 每只股票每个交易日的第一根15分钟K线：开盘价 = 交易所开盘价；最高价 = max(原最高价, 交易所开盘价)；最低价 = min(原最低价, 交易所开盘价)。交易所开盘价按同一复权因子换算。信号、合成日线、开盘成交（含“开盘价已≤P*按开盘价成交”和T+1次日开盘卖出）都用注入后的K线。交易所开盘价缺失的日子保持原样并计数。开盘价09:25已知，不构成偷看未来。成交量不改（分钟数据没有集合竞价量），在局限中说明 | H1成立 |
| R2 收盘价 | 信号收盘价仍用最后一根15分钟收盘价（最后一笔成交价），不用交易所收盘价替换。自身涨停判定仍为：该收盘价等于 stk_limit 涨停价（分为单位整数比较）。上交所2018-08-20前的口径差异写入局限 | 始终 |
| R3 停牌 | 全天各根成交量都为0的股票日，视为停牌，从该股的15分钟序列和合成日线中删除：不参与均线计算、“连续上升”“连续空头≥48根”等计数。按交易日历计的期限（事件40日、最长持有60日、L25的20日、B0持有期）照常按日历走；停牌期间不能成交，到期或触发的卖出顺延到复牌后第一根K线。部分K线零成交量的正常交易日保留 | H6成立；不成立时同样执行，并在报告中写明依据不足 |
| R4 ST补判 | CSV名称缺失的股票日，用名称变更表按起止日期推出当日名称，判断是否ST。仍无法判定的记为未知，不新开仓 | H7成立 |
| R5 数据不可靠股票 | 由 Claude 根据H5的报告决定是否剔除；剔除名单写入数据使用登记表 | H5发现聚集时 |

R1–R4 同样适用于考卷年份和已看过时段，不因年份不同而改口径。

## 5. 执行要求

1. **新上下文。** S0报告显示主控在校准阶段就累积了约250万缓存输入，当前S0总量已到641万（预算1,137万，保险丝1,706万）。诊断和后续S0工作必须由新开的上下文执行，只读：本修订单、设计v2.1、v1.1、≤3KB的S0交接状态。不继承前面的长对话。
2. **一个有界工作包。** 第2节诊断由本地脚本一次批量完成，产出一个汇总JSON和一份不超过5KB的Markdown摘要。AI只读这两份文件。
3. **登记。** 2018年的质量访问、名称变更表、停牌接口的读取都写入访问日志，用途标“S0诊断”。
4. **通过时：** 按D01-R完成S0全部检查和全部年份，写S0报告（含原口径与新口径两套数字、H0–H7结果、R1–R5的启用情况），上传、通知，继续S1，不再停。
5. **不通过时：** 写诊断报告、上传、通知，等待 Claude 的处理意见。
6. **禁止：** 降低0.5%或1%；豁免2017；用交易所日线整根替换15分钟K线；在门槛计算前剔除股票；读取考卷做任何策略计算。
