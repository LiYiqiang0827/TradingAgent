## 1. 一句话研究问题

在 2025-10-30 至 2026-08-31 的开盘啦涨停题材数据里，题材如何活跃、退潮、再活跃；同一行情段内和跨行情段时，龙1、龙2、龙3会如何守位、晋级、退位或被新股票替代。

## 2. 明确不在本轮范围内的事项

- 不预测下一交易日。
- 不设计买点、卖点、仓位或开盘30分钟执行规则。
- 不使用新闻解释题材催化。
- 不把后视镜“实现龙头”当成当时可见信号。
- 不把日线最低价到后来最高价、最高价到后来最低价解释成可实现回测收益。
- 不给出任何实盘下单或投资建议。

## 5. 核心定义

### 5.1 活跃日

满足任一条件：

1. 同一原始题材当日有至少 3 只封住涨停；或
2. 至少 2 只封住涨停，且至少 1 只是连板。

高度不能单独替代宽度。

### 5.2 退潮与行情段

同一原始题材的活跃日被退潮日分开时，后一次活跃视为新行情段。退潮包括零涨停或极端断档。由于使用原始大标签，同一标签的不同段可能对应不同催化、分支和核心股。

### 5.3 三个龙位时间钟

|名称|认定日期|主要用途|
|---|---|---|
|冻结龙位|行情段首次进入每日展示集合的日期 `role_freeze_date`|检验当时可见选择后的纯前瞻表现|
|段首龙位|行情段 `start_date`|比较反复题材跨段是否换龙|
|当日龙位|行情段内每个交易日|比较单轮多日题材的 t−T 换位|

三套角色不得静默混用。

### 5.4 龙1、龙2、龙3排序

候选股按以下固定顺序排序：

1. 解析后的连板高度降序，缺失最后；
2. 封住涨停优先于炸板；
3. 封板时间升序，缺失最后；
4. 封单金额降序，缺失最后；
5. 成交额降序，缺失最后；
6. 股票代码升序，作为确定性并列打破。

排名第1、2、3依次显示为龙1（龙头）、龙2、龙3；其他候选为后排。

### 5.5 实现龙头

实现龙头是完整行情段结束后的后视镜描述标签。每段按以下顺序选一只：

1. 行情段内达到的最高连板高度；
2. 行情段内累计峰值收益；
3. 最早达到最高板的日期；
4. 该日最早有效封板时间，缺失最后；
5. 股票代码升序。

用途：解释最后谁走出来，并回看它在冻结日是什么身份。禁止将其替换成冻结龙位或实时信号。

### 5.6 容量中军

候选范围：冻结日同一原始 KPL 题材的精确概念成分；沪深股票；排除 ST 和非沪深代码。

候选门槛：

- `circ_mv`、`amount`、`pct_chg` 完整；
- 题材内自由流通市值分位不低于 80%；
- 题材内成交额分位不低于 70%。

评分：

`capacity_score = 0.55*circ_mv_percentile + 0.35*amount_percentile + 0.10*return_percentile`

最高分为主中军，第二名为备选；并列按市值、成交额、涨幅、代码依次打破。

覆盖限制：793段中407段有冻结日，仅70段可将原始题材精确映射到成分股；这70段全部找到明确中军。因此当前数据无法干净比较“有中军”和“无中军”。

## 6. 题材层结果

### 6.1 生命周期

- 137 个活跃题材中，80 个反复活跃，占 58.4%。

## 8. 专题一：反复题材跨段换龙

### 8.1 分母

- 反复题材：80。
- 行情段：736。
- 第二段及以后非空段首前三槽位：1,854。
- 曾进入段首前三的去重“题材×股票”组合：1,480。

### 8.2 槽位连续性

- 紧邻上一段连续：281 / 1,854 = 15.156%。
- 在任一更早段出现过：597 / 1,854 = 32.201%。
- 新龙槽位：1,257 / 1,854 = 67.799%。

“新龙”指该股票未在同一原始题材任何更早段的段首前三出现，不代表新上市或全市场第一次活跃。

### 8.3 去重股票持续率

- 至少跨两段进入前三：375 / 1,480 = 25.338%。
- 始终为龙1：64。
- 做过龙1且发生龙位移动：181。
- 始终只在龙2/3：130。

结论：跨段持续的旧龙存在，但多数持续龙会换位；后续段的前三仍以新股票为主。

## 9. 专题二：单轮多日题材的 t−T 换位

母体为全部10个单轮多日题材，不按结果选案例。T为行情段开始日，`tau_trade`按全市场交易日递增。

T+1：

- 可观察题材 n=10。
- T日龙1仍是龙1：4/10 = 40.0%。
- T日龙1仍在前三：6/10 = 60.0%。
- T日龙2/3仍在前三：4/19 = 21.05%。
- 至少一个T日龙2/3晋级龙1：1/10 = 10.0%。
- 当日前三可用槽位中，新股票：15/25 = 60.0%。

T+2只剩3个题材：龙1守位33.3%，龙2/3保留20%，新股票占71.4%。由于分母过小，不外推总体规律。

一季报增长持续18个交易日，段首前三为东山精密、百龙创园、香农芯创；冻结日为2026-04-14，冻结前三已变为博云新材、协创数据、腾远钴业。该案例说明段首龙位、冻结龙位和日度龙位必须分开。

- 可精确映射并识别中军的行情段：70。

## 11. 678只龙股的收益口径

### 11.1 2026 YTD

从2026年首个可得交易日至2026-08-31复利。原 v0.1 统计：中位约0.1%，正收益比例50.0%，均值约21.5%，3只为部分年度样本。

### 11.2 研究区间收益

`100 * (product(1 + pct_chg/100) - 1)`，窗口为2025-10-30至2026-08-31，每只股票受自身可得交易日约束。

- n=678。
- 中位数：+7.1008%。
- 均值：+30.7455%。
- P25：−13.9692%。
- P75：+48.0444%。
- 正收益比例：58.5546%。

### 11.3 最低价到后续最高价

先由日收益建立累计收盘指数：

- `adjusted_high = close_index * high / close`
- `adjusted_low = close_index * low / close`

计算所有 `s <= t` 下 `100*(adjusted_high_t / adjusted_low_s - 1)` 的最大值。

- 中位数：+97.5589%。
- 均值：+141.9932%。
- P25：+61.1374%。
- P75：+163.2064%。

同日内高低先后未知，因此这是理想化“神抄底”边界。

### 11.4 最高价到后续最低价

计算所有 `s <= t` 下 `100*(adjusted_low_t / adjusted_high_s - 1)` 的最小值。

- 中位数：−53.4002%。
- 均值：−52.6273%。
- P25：−59.7884%。
- P75：−46.2594%。

同样是日线极端边界，不是策略可实现亏损率。
