# 方法与数据合同

本次是描述性市场环境研究。F1固定五模块衡量接力强弱；C0整理历史过程；既有theme-market-review-v2给出题材热度和结构，三者分别输出。没有连接策略收益，也没有交易、调仓、自动日更或永久解除数据冻结。2026年已经被项目研究使用。

## 版本与适用范围

| 版本 | 输入与意义 |
|---|---|
| B0-reference-parity-v1 | 相同旧parquet快照与五个原参考脚本；保留旧ST近似和股票自身行序昨日，仅作参考复现 |
| F1-formal-live-v1 | 修复LIVE数据、历史有效名称、市场交易日群体、局部缺失处理，重新冻结2025标尺 |
| C0-v1 | 在本次正式统计前冻结的探索性相位；不读未来结果，不根据策略收益调阈值 |

B0实算415个参考日期，显示精度下总分、档位、模块及主要计数全部一致。独立F1评分核心在B0原始指标上的最大模块差约1.5e-13（浮点误差）。F1与B0允许因实际修正而改变，不能限定只变9/10、9/11。逐日归因见`reference_to_formal_diff.csv`。

这轮按新执行书沿用参考的Q(M1raw)、Q(SQ)、Q(MIDfail)，不同于旧v0.4的自然比例直接乘100。旧v0.4及其114场景测试仍是原版本档案，本轮使用针对F1/C0真实边界的测试与全数据集成验收，不能混称为同一算法版本通过。

分析区间2026-01-01—2026-09-30；正式日期集合来自SSE官方交易日历，181日。2025年243日用于固定先验和标尺；2024年末用于前20日成交额、连板及周期预热。2025全年锚点应用于2025自身是回顾性标准化，不代表当年年初已知道这些锚点。

## 股票池、身份与日历

沪深A股代码前缀60/00/30/68，排除ST、明确特殊制度、上市前20个市场交易日，以及无法计算必需价格事件的个别行。第21个交易日起满足年龄条件。上市日期缺失记录排除，不赋予虚构的高年龄。

历史名称首先使用当日有效namechange区间：`start_date≤t`，且`end_date`为空或`end_date≥t`。同一边界重叠优先较晚起始区间，原始冲突留档；无法判明的实质冲突不静默吞掉。缺少历史名称时允许使用当日KPL名称或明确可识别的历史限价制度，单列降级来源和股票日分母。当前名称不冒充历史身份。

外部对账另建comparison池：沿用沪深范围、历史非ST与可核验价格制度，取消上市年龄排除，并剔除当日有效名称中含“退”的明确退市标记。该规则不改变formal主池；分别报comparison_delisting_excluded_n和两套计数，不能将外部表的差异全解释成计算错误。

F1连板仅跨相邻市场交易日，停牌后的首日重新计连续高度。昨日群体先由前市场日的合格涨停集合固定，再左连接今日。今日确证停牌、漏行情、可观测成员分别列出；不能先用今日记录筛选昨日群体。少量漏行局部排除并披露原分母与有效分母，不按失败填入。

## 事件与群体

价格比较按分四舍五入：`floor(price*100+0.5+1e-9)`。使用原始日线与原始限价，不能把前复权收盘与未复权限价混算。pre_close以标准10%/20%等限价规则一致性核验后使用；验证分母与特殊制度排除数分别登记。

正式制度识别同时核对名义5%/10%/20%的上、下两端限价按分舍入结果，不用固定涨幅区间近似排除低价股票。主板5%与10%若同时匹配，保留歧义并排除，不猜制度。旧比例区间只保留在legacy字段和归因路径中。例：前收0.24、涨停0.26、跌停0.22符合10%按分舍入，尽管实际涨幅8.33%小于旧近似区间下界。

价格质量还核对有限正值、OHLC内部上下界。昨日成员的今日收益要求价格与参考前收可核验；存在记录但不满足条件的成员单列unobservable，不混入停牌或漏行。成交额只汇总正且有限的原始amount；少量缺失单列覆盖率与partial标记，全缺保留NaN。覆盖分母是实际收到的沪深A日线行，不声称已经证明所有缺席证券都应有成交。

- U：收盘等于涨停价；Touch：最高价等于涨停价；Z：Touch且不是U；D：收盘等于跌停价；H2L：Touch且D。
- N为当日可计算的合格股票数；涨停/跌停密度均每千只。触板数=涨停数+炸板数。
- 梯队覆盖为1/2/3/4/5/6+六档的非空档数÷6；高度按当日已实现的连续涨停计算。
- M1分组：昨日1、2、3、4+板；成功是今日正常继续晋级。组内权重.25/.30/.25/.20。
- P为全部昨日合格涨停群体今日开/收盘相对参考前收收益；C为其中昨日高度≥2；开/收盘各占.4/.6。
- 高标H：昨日高度≥2的前三个不同高度，纳入所有并列股票；每只可观测股票等权，不能先按高度平均。选群体在匹配今日数据之前完成。
- 高标互斥优先级：H2L→0；其他跌停→0；正常晋级→100；收益≤−5%→15；−5%<收益<0→35；=0→50；>0→75。停牌/漏行不分配虚构收益。
- 炸板按今日触板股票的尝试高度分首板/2板/3+，权重.2/.3/.5。MID为昨日2—4板；失败是`收益≤−5% 或 D`并集，不重复计数。

事件和群体明细保存在本机大规模RUN中，发布包保留日度完整分母、必要审计样例和可再生成代码。

`missing_prev_cohort_n`统计没有当日价格且未按停牌表识别的成员，不自动意味着需要补写报价。独立`cohort_exceptions.csv`再用同一冻结基础表的delist_date解释终止上市等原因，保留原缺观测计数，不伪造报价或计作晋级失败。

## 先验、标尺与五模块

2025年同组先验固定为累计事件数÷累计样本数。主伪样本量a=5，平滑率`(k+a*p)/(n+a)`。自然空组n=0不当失败，不参与规定的组内加权。先验不以2026全样本更新。

`Q(x)=clip(100*(x−P10)/(P90−P10),0,100)`。P10/P90只取2025指标分布，线性分位数；不读策略收益。P90=P10时该项固定中性50并标记constant_anchor。

| 模块 | 公式 |
|---|---|
| M1 | Q(按规定权重合成的各晋级组平滑率) |
| M2 | .4P+.35C+.25H；P/C为开盘Q×.4+收盘Q×.6；H已在0—100，不再次Q |
| M3 | .4Q(BL)+.35Q(SQ)+.25[100−Q(Ddens)] |
| M4 | 100−Q(平滑MID失败率) |
| M5 | Q(log(今日全沪深A成交额/前20个市场交易日均额))；恐慌成立时封顶50 |

BL=涨停密度×梯队覆盖。SQ=1−按规定尝试高度权重合成的平滑炸板率。M2/M3内部仅按规定的可用部分重分配权重；正式外层必须五模块齐全。

恐慌同时满足：成交额比>1、合格股票收益中位数<0、且（跌停密度>0并≥2025 P90，或高标H2L至少1只）。负反馈来自价格，成交额仅提供放量前提。

`score5=(25*M1+20*M2+20*M3+15*M4+10*M5)/90`。分档用未取整分数：D[0,35)、C[35,50)、B[50,65)、A[65,80)、S[80,100]。相邻市场日变化≥2为上、≤−2为下，否则平；无可比较前日为UNKNOWN。

必要模块完全不可观测则保留日期、score5为空。`score_available`为独立诊断字段，`available_weight_sum`是原五模块权重中实际可用之和，不能将其无声代入正式序列或C0。题材缺口不阻断五模块。六模块未取得完整有效M6证据，本轮不强行生成、不按日切换。

截断表逐年逐项记录严格`x<P10`、`x>P90`的数量/有效分母，同时分别列`x==P10/P90`端点、标准化后0/100饱和以及缺失分母。不能把端点饱和全部称为超界截断。

## C0相位与研究统计

完整冻结规则见 [CYCLE_SPEC.md](../../../policyStudy/policy/speculation_sentiment_lite/config/CYCLE_SPEC.md)。只用正式score5、M1—M5、panic与截至当日历史。前5日最小/最大值不含当日；d5是与5个市场交易日前之差。按冰点、退潮、启动候选、修复、分歧、扩散、强势、中性/混沌顺序取首次命中。

历史窗口不足标预热，窗口中缺正式分则证据不足。日历缺口不跨越连接。相位不平滑、不用未来高点标顶部、不强迫阶段按圆圈推进。高强度并不自动等于即将见顶。

转移表分母为该起始状态、且下一相邻交易日也有效的边数。runs末端未结束的段右删失、开始落在区间边界的段左删失。事件表保存当日及后1/3/5市场日，完整性分别标记；事件重叠保留，同时报连续事件簇数。案例选择规则固定并留档，事后结果只用于案例选择与展示，不反写事件日相位。

phase_consecutive_days延续可用的2025历史；runs表只计报告区间的观测长度并标删失。年初案例的前五个市场日跨入2025，并补上对应题材上下文。feedback_lead_lag.csv列M4/高标反馈变化与前一日、同日、后一日及后三日总分变化的描述相关；两者本来参与总分，不能把同日关系写成预测能力。

a=2、10只改变指定收缩强度，沿用F1/a5先验比例、锚点、权重、档位及C0规则。报告分差、档位和相位变化，不搜索收益最优参数。

## 题材与人工对照的边界

题材前三热度按.5/.3/.2合成，再取截至当日最多120个交易日百分位。结构有主线明确、多主线、主线替换、热点分散无主线、热点低迷无主线五类；ST/次新题材排除。热度、结构和候选名称保留既有方法版本。算法按日期截断，并不证明原始KPL标签当日首发且之后未修订；历史分类字典也可能经过事后完善。最终episode结束日不进入情绪相位。

人工短摘录注明原对象、定位与时间属性。部分资料是周复盘或次日回顾；原文的题材S评级不当市场S评级。对照用于描述边界，不将原聊天当金标，也不将假想回测、私人交易故事或未核实收益数字写成实测结果。

`sentiment_daily.csv`包含日期、全精度score5/grade5/direction/delta1/delta5、M1—M5、panic、合格/排除/涨停/触板/炸板/跌停/连板数、最高板/梯队覆盖、晋级率、昨日开收反馈、中位失败、CNY成交额与20日比、质量原因、缺失群体、辅助分与可用权重、方法/校准/输入版本及可用性依据。

`cycle_daily.csv`独立保留phase、触发规则、标签、连续日数、d1/d5/lo5/hi5/breadth_up和证据质量。`environment_daily.csv`按唯一交易日一对一连接正式分、相位与题材，供下游账本使用。

`information_cutoff`指t日收盘。`available_at_basis`为收盘后研究约定，不虚构供应商精确首发时刻。用于t+1准备，不能用于t日上午入场；严格策略回测还须验证`available_at≤decision_time`。
