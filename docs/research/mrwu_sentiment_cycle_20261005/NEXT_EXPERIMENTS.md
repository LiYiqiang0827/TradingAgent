# 下一轮三项环境增量实验（本次未执行收益检验）

本研究只冻结环境特征。2026年1—9月已经被项目反复研究，以下登记草案不能将它重新包装为盲测。每项在连接账本前另存正式登记版本，明确新增验证区间、唯一主要统计量、允许的尝试次数和失败条件。环境算法不根据收益重新调参。

## 1. 首板次日早盘强度

- 固定已有策略的候选、入场、退出、费用、可成交与跳过规则，不重跑参数搜索。
- t日收盘环境用于t+1入场；必须满足available_at≤decision_time。四个对照为无环境过滤、单一昨日涨停反馈、单一晋级率、综合score5。单指标分组使用相同日期比例，避免仅因筛选数量不同得到优势。
- 主要结果变量：按入场交易日聚合的平均净收益；同时报告尾部亏损、候选/成交/无法成交/取消/未平仓的完整分母。先按日期聚合再分块推断，不把同日多股当作独立样本。
- 失败解释：综合分若不超过更简单指标，优先保留简单基准；若差异只由一个月驱动，不能推广为稳定环境过滤器。

## 2. 首次回调再启

- 固定既有首次回调事件定义和候选分母，区分紧平台、浅回调与深回撤修复；不把同一股票同一整理段多次触发当独立事件。
- 对照只按分数区间分组，与分数区间加C0相位分组。预先指定修复/退潮比较，控制月份、题材和重复事件簇。单组样本不足不事后合并出好看的结果。
- 主要结果变量：按固定交易规则得到的净收益分布；另列结构成功/失败标签，不能用事后最高价空间代替兑现收益。
- 失败解释：若相位没有新增解释力，保留它作历史描述；不调整C0阈值去救已见样本。

## 3. 情绪与题材结构联合分组

- 固定同一候选账本，比较情绪单独、题材单独、二者联合。题材仍使用历史主归因、截至当日窗口和质量标记，不使用最终episode结束日。
- 主要结果变量：交易日级净收益与尾部；检查整体较弱但局部主线清晰的候选，与同分但热点分散的候选是否不同。
- 控制组：等数量的简单情绪分组与单一题材热度分组；逐月、逐题材事件簇报告分母。
- 失败解释：联合分组若因样本稀疏而不稳定，结论是证据不足；若不优于单维度，减少复杂度。

通用时点限制：本次available_at_basis是收盘后研究约定，并未验证供应商逐条首发时间。若下一轮回测需要严格盘中可执行性，应补充相应时间证据；不将本报告收盘特征用于同日上午入场。
