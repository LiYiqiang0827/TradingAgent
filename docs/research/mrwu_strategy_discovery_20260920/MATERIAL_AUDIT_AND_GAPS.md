# 公开研究材料审计与缺口清单

审计日期：2026-09-20
审计对象：`mrwu_strategy_discovery_20260920` 公开研究包
用途：供李老师及其AI判断该包可以复核什么、不能复核什么、还缺什么

## 一、审计结论

当前公开包适合：

- 理解本轮研究目标、数据日期和因果时序；
- 阅读主要结果及其局限；
- 检查部分核心纯函数；
- 运行脱离私有数据布局的合成测试；
- 向另一套AI交代本轮发现、反证和方法边界。

当前公开包不适合：

- 在没有原始数据和生产stage的情况下逐笔复算全部结果；
- 证明168条线索已经全部开发；
- 证明完整“候选—板块—个股—买点—退出—组合”链路已经完成；
- 推导模拟盘或实盘交易指令；
- 计算真实账户年化收益、最大回撤和资金容量。

材料完整度结论：**方法复核可用，结果理解可用，完整生产复现不足，完整策略交接不足，实盘部署不可用。**

## 三、数字口径审计

### 早封板

公开报告正确保留了以下界限：

- 14,019是事件母体，不是无遗漏全市场认证。
- 裸0—5分钟早封H3平均净收益 `-1.211%`。
- 加前日all3后平均 `+0.943%`，日期等权 `+0.161%`，高摩擦日期等权 `-0.024%`。
- 成交收缩子组36笔、18日，属于同一开发期后验观察；不是独立样本外确认。
- 子组 `+4.042% / +3.627%` 采用固定H3退出，不是完整退出体系后的最终收益。

### 成本

公开包的基准/高摩擦成本定义清楚：

- 买卖各0.03%佣金，最低5元；
- 买卖各0.001%过户费；
- 卖出0.05%印花税；
- 基准每边0.10%滑点；
- 高摩擦每边0.30%滑点。

它们是研究假设，不是用户券商账单认证。

### 分钟、GPU、新闻和跌停

公开包正确声明：

- 分钟情景行高度重叠，固定展示的单机制闭合数很少；
- GPU的1,031,108个候选行不是独立策略，8个固定模型跨窗口不稳；
- 92,651条新闻记录多数为标题或短文本，不是92,651篇完整正文；
- 跌停等待研究是遇到跌停后的条件子样本，不是原策略总体收益。

## 四、发现的关键缺口

### P0：完整策略漏斗缺失

公开包没有一张可逐项追踪的完整表，将以下环节串在同一策略版本中：

`线索来源 → 候选母体 → 板块资金 → 梯队深度 → 个股图形 → 个股量价 → 分钟买点 → 初始止损 → 持有条件 → 止盈/失效 → 仓位 → 组合`

各环节的局部研究存在，但没有统一策略身份、版本和逐层增量结果。这是最主要的交接缺口。

### P0：退出体系缺失

主要收益仍来自H1/H3/H5固定退出。公开包说明了S01/S02/S03和跌停等待，但没有生产结果支持以下完整退出：

- 15分钟趋势＋图形双跌破；
- ATR/波动率初始止损；
- 板块退潮和梯队断裂；
- 龙头失位；
- 量价背离；
- 移动止盈；
- 分批退出；
- 结构、时间与市场状态的混合政策。

因此所有主收益都应理解为入场信号在固定观察窗口下的表现。

### P0：统一账户缺失

尚未完成：

- 同时出现多个候选时如何分配资金；
- 同股和同题材冲突；
- 共享现金与T+1库存；
- 真实公司行动账务；
- 部分成交、盘口容量和冲击；
- 组合级AR15/AR30风险路由；
- 可比的进攻、防守和现金净值。

所以不存在可以从本包诚实报告的统一年化收益或账户最大回撤。

### P1：168条线索到实验的映射不完整

本地存在168条线索的登记和路由材料，但公开包没有逐条公开：

- 原始想法；
- 可能的主策略/辅助角色；
- 是否完成操作化；
- 是否进入过生产实验；
- 使用了什么代理；
- 当前状态及未测原因。

因此公开包不能回答“策略库究竟覆盖了多少”。

### P1：板块梯队深度不完整

当前all3只有资金参与、上涨广度和相对活跃度。需要但尚未形成完整历史可用字段的内容包括：

- 首板、二板、三板及以上数量和比例；
- 最高连板与梯队断层；
- 封板、炸板、回封和修复；
- 龙头、次龙、后排的相对表现；
- 板块跌停和大幅回撤；
- 大成交承载与成员扩散；
- 这些字段在盘中何时真实可见。

### P1：完整生产复现不足

出于数据许可、安全和本地布局原因，公开包没有包含：

- 原始行情、分钟、新闻和供应商数据；
- 完整生产stage、研究控制面和私有适配器；
- 全部逐笔事件结果；
- 本地运行目录和日志。

这项缺失部分是有意的安全边界。若双方需要逐位复现，应先单独对齐数据schema、许可、交易日历、原始文件哈希和生产源码版本，而不是把数据直接提交到公开仓库。

### P2：外部数据的历史时点认证不足

若干历史字段的“何时发布、何时可被交易决策使用”仍未完全认证，特别是：

- 新闻正文与精确发布时间；
- 部分题材/概念成员变更；
- 资金流统计发布时间；
- 龙虎榜等盘后数据；
- KPL部分封板时间语义；
- 在线接口的市场时段新鲜度。

这些数据不是无用，而是必须明确只能从什么时点开始影响交易。

## 五、易误读表述审计

| 易误读说法 | 正确说法 |
|---|---|
| “已经回测168个策略” | 168项主要是线索、组件和辅助规则；没有全部发展为成熟策略 |
| “93个策略都失败了” | 93个旧日线代理未过门槛；不等于原始盘中想法被否定 |
| “all3就是板块资金和梯队深度” | all3只是资金参与、上涨广度和相对活跃度三个代理 |
| “早封策略平均赚4.042%” | 同一开发期后验成交收缩子组，在固定H3出口下36笔平均4.042% |
| “分钟策略已经大样本回测” | 数据缓存较大，但各固定机制真正闭合触发很少 |
| “GPU跑了百万样本所以模型可靠” | 百万是候选行；8个固定模型跨窗口方向不稳 |
| “新闻研究读取了九万篇完整文章” | 92,651条多数是标题或短文本，正文与发布时间不完整 |
| “结构止损已经解决退出” | 只做了日线S01/S02/S03初测；大量关键退出未进入主结果 |
| “测试全部通过” | 公开测试90项通过、1项因私有适配器明确跳过 |
| “Hermes在线等于后台持续研究” | 服务在线、模型运行和计算任务是不同状态；自动唤醒已删除 |
| “Kimi完成了GitHub操作” | Kimi只生成文本草稿；受控Git实际执行和核验推送 |
