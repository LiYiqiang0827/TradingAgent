# 方法论、数据口径与复现说明

## 1. 研究目标与治理

目标是在 long-only、无杠杆、允许持有现金的前提下，把策略库、用户与李老师的市场线索发展成可证伪的交易机制，并在单边万分之三佣金及明确交易摩擦下寻找绝对净收益。回测是策略发现的辅助，不是把含糊灵感包装成合格证。

研究分工：Python 承担数值计算；Kimi 只做可核验的文本整理或机械草稿；Codex 负责机制、因果时点、实验冻结、缺陷判断、独立验收和最终分级。Hermes 只启动已注册、源码哈希固定的研究阶段，没有任意 shell 或自动下单权限。本轮没有实盘交易。

每个实验遵循同一链条：

`线索 → 可用时点 → 冻结候选/参数 → 保留未知与失败 → Python 计算 → 独立重算/哈希验收 → 研究分级`

不得做的事情包括：以未来收益选择当时的板块或股票、用下一条股票记录代替全市场下一交易日、把缺失当零、把多个参数版本当独立成功、把事件均值冒充统一账户净值、把 2025/2026 已经看过的资料称盲测。

## 3. 日历、证券身份与清洗

### 3.1 交易日

所有“下一日”均指统一交易所日历的下一开放日，不是自然日，也不是某只股票的下一条记录。成交状态计算使用 2024-07-01 至 2026-08-31 的 528 个精确交易日：2024H2 为 125 日、2025 为 243 日、2026 年 1—8 月为 160 日。

### 3.2 中航成飞代码更名缺陷及修复

第一版严格深圳前缀规则遗漏了合法代码 `302132.SZ`。进一步检查发现源表还对更名前的 151 个交易日同时保存 `300114.SZ` 与 `302132.SZ`，六个 OHLC/vol/amount 字段逐日完全相同。若简单纳入全部 3xx 会重复成交额。

按深交所公告的 2025-02-17 生效日冻结唯一身份：此前只选 `300114.SZ`，当日及以后只选 `302132.SZ`；同日出现双码时，六字段必须完全一致才允许排除非生效别名，否则 fail closed。旧 v1 保留并拒收；v2 在前 151 日与 v1 金额相同，只补齐之后 377 日。v2 共保留 679 条别名原证据、排除 151 条完全相同别名、形成 528 个身份日。该处理只修正未复权成交额，不把重组或代码变更扩展成价格复权结论。

### 3.3 缺失、异常与未知

- 无效金额、缺市场、缺关键价格或未知 ST 一律标 UNKNOWN，不填 0。
- 未触发不是亏损；已入场但未闭合不进入闭合收益均值，另给胜率上下界。
- 欲卖日的关键观测未知时，退出路径立即变 UNKNOWN，不跳到后来价格伪造“首次可卖”。
- 分钟数据每个实际消费窗口都要求有限数值、正价格、可用性标记；未知未来点不能影响此前首次触发。
- 证券日重复、同身份冲突、分层内重复股票日直接拒绝，不做有利去重。

## 4. 成交活跃度四阶段

令 A(t) 为观察到的沪深 A 股当日成交额（CNY，排除北交所、B 股、基金；仍是 observed-universe proxy）。定义：

```text
M5(t)  = mean(A[t-4:t])
B60(t) = median(A[t-60:t-1])
R(t)   = M5(t) / B60(t)
G(t)   = M5(t) / M5(t-5) - 1
```

REL 水平状态带滞回：R≥1.10 为 HIGH，R≤0.90 为 LOW，中间沿用上一状态；首个有效点以 R≥1.0 决定 HIGH/LOW。ABS2T 对照以 M5≥2 万亿元为 HIGH。原始相位优先级：G≥5% 为 RISING，G≤−5% 为 RETREAT，否则 HIGH→ACTIVE、LOW→INACTIVE。相位改变需连续两个有效交易日确认；缺失会清空水平、确认态和 pending 状态，并重新积累完整窗口。

D 的 confirmed phase 是收盘后标签；盘中事件只可使用前一交易日的 `decision_phase/level/coverage`。早封事件因为本身在 D 收盘后才完整确认，可用 D confirmed phase 研究 D+1 入场。RISING/RETREAT 是成交额趋势，不是股价涨跌；ACTIVE/INACTIVE 是趋势不明显时的成交水平。

v2 独立重算 1,056 行（528 日×REL/ABS2T），全部哈希、公式、两日确认和前日 shift 无差异；官方交易所总额尚未独立对账。

## 5. 早封板持续性与次日交易代理

母体先选 D 收盘原价等于涨停价的股票日，不用原策略 eligible 掩码预筛。时间分组互斥：09:30 及以前、(09:30,09:35]、(09:35,09:40]、09:40 后、未知；0—10 分钟汇总是嵌套统计，不能当独立样本。

持续性描述计算 D 收盘到 D+1/D+3/D+5 的复权收益、路径最低点、后续涨停收盘次数与首次断板；它不声称能在 D 收盘买到。

交易代理在 D 收盘后形成信号，D+1 开盘尝试买入，固定 H1/H3/H5，在 entry+hold 的开盘尝试卖出，最早 D+2。涨停或滑点越界不假设买到；卖出遇跌停最多向后 10 个交易日；关键观测未知立即终止为未知。核心函数见 `code/early_limitup_returns.py`。

同伴 all3 为：前一交易日同伴五日资金流比率 >0、上涨广度 >0.5、相对活跃度 >1，三者同时通过。至少三个有效同伴且覆盖≥80%；候选自身从同伴统计排除。`postclose_all3` 使用 D 收盘信息，只供 D+1；不能倒称 D 早盘已知。

### 5.1 费用

固定事件名义金额 100,000 元，仅用于使最低佣金可计算：买卖各单边佣金 0.0003、最低 5 元；买卖两边均收过户费 0.00001；卖出另收印花税 0.0005；基准每边滑点 0.001、压力每边 0.003。净事件收益由复权比例价格核扣除适用费用。没有真实整手、排队、容量、部分成交或分红送股现金账，故是事件价格代理。

## 6. 分钟候选机制

20 张机制卡是策略假设，不是 20 个完成回测的策略。首批实际计算了原 8 张及新增 4 张；全部使用前日冻结板块、两个锚定股和排名候选，不可按当日赢家重选。

分钟点位扫描 stride 为 1 或 5；代理入场延迟为 1 或 3 点；退出是下一交易日固定点位版本；基准/压力费用分别保留。46,080 与 23,040 是相关情景行，不是独立交易笔数。

新增四张的冻结含义：

- M03：锚定股先领先并进入窄幅高位平台，板块广度和候选参与度上升，候选仍落后锚定股后突破自身近五点高位。
- M04：候选前日站上 MA20 且动量弱于锚定股，平/低幅开盘；双锚同步为正并高于自身近五点均值，板块扩散，候选放量突破。
- M16：午前板块已有上涨且候选未深回吐；午后板块、广度再扩张，候选放量突破午前末段高位。
- M17：候选先推进，随后十点窄幅缩量，在板块不弱时放量突破；滚动窗口均严格排除当前点。

M11 检验“旧龙头温和休息、次龙相对换位”：锚定股近十点窄幅且未明显回撤；候选相对板块收益和成交参与在 t−10、t−5、t 连续增强，板块广度不下降，且候选跑赢至少一个平稳锚定股。入场前锚定状态失效即取消。

这些点位代理不包含盘口队列、真实 VWAP、逐笔成交或真实资金流，样本也很稀疏，因此现阶段均不能据此部署。

## 7. GPU 排序研究

固定设计为 2 组特征（价格+市场状态；再加前日板块资金/参与）×2 目标（五日净收益回归、净盈利分类）×2 树深（3/5），共 8 个模型，每个 300 棵树；另有同池 20 日动量基线。

2025-01—06 训练，训练标签退出必须不晚于 6 月 30 日；07—08 为开发评价，09—12 为后段诊断。T 收盘产生 X，T+1 开盘入场代理、T+6 开盘退出代理。缺未来价、ST 未知或涨跌停不可成交仍留在排名母体，以未知/阻塞状态报告，不能先删后算收益。

实际 CUDA 复验：8 模型、1,031,108 候选行、461,821 训练行，53.8 秒。7—8 月和 9—12 月排序表现方向不稳定，因此这 8 个固定规格没有晋级；不据此否定 GPU/机器学习本身。

## 8. 新闻过程研究

新闻从声称发布日期严格推迟到下一交易日，因为历史发布时间未认证。字符 2/3-gram 固定哈希到 16,384 维，不学习全样本词表；每主题只与严格更早可用日的最近 20 交易日、最多 256 条向量比较。词面“新增”仅指在前 20 日集合中未见的订单/交付/业绩/政策词，不代表事实已核实。最终产物为432个描述性汇总格。

缺采日记为 `MISSING_COLLECTION_UNKNOWN`；1—19 篇或低于此前 20 日观察中位数20%（至少5日历史）记 `SPARSE_COLLECTION_UNKNOWN`；其他也只是 `OBSERVED_COLLECTION_UNCERTIFIED`。新闻叠加仅做四类描述：信息累积、词面升级、重复叙事+资金回落、负面词后的承接；保留 ALL_BASE/WITH/WITHOUT/UNKNOWN，结果不能作新闻因果效应。

## 9. 跌停后等待反弹压力试验

只对已经遭遇确认跌停的条件子样本，比较立即想卖 R0 与最多等待 3/5/10 日的 R3/R5/R10。等待期内若收盘相对事件以来最低复权价反弹≥5%，次日开始锁定卖出意图；一旦进入 WANT_SELL，跌停阻塞继续等待，未知关键观测使路径 UNKNOWN。状态机见 `code/rebound_state_machine.py`。

该研究有 572 个完整跌停暴露、155 个“股票—首次跌停日”簇。事件均值略改善但簇等权改善很小，最坏路径反而由 −29.09% 扩到 −49.53%，所以“不恐慌、总会反弹”没有获得支持。

## 10. 统计量与分母

每个格子至少保留候选数、入场数、闭合数、W/L/Z、未决、未知、日期数、独立股票/股票日数。闭合事件净均值为：

```text
mean_net = mean(r_i for closed i)
win_rate = W / N_closed
avg_win  = mean(r_i | r_i > 0)
avg_loss = mean(r_i | r_i < 0)
payoff   = avg_win / abs(avg_loss)
PF       = sum(positive r_i) / abs(sum(negative r_i))
date_balanced_mean = mean_date(mean_event_on_date(r_i))
```

若 N_closed=0 或没有亏损，不虚填盈亏比。闭合样本 0—4 或闭合日期<5 明示薄证据。另报告 median、worst、p05、亏损≥15%/30%数量。未决不塞进均值，同时给 all-entered 胜率上下界。多个持有期、成本、扫描 stride、入场延迟、退出点、REL/ABS2T 都是相关版本，不可相加成成功次数。

## 11. 独立验收与幂等

每个生产包有预注册清单、输入/源码/输出 SHA-256、固定输出集合和 ACCEPTANCE。旧包只在 manifest 与全部文件哈希完全一致时幂等复用；部分包、源变动、重复键或超限都会失败，不自动覆盖。原始数据库保持只读。

关键验收包括：

- 市场活跃度 v2：1,056 行独立重算，0 findings；151 日重复别名与之后 377 日漏计按有效日修复。
- 活跃度叠加：495,442 分配行、4,800 主统计格、2,292 all3 辅助格；21 个输入/输出哈希、时点与逐格算式独立一致。
- 早封：14,019 母体、84,114 交易情景、42,057 描述情景，10 个产物哈希与全汇总独立核对。
- 原8/新增4分钟：全部事件/费用算式、场景键和相关重叠审计保留；不把情景行当独立交易。
- GPU ST 修复：只允许两个 ST 状态列改变；37 个 GPU 输出哈希通过。
- 跌停等待：4,580 个确认路径/费用案例重放一致。

## 12. 复现边界和运行方法

环境依赖见 `requirements.txt`。随包 `code/` 是本轮实际核心纯函数快照，`tests/` 是可脱离本地数据布局运行的相应测试；它们不读取本机目录、不访问网络、不含密钥。`early_limitup_returns.py` 为逐行审计快照，但依赖未公开的退出 stage，因此公开测试不导入它；分钟核心有一项依赖私有 stage adapter 的集成测试显式 skip。完整生产 stage 依赖未公开的原始数据布局和研究控制平面，因此本包只能复现公式与合成测试，不能在没有原数据时重建每笔结果。

建议审阅方执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python run_tests.py
.\.venv\Scripts\python verify_package.py
```

POSIX 等价命令：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run_tests.py
.venv/bin/python verify_package.py
```

`verify_package.py` 只校验随包文件哈希，不下载数据、不访问凭据。若要完全复算，应由双方先对齐数据 schema、供应商许可、交易日历与 content hash，再运行同一源码版本；不得用后来更新的数据声称逐位复现旧结果。

## 13. 本轮能与不能得出的结论

当前唯一 B 级线索是早0—5分钟封板+前日 all3、H3 次日入场代理；全体逐事件均值 +0.943%，日期均衡仅 +0.161%，压力日期均衡 −0.024%。在 REL 成交收缩格中，基准/压力同一 36 个闭合事件、18 日，净均值 +4.042%/+3.627%，日期均衡 +2.944%/+2.533%，最差 −11.738%/−12.090%，各仍有1笔未决。但该状态是同一开发期后验观察，不能叫样本外确认或稳定策略。

A 级为空。裸早封次日入场、无条件跌停等待和 8 个固定 GPU 规格有负面或不稳证据；M11 与新增四分钟机制样本过少；新闻尚无股票账户增量证明；统一组合会计和 P2 未知主题风险修正未完成。不得据本包自动启动模拟盘或实盘。
