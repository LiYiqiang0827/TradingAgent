# 自我反省与研究纠偏说明

日期：2026-09-20
作者：主 Codex
对象：MrWu、李老师及双方 AI

## 一、为什么需要这份反省

本轮工作的原始任务不是“拿一批成熟策略做合格性回测”，而是进行策略发现：把策略库、用户与李老师的想法、市场材料和数据线索，发展成有经济解释、能够交易、扣除成本后可能取得绝对收益的完整策略。

用户反复强调的方法是：

1. 所有想法首先只是候选生成线索，不是成熟策略。
2. 用板块资金流、板块量价共振和梯队深度判断候选之间谁更值得交易。
3. 再看个股角色、图形、量价和分钟级买点。
4. 买入以后必须有与逻辑一致的止损、持有、止盈和失效判断。
5. 最后才进入仓位、市场状态和统一组合。

这套目标在研究框架中其实写得相当清楚。但实际执行逐渐偏向了容易批量化、容易审计的固定持有期和分散因子试验，没有始终围绕完整策略链路组织工作。因此产生了大量可靠的局部证据，却没有交付用户真正需要的完整策略。

这不是“结果不好”本身的问题，而是研究问题被执行过程缩窄了。

## 二、我做对了什么

反省不应抹掉已完成的有效工作。以下基础工作有价值，并应保留：

- 所有生产计算通过受控研究工具运行；原始数据库保持只读。
- 关键实验保存输入、源码和输出哈希，失败版本与未知状态没有被覆盖。
- 对未来信息、缺失值、涨跌停不可成交、ST状态和T+1做了明确限制。
- 早封板、分钟机制、市场成交状态、GPU排序、新闻过程、结构退出和跌停反弹都留下了可复核证据。
- 没有把负结果删除，也没有把未决交易填成零收益。
- 已经纠正过市场代码更名、Kimi草稿错误、新闻正文覆盖、ST历史和若干时序问题；对应实验状态见`EXPERIMENT_AND_RESULT_LEDGER.md`，公开源码身份见`SOURCE_MANIFEST.md`。
- 没有实盘交易，没有把用户的15%/30%研究回撤预算冒充损失保证。

这些工作使后续研究不必从零开始。但基础可靠不等于研究目标已经完成。

## 三、主要错误

### 1. 把策略发现做成了机械回测

旧日线波次运行了93个代理配置，第一轮发现又运行12个方向、36组排序/环境规则和108个持有期实验。数字很多，但其中相当部分回答的是：

> 某个固定候选定义，在固定持有1/3/5/10日时，历史平均收益怎样？

用户真正的问题则是：

> 怎样从线索形成候选，怎样判断板块是否值得参与，板块中买谁，什么时候买，逻辑何时失效，什么时候继续持有，什么时候退出？

前一个问题是后一个问题的一个诊断步骤，不能代替完整策略开发。执行过程中我让可批量计算的问题占据了研究主线。

### 2. 把零件分别测试，却没有串成完整漏斗

本轮确实分别涉及：

- 策略/形态候选；
- 板块资金参与；
- 上涨广度和相对活跃度；
- 龙头、次龙与同伴排名；
- MA20、平台、突破、缩量和放量；
- 分钟级相对换位；
- 市场成交状态；
- 固定持有期、少量结构退出和跌停等待。

但没有用同一批候选完成以下逐层可归因对照：

`原始候选 → 板块资金流 → 梯队深度 → 个股图形 → 个股量价 → 分钟买点 → 止损/持有/止盈 → 组合仓位`

因此我们知道若干部件可能有用，却不知道把它们合起来以后是否形成一套可以赚钱的交易模式。

### 3. 把粗糙代理当成了用户所说概念的近似完成

早封研究中的 `all3` 只表示前一交易日：

- 5日资金参与代理为正；
- 同伴上涨广度超过50%；
- 相对活跃度超过1。

它不是完整的板块梯队深度。它没有完整描述首板、二板、三板及以上数量，最高连板、炸板与修复、龙头封板质量、次龙承接、后排扩散、跌停数量或梯队坍缩。

同样，分钟点位不是逐笔成交、真实VWAP或盘口排队；新闻记录多数是标题或短文本；供应商资金流是交易分类估计，不等于资金意图。这些代理可以用于发现线索，但不能被写成完整机制已经得到验证。

### 4. 退出研究没有成为策略的一半

主要结果仍以H1/H3/H5固定开盘退出为主。固定期限作为基线是必要的，因为它能回答信号在不同时间窗口是否具有方向优势；但它不是完整交易方法。

本轮只对以下日线结构退出做了初步比较：

- S01：收盘跌破首板日低点；
- S02：收盘跌破首板实体下沿；
- S03：收盘跌破平台上沿；
- 触发后下一交易日开盘退出，否则最迟H10。

同一事件配对中，它们相对H10的平均改善仅约0.04—0.14个百分点，而且覆盖子集有限。更重要的是，下列用户明确关心的退出没有进入主要策略结果：

- 15分钟趋势线与图形双跌破；
- 初始结构止损；
- ATR/波动率止损；
- 板块资金退潮和梯队断裂；
- 龙头失位；
- 量价背离；
- 移动止盈；
- 加速衰竭；
- 分批退出；
- 时间止损与结构退出的组合。

因此当前最强线索的 `+4.042%` 只是固定H3出口下的开发期结果，不是完整策略的最终收益。

### 5. 把任务数量和数据规模混同为研究覆盖

以下数字说明做过工作，但不能说明完成了多少成熟策略：

- 93个旧日线配置；
- 168条策略库线索；
- 12个方向、36组规则、108个持有期实验；
- 14,019个早封股票日；
- 45个分钟板块组和777个成员；
- 1,031,108个GPU候选行；
- 92,651条新闻标题或短文本。

93个代理全部未通过旧门槛，不等于168条原始线索全部失败；大量重叠参数情景也不等于大量独立策略。先前报告虽然多处写过这些限制，但整体呈现仍容易让读者产生“已经大规模覆盖策略库”的印象。

### 6. 报告服务了审计，却没有先服务判断

第一份报告包含大量状态、分母、哈希、未知和限定语，这些对审计很重要，但用户首先需要的是能够形成判断的材料：

- 到底测了什么？
- 没测什么？
- 平均收益、胜率和盈亏比是多少？
- 结果为什么会这样？
- 哪一部分值得继续？
- 完整策略还缺哪几环？

我把审计材料与决策材料混在了一起，导致技术上谨慎、实际难读。后来补写易读报告才纠正这一点。

### 7. 没有始终遵守正确的分工

正确分工应当是：

- 主Codex负责策略构思、实验拆解、关键判断、困难调试和最终验收；
- Kimi负责有界、可核验的机械整理、分类和草稿；
- Python负责规模化计算；
- 用户负责最终实盘、重大风险和不可逆授权。

执行中出现过主模型承担过多机械审计、GPT子代理规模偏大、以及把“Kimi可协助”说得像“Kimi拥有本地工具”的风险。Kimi实际上是无文件、无终端、无GitHub工具的文本工作者。Git推送必须由受控Git完成，不能冒称由Kimi亲自操作。

### 8. 对“持续工作”的表达不够严谨

自动唤醒已经按用户要求删除。Hermes服务保持可用，不等于研究计算持续运行；没有活跃计算时，不应把定期检查或服务在线描述成后台高强度研究。后续交接必须区分：服务在线、任务排队、模型运行和本地计算是四种不同状态。

## 四、已有结果应怎样重新理解

### 早封板线索

裸0—5分钟早封、次日入场、H3固定退出，平均净收益为 `-1.211%`。

加入前一交易日all3后：

- 111笔闭合；
- 平均净收益 `+0.943%`；
- 日期等权 `+0.161%`；
- 高摩擦日期等权 `-0.024%`。

再按同一开发期资料事后观察成交收缩状态：

- 36笔闭合，覆盖18个日期，另有1笔未决；
- 基准/高摩擦平均净收益 `+4.042% / +3.627%`；
- 日期等权 `+2.944% / +2.533%`；
- 胜率 `63.889%`；
- 盈亏比 `1.645 / 1.476`；
- 最差单笔 `-11.738% / -12.090%`。

正确结论是：板块环境可能显著改善早封候选质量，成交收缩时的相对题材需求值得冻结后验证。错误结论是：已经找到单笔预期4%的成熟策略。

### 板块排序和日线候选

第一轮发现中：

- 板块资金持续＋板块排序＋环境：1,792笔闭合，基准 `+0.384%`，高摩擦 `-0.017%`；
- 强势股延续＋板块排序＋环境：1,522笔，`+0.368% / -0.032%`；
- 月日线结合＋板块排序＋环境：1,401笔，`+0.007% / -0.392%`；
- 简单突破＋板块排序：2,793笔，`-0.981% / -1.376%`。

正确结论是：板块辅助对部分候选有增量，但现有优势普遍不足以覆盖较差成交。错误结论是：板块资金无效，或者加上板块排序就已经完成用户的方法。

### 分钟机制

M03/M04/M11/M16/M17确实表达了平台、锚定龙头、次龙换位、广度扩散、MA20、缩量和放量突破等想法。但固定展示切片只有0—20笔闭合，多数只覆盖少数日期。它们证明了机制可以被代码表达，不证明机制已经赚钱。

### GPU、新闻和跌停等待

- 8个固定GPU模型跨2025年不同窗口方向不稳，不能通过事后切换模型拼成策略。
- 新闻语料尚未形成可靠股票账户收益结论，正文和历史发布时间仍不完整。
- 无条件等待跌停反弹平均改善很小，极端亏损扩大，不能形成“跌停不要止损”的通用规则。

## 五、纠偏后的研究对象

从下一轮开始，“策略”必须是一张完整生命周期卡，而不是只有入场条件。每张卡至少包含：

1. **来源**：对应哪条库内线索、用户/李老师想法或外部研究。
2. **经济机制**：为什么这种行为可能持续产生收益。
3. **市场环境**：在哪种成交、指数、风格和题材阶段启用。
4. **候选生成**：何时、从什么母体产生候选。
5. **板块判断**：资金参与、量价共振、梯队深度和角色状态。
6. **个股选择**：龙头/次龙/补涨/容量角色，图形、量价和相对强弱。
7. **入场**：分钟级触发、确认、成交代理和放弃条件。
8. **初始风险**：结构失效位、T+1隔夜风险和预计损失。
9. **持有逻辑**：继续持有必须满足什么。
10. **退出**：止损、止盈、结构双跌破、板块/龙头失效和最大时间。
11. **仓位**：个股、题材和全账户风险如何分配。
12. **反证**：什么结果说明该机制应暂停或废弃。

缺少上述关键字段的项目只能叫“信号研究”或“数据诊断”，不能叫完成策略。

## 六、纠偏后的实验结构

### 1. 固定候选的逐层增量实验

对同一候选、同一入场时间和同一资金预算比较：

- A：原始候选；
- B：A＋板块资金流；
- C：B＋梯队深度；
- D：C＋个股图形；
- E：D＋个股量价；
- F：E＋分钟买点。

保存被每一层过滤掉的候选作为影子样本，才能判断该层究竟提高了选择能力，还是仅减少交易。

### 2. 固定入场的退出实验

在完全相同的入场交易上比较：

- 固定H1/H3/H5/H10基线；
- 初始结构止损；
- ATR/波动率止损；
- 板块资金与梯队失效；
- 龙头失位；
- 15分钟趋势＋图形双跌破；
- 移动止盈和加速衰竭；
- 时间止损；
- 上述规则的预注册混合版本。

触发必须只用已结束的K线和当时可见数据，成交使用下一可成交点；绝不使用当日最高价或最低价作为理想退出。

### 3. 最后才做统一组合

只有单策略生命周期形成后，才研究：

- 共享现金；
- 同股、同题材和同风险因子冲突；
- AR15/AR30两种研究预算；
- 进攻、防守和现金切换；
- 仓位、容量、滑点和无法成交；
- 公司行动和真实账务。

不能把若干独立事件均值相加成组合收益。

## 七、纠偏后的报告标准

以后每份主报告按以下顺序：

1. 一页结论：找到什么、否定什么、还缺什么。
2. 完整策略链路图：每一环是已测、代理还是未测。
3. 主结果：样本、日期、平均净收益、日期等权、胜率、盈亏比、最差交易和未决。
4. 归因：板块、图形、量价、买点和退出各自增加了什么。
5. 失败与尾部：不能只展示正向子组。
6. 可执行性：T+1、涨跌停、容量、滑点、公司行动和账户约束。
7. 明确状态：信号研究、B级待证、确认候选或统一账户验收。

测试通过、哈希一致和任务完成只能证明工程过程可靠，不能替代策略结论。

## 八、当前责任结论

本轮没有完成用户要求的完整策略发现系统。完成的是一批有审计价值的局部实验、数据能力和反证。

目前最有价值的线索仍是“早封候选＋前日板块条件＋成交收缩环境”，但它缺少完整梯队深度、个股图形量价排序、盘中买点、结构化退出和统一账户验证。它只能作为下一轮完整策略开发的起点。

我应承担的纠偏责任不是把已有数字包装得更好，而是确保下一轮所有计算都服务于完整交易逻辑；如果一项任务不能减少对“选什么、何时买、何时持有、何时退出、买多少”的不确定性，就不应因为容易计算而占据主线。
