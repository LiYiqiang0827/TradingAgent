# MrWu 策略发现研究：方法、数据与可复核代码包

版本标记：2026-09-20（Asia/Tokyo）。文中所有 A 股交易时钟、封板时间和分钟点位均为 Asia/Shanghai；交易日日期在两地相同。

本目录供李老师及其 AI 审阅本轮策略发现工作。它回答的是“我们用了什么数据、何时可见、如何计算、哪些结果真的跑过、哪里失败、怎样复核”，不是收益宣传材料，也不是自动实盘系统。

建议阅读顺序：

1. `ORCHESTRATION_INCIDENT_POSTMORTEM_20260920.md`：供第三方接管者阅读的事故复盘，说明 Token 消耗、编排失误、用户持续加入研究灵感时的变更管理缺陷、定期唤醒问题，以及下一版强制架构。
2. `PLAIN_LANGUAGE_RESULTS_REPORT.md`：面向普通读者的结果报告，直接说明测了什么、没测什么、平均收益、胜率、盈亏比和当前结论。
3. `SELF_REVIEW_AND_CORRECTION.md`：主Codex对本轮研究偏差的反省、完整策略漏斗与后续纠偏标准。
4. `MATERIAL_AUDIT_AND_GAPS.md`：审计本包能复核什么、不能复核什么，以及完整交接仍缺的材料。
5. `METHODOLOGY_AND_REPRODUCTION.md`：完整研究设计、数据日期、公式、时序和验收流程。
6. `EXPERIMENT_AND_RESULT_LEDGER.md`：每项工作的状态、实际样本、主要结果和局限。
7. `SOURCE_MANIFEST.md`：随包 Python 源码与测试的 SHA-256。
8. `code/` 与 `tests/`：本轮已运行计算的核心纯函数及相应测试快照。

状态定义：

- **已运行并复核**：实际产物存在，哈希与独立算式通过复核；仍不自动等于可交易。
- **研究代理**：使用事件价格、点位时钟或不完整成交模型；可发现线索，不能当账户收益。
- **仅设计／暂停**：有机制或纯函数准备，但没有完整生产结果。
- **拒收保留**：发现口径缺陷后保留原版本作为审计证据，不覆盖或删除。

本包刻意不包含：原始行情或新闻、访问密钥、OAuth、cookie、用户目录、Hermes/Codex 认证、可下单接口、真实账户信息。所有本地绝对路径已从公开材料中移除。

核心判断不是“找到了成熟策略”。当前 A 级（独立模拟盘准入）为空；唯一 B 级探索线索是“0—5 分钟早封、前日 all3 同伴条件、H3 次日入场路径”，其中成交量收缩状态表现较强，但这是同一开发期资料中的后验分层，必须冻结后在新的未暴露日期确认。
