## 1. 下载后,移动到这两个目录

从百度网盘下载 7 个 db 文件,移动到 `~/TradingAgent/` 下的两个目录:

| 目标目录(相对项目根) | 文件数 |
|---|---|
| `offlineDataManager/data/` | 6 个 |
| `onlineDataManager/data/` | 1 个 |

## 5. 命令行操作(批量移动)

假设你下载到了 `~/Downloads/`,一行命令搞定:

```bash
cd ~/TradingAgent

# 6 个离线 db
mv ~/Downloads/db_cn_basic.db      offlineDataManager/data/
mv ~/Downloads/db_cn_kpl.db        offlineDataManager/data/
mv ~/Downloads/db_cn_index.db      offlineDataManager/data/
mv ~/Downloads/db_cn_news.db       offlineDataManager/data/
mv ~/Downloads/policy_minute.db    offlineDataManager/data/
mv ~/Downloads/policy_ticks.db     offlineDataManager/data/

# 1 个实时 db
mv ~/Downloads/online_data_*.db   onlineDataManager/data/
```

或者一键:

```bash
cd ~/TradingAgent
mv ~/Downloads/db_cn_basic.db ~/Downloads/db_cn_kpl.db ~/Downloads/db_cn_index.db \
   ~/Downloads/db_cn_news.db ~/Downloads/policy_minute.db ~/Downloads/policy_ticks.db \
   offlineDataManager/data/
mv ~/Downloads/online_data_202609.db onlineDataManager/data/
```

## 6. 验证放对位置

```bash
cd ~/TradingAgent

# 列出 7 个文件
ls -lh offlineDataManager/data/*.db onlineDataManager/data/*.db

# 期望看到 7 个 .db(7 行)
# 预期大小见第 4 节表格
```

如果行数不对 → 漏文件 / 路径错 / 名字大小写错。

---

## 7. 为什么是这个路径?

代码里 `offlineDataManager/scripts/config/settings.py` 硬编码了这些路径:

```python
DB_PATH_BASIC = Path(__file__).parent.parent.parent / 'data' / 'db_cn_basic.db'
# 实际路径: ~/TradingAgent/offlineDataManager/data/db_cn_basic.db
```

**所以 db 放错位置 = 代码找不到 db = 报错**。

详见 `数据库使用须知.md` 第 3 节。
