# 初始化系统环境变量

本项目所有**敏感凭据**和**项目根路径**都通过 shell 环境变量注入,**严禁硬编码到代码或配置文件中**。

## 必须设置的环境变量

把以下两行加到 `~/.zshrc`(或 `~/.bashrc`,取决于你的 shell):

```bash
# 项目根目录(所有脚本从这里推算路径)
export TRADE_AGENT_ROOT_PATH=~/TradingAgent

# Tushare Pro API token(去 https://tushare.pro/user/token 申请 / 重置)
export TRADING_AGENT_TUSHARE_TOKEN=<your_tushare_token_here>
```

加完后:

```bash
source ~/.zshrc   # 或新开一个终端窗口
```

## 验证

```bash
echo $TRADE_AGENT_ROOT_PATH          # 应输出 /Users/<你的用户名>/TradingAgent
echo ${TRADING_AGENT_TUSHARE_TOKEN:0:10}...  # 应输出 token 前 10 位
```

如果两个命令都正常输出,说明环境变量已经生效。

## 在项目里怎么读

### `TRADE_AGENT_ROOT_PATH` — 项目根路径

```python
# 任何脚本里:
import os
from pathlib import Path

def _get_root() -> Path:
    env = os.environ.get("TRADE_AGENT_ROOT_PATH")
    if env:
        p = Path(env).expanduser().resolve()
        if not p.exists():
            raise RuntimeError(f"TRADE_AGENT_ROOT_PATH={env} 不存在")
        return p
    # fallback: 脚本位置推算
    return Path(__file__).resolve().parents[N]  # N 视脚本深度而定

ROOT = _get_root()
```

注意:**协作者 clone 仓库后必须设这个变量**;不设也能跑(fallback 推到项目根),但设了更稳。

### `TRADING_AGENT_TUSHARE_TOKEN` — Tushare Pro API token

```python
import os

TUSHARE_TOKEN = os.environ.get("TRADING_AGENT_TUSHARE_TOKEN", "")

if not TUSHARE_TOKEN:
    import warnings
    warnings.warn("未设置 TRADING_AGENT_TUSHARE_TOKEN,Tushare API 调用会失败")
```

**注意:**
- ✅ 必须从环境变量读,**严禁**写进 `tushare_config.py` 或任何 .py 文件
- ✅ **严禁** commit 到 Git 仓库
- ✅ 如果误提交,立刻去 tushare.pro **重置 token** + 用 `git filter-branch` 清历史 + `git push --force`

## 协作者加入项目

新协作者收到 GitHub 邀请后,**第一件事**就是设置这两个环境变量。然后:

```bash
git clone git@github.com:LiYiqiang0827/TradingAgent.git
cd TradingAgent

# 1. 设置环境变量(参考上文)
export TRADE_AGENT_ROOT_PATH=$(pwd)
export TRADING_AGENT_TUSHARE_TOKEN=<your_token>

# 2. 跑通验证
PYTHONPATH=. python3 -c "
from coreClient.data_provider import get_basic
df = get_basic(exchange='SSE', market='主板', list_status='L')
print(f'✅ get_basic 返回 {len(df)} 行')
"
```

## 当前维护的环境变量清单

| 变量名 | 用途 | 是否必设 | 获取方式 |
|--------|------|---------|---------|
| `TRADE_AGENT_ROOT_PATH` | 项目根路径 | 否(不设 fallback) | 自己设,指向 clone 后的目录 |
| `TRADING_AGENT_TUSHARE_TOKEN` | Tushare Pro API token | **必设**(否则无法拉数据) | https://tushare.pro/user/token |
