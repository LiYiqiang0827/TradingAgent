# 动态条件推演方法

## 1. 静态和动态的分工

- **静态结构阅读**：只回答截至 `as_of` 已经发生了什么，当前趋势、区间、供需、均线、波浪候选和类中枢是什么。
- **动态条件推演**：从静态状态出发，定义未来5/10/20个交易日的互斥路径，计算每条路径触发后各理论如何迁移。
- 动态推演是条件树，不是单一路径预测。每条分支都要有触发条件、观察窗口、目标/阻力、失败条件和可验证标签。

## 2. 先固定关键边界

至少确定四类价格，并为每一项标注日线、周线或月线来源：

1. `U1`：第一向上确认位，例如区间上沿或最近同级别确认高点；
2. `U2`：突破后的下一阻力，例如更高级别摆动高点、密集成交区上沿或缺口边缘；
3. `S1`：第一支撑带，例如突破位、最近回踩低点或关键均线附近；
4. `D1`：结构失效位，通常是同级别确认低点或区间下沿。

每个价格必须说明来源和容差。容差可使用 `max(0.5*ATR14, 1%*close)`，但应在研究版本中固定，不得逐图随意调整。

目标空间先从月线和周线寻找下一层历史压力/支撑，再用日线确定到达路径和短期确认。动态路径突破日线U1后，不能直接假设无限延伸；应依次检查周线U2和月线U3。

## 3. 五条标准路径

路径应按“先触发什么”定义，避免事后重叠归类。默认观察窗口为5/10/20个交易日：

| 路径 | 触发规则 | 结构含义 |
|---|---|---|
| P1 直接上行 | 未先触及S1，收盘有效突破U1 | 强势延续，观察U2和突破保持 |
| P2 回踩后转强 | 先触及S1但未收盘跌破D1，随后收盘突破U1 | 支撑测试成功后再启动 |
| P3 回踩后横盘 | 触及S1且守住D1，窗口结束仍未突破U1 | 供需重新平衡，等待方向选择 |
| P4 直接转弱 | 在有效突破U1前收盘跌破D1 | 原结构失效，寻找下一层支撑 |
| P5 高位或原区间横盘 | 窗口内既未触及S1，也未有效突破U1或跌破D1 | 波动收缩或时间换空间 |

若出现假突破后跌回、跌破后快速收回等路径，可作为P1/P4的结果子标签，不改变第一触发路径。项目可根据实际统计调整定义，但变更必须升级规则版本。

第一触发只是路径链的第一层。每个样本还必须在T+5、T+10、T+20记录终态：

- `above_upper`：收盘仍在向上确认位之上；
- `between_support_and_upper`：突破未保持，但核心支撑尚在；
- `between_invalidation_and_support`：核心支撑失守，结构尚未完全失效；
- `below_invalidation`：原结构失效。

最终验证使用形如 `P1 → above_upper@T5 → between_support_and_upper@T10 → below_invalidation@T20` 的路径链。突破后跌回支撑称为“突破失败”，先大幅延伸再跌回称为“延伸后反转”。

## 4. 概率的来源

概率必须附带 `probability_type`：

- `historical_calibrated`：来自严格时点历史相似样本，并在独立验证集上做过校准；
- `historical_raw`：来自相似样本频率，尚未完成独立校准；
- `judgmental_weight`：模型根据证据给出的情景权重，只表示相对排序。

历史相似样本至少报告：截止日期、样本数N、市场/题材状态过滤、相似特征、距离阈值、路径标签版本、观察窗口和置信区间。小样本使用Dirichlet/Laplace收缩，避免出现虚假的0%或100%。

没有相似样本统计时，可以输出总和为100%的情景权重，但必须：

- 以5个百分点为最小粒度；
- 明确写“未校准情景权重”；
- 不使用诸如63.7%的伪精度；
- 后续仍用Brier分数、log loss和校准曲线评价。

## 5. 均线抵扣价推演

对N日简单移动平均：

`MA_N(t+1) = MA_N(t) + [C(t+1) - C(t-N+1)] / N`

其中 `C(t-N+1)` 是下一日被移出窗口的抵扣价：

- 假设下一日收盘高于抵扣价，MA_N上升；
- 等于抵扣价，MA_N基本走平；
- 低于抵扣价，MA_N下降。

多日推演不能只看一个抵扣价。需要列出MA5/10/20/60/120未来每一天将被移出的历史收盘价，再将每条假设收盘路径追加到序列中重新计算均线。使用：

```bash
.venv/bin/python policyStudy/skills/a-share-kline-structure-analysis/scripts/project_ma_scenarios.py \
  --packet /tmp/000565_20260910.json \
  --scenario '直接上行:8.05,8.18,8.32,8.45,8.60' \
  --scenario '回踩横盘:7.70,7.62,7.75,7.80,7.86' \
  --output /tmp/000565_ma_paths.json
```

输出包括每个T+日、每条均线的抵扣价、新均线值、方向，以及MA5/10、MA5/20、MA10/20、MA20/60、MA60/120的金叉或死叉候选。交叉只在假设路径成立时有效。

## 5.1 图形输出

每个分析至少生成：

1. 日线静态图：真实K线、实际成交量、MA5/10/20/30/60/120/250和日线支撑压力；
2. 日/周/月联合静态图：三个周期分别标出自己的支撑、压力、目标和失效位；
3. 动态路径总览图：从最后一根真实K线向右展示全部情景路径；
4. 每条路径的单独推演图：假设K线、重算后的MA5/10/20/60/120、目标位置和预计T+周期；
5. 真实区和假设区必须使用背景分区、虚线或水印清楚区分。

可运行 `plot/plot_kline_scenarios.py`。输入的分析JSON中，每个价位使用 `timeframes` 标明适用周期，例如 `['weekly', 'monthly']`。

最小分析JSON结构：

```json
{
  "ts_code": "000001.SZ",
  "as_of": "20260924",
  "structure_summary": "月线、周线和日线的综合结论",
  "levels": [
    {"kind": "resistance", "price": 12.5, "label": "周线平台上沿U1", "timeframes": ["daily", "weekly"]},
    {"kind": "support", "price": 11.2, "label": "月周共振支撑S1", "timeframes": ["daily", "weekly", "monthly"]},
    {"kind": "invalidation", "price": 10.6, "label": "结构失效D1", "timeframes": ["daily", "weekly", "monthly"]}
  ],
  "path_boundaries": {"upper": 12.5, "support": 11.2, "invalidation": 10.6, "horizon": 20},
  "scenarios": [
    {
      "id": "P1",
      "name": "直接上行",
      "weight": 25,
      "probability_type": "judgmental_weight",
      "expected_period": "1-5交易日",
      "trigger": "收盘突破12.5",
      "invalidation": "跌回11.2下方",
      "closes": [12.7, 12.9, 13.2, 13.1, 13.5]
    }
  ]
}
```

完整文件必须包含P1至P5且权重总和为100。`closes`是假设收盘序列；绘图器会生成带斜线填充的示意K线并重算均线。示意K线的最高、最低和开盘仅用于表达路径形状，不作为价格预测或回测标签。

若需要对较大样本执行完全一致、可重复的基线分析，可运行 `scripts/generate_default_analysis_spec.py`。它只读取已经截断在 `as_of` 的数据包，固定生成多周期状态、U1/S1/D1、五路径和5个百分点粒度的未校准权重。该输出适合检验技能默认规则，不应冒充逐股深度人工研判或已校准模型概率。

## 6. 五套理论的状态迁移

### 威科夫

- 直接突破U1：SOS候选增强；只有保持在U1上方或回踩缩量守住，才能升级为有效离开/LPS候选。
- 回踩S1守住：测试供给是否收缩；放量下跌或反弹无结果则反证增强。
- 跌破D1：原吸筹/再积累假设失效，转为弱势区间或派发候选。
- 横盘：观察振幅和成交量是否收缩，以及每次测试的结果是否改善。

### 道氏理论

- U1、D1应来自同级别确认高低点。
- 突破U1只改变相应级别趋势；短期突破不能自动推翻长期下降趋势。
- 回踩形成更高低点后再破高，比单次上破具有更强确认意义。

### 均线系统

- 对每条路径精确重算MA，不用语言模型心算。
- 区分“均线因抵扣低价自然上拐”和“价格真正加速”；两者对趋势强度含义不同。
- 金叉/死叉是路径结果，不是路径发生的原因。

### 波浪理论

- 主计数和备选计数各自绑定U1/S1/D1以及浪级失效点。
- 直接上行可能支持推动浪延伸；回踩守住可能支持调整浪完成；跌破关键起点使对应计数失效。
- 目标位只能由明确锚点和固定比例计算，并保留“未到目标即转折”的可能。

### 缠论

- 直接上行：观察是否形成对类中枢的有效离开；返回类中枢则是离开失败。
- 回踩守住：若回抽不进入类中枢，可记为候选三买结构；必须等待完整结构确认。
- 横盘：可能扩展原类中枢或形成更高级别重叠，不提前命名方向。
- 跌破：对应离开方向改变或原向上结构失效。

## 7. 动态输出表

每次推演至少输出：

| 路径 | 概率/权重 | 概率类型 | 触发条件 | 关键过程 | 目标/阻力 | 失效条件 | 五理论迁移摘要 |
|---|---:|---|---|---|---|---|---|

再单列均线抵扣表和“下一交易日需要观察的最小信息集合”：开盘相对U1/S1的位置、首小时成交量、是否回到区间、关键价位收盘确认等。

## 8. 逐根K线更新

动态推演的核心不是在 `as_of` 猜中唯一未来，而是让每条路径具备可观察证据。每增加一根日K，必须更新：

- 第一触发路径的证据权重：股票最初以P1、P2、P3、P4或P5哪种方式展开；
- 当前演化状态：等待触发、支撑测试、突破保持、突破回踩、突破失败预警、延伸后反转预警或结构失效；
- 支持证据、反证和已经失效的假设；
- 下一根K线最少需要观察的价格确认条件。

第一触发路径和当前状态不能混为一谈。例如先走出P1的股票，后面可以进入突破回踩、突破失败甚至结构失效。原始P1仍记录“它如何开始”，当前状态回答“它现在走到哪里”。

可运行：

```bash
.venv/bin/python policyStudy/skills/a-share-kline-structure-analysis/scripts/update_dynamic_paths.py \
  --project-root /Users/nickzhang/TradingAgent \
  --packet /tmp/000001_SZ_20260701.json \
  --analysis /tmp/000001_SZ_20260701_analysis.json \
  --through-date 20260708 \
  --output /tmp/000001_dynamic.json
```

输出中的权重是规则证据权重，不是已经校准的概率。只有使用历史样本学习似然并经过独立时间外校准后，才能改称概率。

## 9. 做多风险状态

路径证据再映射成五类风险状态，避免把“可能上涨”直接当成持有理由：

| 风险状态 | 条件 | 含义 |
|---|---|---|
| `observe_no_position` | 尚未触及关键位 | 等待，不新增做多风险 |
| `observe_upside_unconfirmed` | 已测试S1但未突破U1 | 只保留观察资格，等待P2确认 |
| `upside_confirmed` | P1/P2突破U1且保持 | 上升假设成立，S1成为必须守住的结构位 |
| `reduce_risk` | 突破后跌回U1下方但仍守住S1 | 突破未保持，降低风险并等待重新确认 |
| `exit_risk` | 跌破S1形成失败预警，或跌破D1 | 退出原上升假设，等待新结构 |

风险状态只表达证据与结构约束，不直接给固定仓位百分比。仓位、成交可行性、滑点和涨跌停限制需要在后续交易规则中单独验证。
