# 已运行的评估与后续验收

最新完整GPT逐日回放见第7节。前面的v1是机械基线，两者不能混称为同一模型，也不能把全期回放与原留出期直接比较。

## 1. v1实际做了什么

2026-01-05—08-31共160个交易日；1—4月77日滚动开发，5—6月39日验证，7—8月44日初次锁定测试。最后1/2/3日分别因未来窗口不全不能评分，不借用9月。日线热身从2025-12开始。

特征提取按日，盘中观察固定前一日涨停池，禁止当日最终名单倒灌。1—4月每个预测只使用当时已成熟标签；5月起冻结4月30日模型。训练样本最大日：情绪4月29日、主线4月27日、个股4月28日，其标签最晚都在4月30日成熟。

模型是标准化+固定C=0.3的L2逻辑回归，没有搜索参数。冻结训练量：情绪76日、主题1636行、个股3930行；股票行和主题行不是相互独立交易日。

规则分数、逻辑回归、按当日涨停宽度排序的简单基线同时报告。未把验证/测试标签用于训练；现在结果已经被阅读，后续改规则必须承认7—8月不再是未见样本。

## 2. 真值代理

| 任务 | 冻结标签 | 尚不能证明 |
|---|---|---|
| 次日可做性 | D涨停篮子在T的中位收益减沪深300；>0.5%且收盘跌超3%的比例<30%为hot，<-0.5%或跌超3%比例>=30%为cold，其余neutral | 当日情绪人工判断准确率、可执行交易收益 |
| 主线 | T..T+2三个交易日累计主归因涨停股日数最多者，允许并列；未来新主题也进真值集合 | 事件层面真正主线、最佳可交易收益题材 |
| 龙头代理 | D该题材已涨停候选中，T..T+1复合超额收益最高者；主指标排除单候选 | 全题材启动前龙头、市场公认的号召力 |
| 高度核心 | 同一候选池未来两日最高连续板达到者，另报 | 不能代替后续收益冠军，更不能用两者择优报成绩 |
| 整链 | 主线正确且其候选股也正确；题材错直接错 | 条件准确率不能替代整链 |

缺价格不填0，缺完整未来窗口记未成熟。当天状态和生命周期没有独立人工盲标，因此它们没有已证实的准确率。

## 3. 首次冻结结果

| 指标 | 5—6月验证 | 7—8月测试 |
|---|---|---|
| 次日可做性三分类 | 19/39，48.7% | 22/43，51.2% |
| 未来3日主线top1 | 8/39，20.5% | 6/41，14.6% |
| 候选top3命中 | 26/39，66.7% | 18/41，43.9% |
| 所选题材内个股，>=2候选，不要求题材正确 | 9/37，24.3% | 9/42，21.4% |
| 主线+个股整链 | 2/38，5.3% | 1/41，2.4% |
| 仅按涨停宽度选主线 | 11/39，28.2% | 8/41，19.5% |

v1旧材料中“条件龙头”指所选题材内个股成绩，不要求题材本身选对；真正以题材正确为条件的成绩在第7节另列，不能混用两种分母。

测试情绪balanced accuracy为37.0%，多数类基线也是51.2%；不能把51.2%的总体命中解释为较强情绪能力。测试主线top1 Wilson95%区间6.9%—28.4%，条件龙头11.7%—35.9%。时间相关性使这些简单区间仍可能乐观。

测试盘中主线命中09:45为3/41、10:30为3/41、14:00为2/41；条件龙头分别21/40、25/41、21/41。10:30的61%是看过当日上午价格之后，对从当日开盘起算的两日强者的确认，不是从10:30之后才开始的收益预测，更不是整链61%。

## 4. 从失败中保留的方法约束

这些是实验支持的约束，不能夸大为已证实的赚钱规律：

- 复杂评分没有胜过简单宽度基线。高板、封单与新闻关键词组合不足以选主线；须验证事件归因与催化的独立贡献。
- 单只核心强与主题后续广度不同。盘中小篮子可能因两股涨得多排第一，却不是持续主线；盘中重排必须同时检验集体代表性。
- 条件龙头不能掩盖题材错。验证期条件命中24.3%，整链仅5.3%；两层都要改进。
- 封单大、高度高不是必胜。模型系数也不是因果规律，不用系数正负编事后产业故事。
- 新闻缺失不是负面信息。cls有26天0条，多源也存在覆盖变化；不得以0关键词当作利好消失。
- 宽主题包含不同产业事件，存在“选对行业却选错当期子题材”；需要有版本的主题树、成员重合及原始催化证据。

可复查的验证期例子：

| 决策数据日 | 当时主线预测 | 未来宽度主线代理 | 解释 |
|---|---|---|---|
| 2026-05-06 | 半导体，20只涨停、4板，高潮候选 | 通信 | 当天强不是未来三天强；高潮描述和持续性预测分开 |
| 2026-05-07 | 算力，21只涨停、3板 | 通信 | 个股603045在所选题材内命中，但主线错误，整链应失败 |
| 2026-05-11 | 半导体，分歧转一致候选 | 半导体 | 主线正确，个股002918未命中后续强者688146，不能算龙头正确 |
| 2026-05-13 | 电力，17只涨停、6板 | 半导体 | 高度与宽度可观，仍不能单凭此确立后续主线 |

这些例子是事后误差分析，不作为同一日期的盲评输入。

## 5. 下一版本的可行检验顺序

1. **先校准目标定义**：邀请研究者在只见截止信息的条件下标当日情绪/生命周期；龙头分别标高度、带动性、容量和后续结果，保留分歧与“不确定”。预测主线定义固定3日/5日两个窗口并并列报告，不事后挑好看的窗口。
2. **补输入而非补故事**：版本化题材树与历史成分；全候选日线；多源新闻按首次可见时间去重；竞价和盘中封单需要历史快照。不能用今天接口抓到的当前盘口替代历史盘口。
3. **对照LLM增量**：同一时点数据包，A=宽度基线，B=结构特征，C=B+可核查新闻语义；相同候选池、相同缺失分母。逐日冻结LLM输出和模型版本，盲评之后再打开未来标签。
4. **先做收盘/次日盘前，再做盘中**：盘中09:45、10:30分别考核新增信息是否改善未来剩余区间预测；结果起算点必须晚于决策截面，不把上午已发生的涨幅算作预测收益。
5. **留新盲测**：1—8月现在只能继续开发/错误研究。新版本在此前未使用的后续时段或实时纸面预测中验证，不能重新包装已看过的7—8月。

如不能立刻获得人工真值，继续报告代理标签，并明确“不等于目标正确率”，不要停在无标签却宣称成功。

## 6. 达标合同

独立技能行为验证曾仅给出2026-06-30及此前5日的隔离包，由另一个判断器先冻结答案再打开标签。它给出hot、半导体、603928，top3含机器人；代理真值为hot、机器人、所选半导体内600641。因此情绪命中、top1和个股未命中，仅top3命中。单日不构成准确率估计，也没有用它修改v1模型。第一版行为材料还带有全期数据覆盖的元信息，所以不视为严格独立预测检验。

行为验证发现字段派生含义和盲评参考路由不清楚。已补特征字典，新增`--blind`只导出截至当时事实及无答案参考，移除模型/规则答案和全期覆盖摘要，并保留前五日逐股证据。未借此单日结果宣称语义方法有效。

报告每类混淆矩阵、macro/balanced accuracy、top1/top3、主线缺席率、条件和整链、样本数、拒判及覆盖率；按月份、行情状态、生命周期、10%/20%和新闻覆盖拆分。大类命中不能掩盖neutral等少数状态几乎全错。

95%与100%只是用户验收目标。本轮未达标；不能改为只挑几天、只看单候选、top3当top1或剔除失败来完成验收。即使41个样本全对，Wilson95%下界也只有约91.4%；样本100%不能证明未来100%。

v1的防未来信息测试包括：修改未来日线不改变过去特征、修改未来分钟不改变当前截面、未来赢家不加入固定池、缺失/陈旧成员导致拒判、未成熟标签不得进入拟合、严格离线不联网。它们证明这些代码边界，不证明数据源当时版本，也不证明策略盈利。

## 7. v2实际GPT逐日回放：完整160日

三个不继承研究对话的判断器，只通过逐日门控获取截至当时的结构、候选及新闻，提交后才开放下一日。160份判断全部冻结、审计通过后，评分器才读取原v1标签。本轮没有用规则程序代替GPT判断，没有按成绩重填答案。1—8月已用于方法开发，仍属于时点受限的历史回放，不是未见样本验证；共享文件系统的逻辑门控也不是操作系统隔离。

末1/2/3日分别缺少下一日/两日/三日观察，不借9月。5日所选题材价格标签缺失，仍保留在严格分母；其中3日题材已选对，所以条件选股和整链各有3日未知。原池高度标签有34日并列（全两日成熟样本），不能用更宽松的高度成绩替换最强股主指标。主线与个股均无拒判，单候选题材无样本。

同一157日的宽度基线为38/157，24.2%，GPT只多4日。同一GPT所选题材池里，最高板29/158，18.4%；最早首封35/158，22.2%；成交额最大6/158，3.8%。GPT选股未超过最早首封基线。情绪balanced accuracy为40.1%，总体38.4%低于事后多数类参照54.7%。这些结果不支持已经达到目标，也没有通过新闻有无的配对消融来证实新闻语义的独立贡献。

21/157日未来主线完全不在当日涨停题材池。当前候选限制下，主线top1理论上限136/157=86.6%，无法达到95%；后续必须扩展到当时已经可知的题材候选，不能用未来名单回填。19日出现“题材选错但所选题材内个股选对”，28日“题材选对但个股错”，72日连前三也未覆盖未来主线，分别暴露选题、选股和候选覆盖问题。

流程审计限制也计入本轮成绩：A组5日存在部分全文查询与提交同批执行，模型冻结前未看到这些新增原文；B组前26日因上下文压缩无法复核是否同批。均未剔除或重做。接口返回765条次全文不等于逐条完成判读。新闻和KPL没有历史首发版本存档，仍是依据来源时间重建可用性。20项合成门控/评分测试通过；未来数据修改不影响首日包、160日时点检查与全量冻结审计通过，不能据此宣称数据源本身完全无误。
