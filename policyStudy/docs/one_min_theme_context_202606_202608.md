# 1 分钟涨停路径加入题材信息：2026 年 6—8 月

这轮先在全部实际触板股上检验“题材强”和“同题材同步”，随后按用户要求收紧到[题材龙头二进三](one_min_two_to_three_theme_leaders_202606_202608.md)。**宽口径里 8 月的正收益没有跨月份稳定性，不能独立推出打板规则。**

![宽口径题材条件图](../../outputs/one_min_limit_up_pilot/theme_context_202606_202608/theme_conditioned_returns.jpg)

从[分钟基线试验](one_min_limit_up_pilot_202606_202608.md)的 7,207 个合格触板股票日出发，以 KPL 主归因涨停股和题材知识库为准，排除 ST、次新、北交所及异常分钟数据。D0 盘中只能使用此前 20 个交易日已知的主题材成员；“强题材”取 D-1 收盘至少 3 只涨停、热度不低于 50 的前三题材。盘中“同题材同步”取龙头首次触板分钟及过去 30 分钟内另有至少 2 只既有主题材成员首触涨停。D0 最终 KPL 归因和 D0 最终热度**没有用于 D0 入场信号**。

D0 首触后的下一分钟若低于涨停价且有成交，按该分钟开盘买入、D1 09:32 卖出的代理收益：6—7 月全样本 1,340 笔净均值 -1.03%，8 月 480 笔 -0.74%；“D-1 强题材 + 同题材同步”分别仅 151 笔 -1.31%、44 笔 -1.31%。题材条件在这个较可成交的路径上**没有改善均值**。

另一种问题是 D0 已经封板，D1 09:45 再判断同题材成员是否同步走强，于 09:46 以低于涨停价的下一分钟开盘买入、D2 09:32 卖出。此时可以使用 D0 收盘后的主题材和热度，但历史 KPL 缺首发时间戳，尚不能证实每一天的 D0 标签在 D1 09:45 前已发布。D1 同步定义为 D0 同一主题材至少 3 只已封板且数据覆盖至少 80%，至 D1 09:45 至少另有 2 只、且过半同伴同时高于 D0 收盘和各自 09:31 开盘至少 0.5%。

| D1 09:46 入场，D2 09:32 计划卖出 | 6—7 月可退出笔数 / 净均值 / 正收益 | 8 月可退出笔数 / 净均值 / 正收益 |
|---|---:|---:|
| 全部 D0 封板 | 3,180 / -1.10% / 35.4% | 1,325 / -0.40% / 41.8% |
| D0 强题材 | 1,275 / -1.02% / 37.2% | 473 / -0.15% / 44.2% |
| D1 同题材同步 | 692 / -2.09% / 28.0% | 250 / +0.69% / 53.6% |
| D0 强题材且 D1 同步 | 401 / -2.39% / 26.4% | 160 / +1.30% / 58.1% |

8 月最后一组的 160 笔分布在 12 个 D0 交易日，其中 8 月 4—6 日共 108 笔；去掉这三天后，余下 52 笔净均值 -1.92%。仅“通信”题材就有 51 笔、净均值 +4.26%；剔除它后余下 109 笔约 -0.09%。因此“8 月 +1.30%”更多是集中行情的描述，不是可迁移的题材过滤效果。按交易日整块重抽样，8 月“强题材且同步”相对其他有 D0 主归因的封板股均值差 +1.92 个百分点，95% 区间 [-0.83，+3.74]，跨零；6—7 月差 -1.47，区间 [-2.58，-0.43]。

费用固定为买卖各 0.10% 滑点、各 0.03% 佣金及卖出 0.05% 印花税。若计划卖出分钟跌停或零成交，该笔不假定退出；收益表只含按计划有价可卖的股票，因此仍可能偏乐观。6—7 月的分钟来源主要是 `tdx_with_csv_fallback`，8 月是 TDX，行情与数据源的变化相混。涨停价排队成交不能由 1 分钟 K 线还原。对强题材、同步、龙头、板位的后续组合筛选，应以[二进三窄口径报告](one_min_two_to_three_theme_leaders_202606_202608.md)和以后冻结规则的新数据为准。
