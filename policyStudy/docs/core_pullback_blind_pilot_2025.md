# 核心股回调：12例匿名结构盲读与事实核对

2026-09-29。此轮先检查大模型能否可靠地阅读当时已知的价格结构。MiniMax-M3 的12份回答中，按预先冻结的 v1 校验得到6份有效、6份无效；有效输出又有2份重复 JSON 键。**这套直接把K线数组交给模型的方案，目前不能承担选股或交易判断。** 格式有效也不等于事实正确，更不等于盈利。

## 样本和信息边界

基础池来自[2025年回调结构研究](core_pullback_structure_2025.md)之前的完整160个信号、145只股票。它本身限定为当时的题材机械核心及既定15分钟信号，不代表全部首板、二板或所有二次启动机会。

先按信号时间、代码、锚点时间排序，用固定种子 `2026092901` 打乱，每只股票最多一例，取12例。没有按未来涨幅、是否可成交、后续数据完整性或原A/B/C结构筛选结果选择样本，也没有用失败样本补抽。2025年是开发期，这12例不作为独立留出期。

每个包只有：

- 60根已完成日K，截止D-1；D-5至D0决策时刻已结束的15分钟K，每例87至92根。
- 截至当时的锚点高度、核心排名，以及D-1题材热度、宽度、排名。缺失字段保留null。
- 匿名编号、相对交易日和盘中时钟；没有真实代码、名称、题材名称、绝对日期或未来收益。
- 以锚点收盘100归一的OHLC；日线“手”换成“股”，再与分钟量共同除以此前20日完整日成交量中位数。过去5天的两种量源核对全部一致，最大相对误差0.000007。

复权使用截止时点的有效因子；因子历史发布时间没有归档，仍存在“生效日开盘时已知”的假设。数据库接口按日期读取后立即裁掉未结束K，再计算输入；这实现了传给模型的前缀隔离，**没有实现数据库物理查询层的时间戳隔离**。删除或污染未来分钟、日线、复权因子的合成测试确认包字节不变。

## 模型调用与封存

本地Hermes配置白名单给出的实际服务是 `minimax-cn / MiniMax-M3`。本轮直接调用其HTTP接口；没有启动Hermes Agent、工具、知识库、项目文件访问、记忆或历史会话。每例只有一条用户消息，独立串行运行，未请求正在处理新闻的Qwen。

正式批次在06:03:26至06:06:08（Asia/Shanghai）运行，墙钟约162秒。12例共18次调用：6例首次通过，另外6例各按协议补试一次且仍无效。18次响应均正常结束，没有传输失败或输出长度截断。模型报告输入124,195 tokens、输出21,089 tokens，另报告缓存读取3,532 tokens；这些是服务端用量字段，不是Codex用量统计。

`RUN_PROTOCOL.json`冻结模型、提示词、程序、传输代码和输入哈希；每次请求、服务器响应、提取文本、解析结果、错误和用量均另存。全部12例终态写入`FROZEN_OUTPUTS.json`后，才允许打开私有映射和收益。评分器还验证完整12个编号、成功请求/响应/解析链，并以固定种子重新计算身份映射，防止将模型判断事后换到另一只股票。

已有v1封存有两个限制：无效尝试的全部原始文件哈希未逐一绑定到最终seal；默认JSON解析没有拒绝重复键。本轮如实保留，不通过重写历史清单假装原先已具备这些保护。

## 先盲审事实，再揭盲结果

固定主分母为12例×6个检查项=72项。审阅者只看原匿名包、原回答和预先写好的准则；没有访问私有映射、收益、未来行情或后来创建的程序派生事实。审阅逐项保留原句、引用ID、实际K线字段和理由。审计不是客观结构标签的替代品，以下是材料支持性分类。

| 分类 | 项数 |
|---|---:|
| 无效缺输出 | 36 |

有效回答共引用241次检查项证据ID，ID都存在，但没有防住字段读错、大小关系写反和时间窗口混淆。11项错误也有程度差别，例如将最新K的90.40误当截至此刻全局最高90.48，和把高开读成低开，不宜压成一个未经定义的“交易准确率”。14项证据不足中，也有数字正确但所引比较端点或窗口不完整的情况。unknown和合理解释不计作预测成功。

## 可复核的阅读错误与程序事实层

S07写“09:45低点81.85低于前日低点81.18”，比较方向错误。真实关系是81.85高于81.18；之后同日又出现79.85，确实低于前日低点。这说明**需要同时保存哪个时刻、哪一根K、哪种低点**，不能把最后的偏空解释用于掩盖前面引用的错误。

S04将13:15一根15分钟的量与前日全天的量直接比较，无法据此断定反弹无量。等时段计算显示：该根K是此前5天同一时刻量中位数的14.37倍，而截至13:15的同钟累计量只有历史中位数的0.86倍。单根放量和累计量偏弱可以同时成立；这些事实本身都不证明“主力吸筹”或未来上涨。

![匿名输入的低点与同钟量复核](../../outputs/core_pullback_blind_2025/fact_check_examples.jpg)

新增 `derive_core_blind_facts.py` 从原匿名包生成程序事实：前日/当日不同低点的明确比较、收盘相对此前4/8/16根已观察K高点的位置、同钟单根与累计量比较，以及锚点与D-1题材身份是否同一日期。全部保留来源ID、输入哈希、计算定义和缺失信息；不产生买卖标签，不把单根突破等价为持续突破。

这些派生文件放在独立`derived_facts_v1/`，明确创建于原模型回答之后。**没有修改原12个输入或重跑模型，也不是本轮模型曾收到的证据。** 它们是下一版阅读方案的准备工作。

派生模块独立审阅还修复了首根09:45缺失被后续K替代、缺值被标为known等边界；观察到的K线窗口会标明计划时段缺口，单日缺失时钟不会被补成零量。重新生成派生文件后核验110个v1冻结文件哈希未变。

## 当前边界与下一步

本轮没有产生可交易的新规则，也没有新增仓位结论。模型“待观察”并未定义可执行的等待时长、再确认条件及重入时点；不能拿这些文字去偷偷移动既定入场点。后续收益分组只研究原模型分类与原基线结果的关联，不是模拟模型实时交易，尚未计入模型响应延迟。

下一版先解决事实可靠性：程序计算数字与同钟比较，模型负责解释冲突、指出缺失和提出可观察条件；输出严格拒绝重复键，数值陈述应可回指计算证据。在本轮12例上调试只算开发，不能改称新留出验证。只有阅读质量过关，再冻结新规则，在未参与调整的日期上验证完整候选分母、T+1、延迟、不可买卖和损失尾部。现阶段不能声称找到了稳定盈利或可把10万元复利做到20万元的体系。

后续已完成[程序事实与模型解释开发复测](core_pullback_blind_facts_v2_2025.md)：同12例命名OHLC和事实表的方案仅3份输出有效，交付可靠性未改善。新版产物、提示词与审计单独封存；本文原v1输入、输出和结果均保持原样。
