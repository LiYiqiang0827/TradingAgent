## 3. 计划没有提到、需要补上的五件事

1. **token预算校准**（同Q22）。原360k的预算没有区分缓存输入，S0很可能一开始就触发150%保险丝。先实测再定。
2. **样本量。** S2报告逐年漏斗。S6用挖掘期的成交率估算主考卷的独立单位数，低于70时在必停点提示。
3. **信号用的日线来源。** 一律由15分钟CSV合成；日线库只用于S0对账以及流通市值、限价等字段。
4. **案例对齐图提前，并有“说不对”的流程。** 按设计第7节的确认记录格式和重跑范围执行。
5. **候选交易表。** 15个特征在S1–S2就算好（S2的单因素分组要用），S6导出，附手算核对20笔。
