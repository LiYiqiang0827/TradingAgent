## 3. 自主决定的五条底线

1. **不碰考卷。** 2023–2024年只做数据质量统计，不做任何事件、信号、收益计算。
2. **不改核心规则。** 【李】标注的规则、数据划分、标签定义、验收标准，都不改。
3. **修数据只看证据。** 依据只能是数据本身、交易所规则或独立数据源，绝不能看策略收益来决定怎么修。同一种修法适用于所有年份。
4. **不为过关而放宽。** 0.5%和1%作为质量指标照常报告。超过时先修；修不好的股票日标为“质量存疑”，**保留数据、照常计算**，最终报告另给一份“剔除质量存疑交易”的对照结果。
5. **每个自主决定都记进“决定日志”**，一行一条：问题、证据、做法、影响了多少股票日或交易。里程碑报告附摘要。
