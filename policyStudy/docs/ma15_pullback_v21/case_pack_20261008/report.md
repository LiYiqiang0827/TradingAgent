## 本次口径差异与质量结论

1. **额外09:30整条退出研究视图。** OHLC、量、额都未补入正常bar；原始文件和每个股票日的正常16根保留。2240个股票日的35840根正常bar与原始CSV逐字段一致，未因额外行删除首根或整日。
2. **日线和开盘成交使用同一新口径。** 日线O取正常首bar O，H/L取保留bar极值，C取末bar收盘，量额只聚合保留bar；开盘步骤只读取正常bar O。开盘时刻和bar结束标签分别记录，后续H/L/C/量额不能反向决定该开盘步骤。独立参考日线只作质量比较，不覆盖新口径。
3. **用途不同，阻塞范围不同。** 本包允许已核实的正常价格、因果均线和无买入原因用于案例解释。量额残差仍保留；本种子不消费成交额，但涉及异常依赖日的量比判定仍是条件性结果，不登记量比已通过。真实成交、收益、年度质量和正式阶段不因此放行。
4. **按股票日重新建立并集，没有从旧10.48%直接扣数。** 本地七股320交易日（含2025预热）共2240个股票日，新疑点并集624日，即27.857%；其中额残差526日、量残差141日、重合43日。该局部比例不是新年度比例，年度新值留空。未解释残差即使很小也保留：量绝对残差最大107股，额最大811.2元；既定容差未放宽。
5. **其他异常与增量保留。** 原E2的31条原因记录、18个新增疑点键完整继承；“32”是旧抽样数，不是增量原因行数。旧年度99,485/949,391只作历史证据。原STOP文件哈希未变；原始文件只读凭据检查大小及修改时间，未声称完成全源哈希审计。

正常H/L与全时段参考的差异能够由正常行加已排除行作算术覆盖说明；这仅解释覆盖范围，不认定供应商语义，不把排除行极值归入某根正常K线。O与参考开盘不完全一致是已明确采用的代理口径，精确不等的1634日不等同于价格质量门槛超限日数。
