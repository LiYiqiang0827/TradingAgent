# 2—4板突破后回踩上行MA20的第二波：2026年6—8月试验

本试验只回答：用户提出的日线结构是否能在当时识别、事后是否常见第二波、以及两种最直接的买入时点是否有可执行收益。个股试验完成后，又对同一批26段补做了[题材宽度与首轮成员复活审计](ma20_second_wave_theme_audit_202606_202608.md)。题材指标尚未进入买卖规则，也没有15分钟确认或独立留出期，不能当作稳定盈利策略。

## 冻结的结构与时间顺序

数据来自本地开盘啦涨停榜、Tushare日线和涨跌停价，均通过 `coreClient.data_provider` 读取。候选是2026-06-01至2026-08-31首次出现“2连板”的股票；检查其后的连续板，只保留最终停在2—4板的段落。**最终板高必须等首个非续板交易日出现后才用于筛选**。排除ST、退市、北交所、ST与次新题材。用2026-03-01起的前史计算均线；交易和10日标签可观察至2026-09-28。

下列门槛在统计结果前固定；使用前复权价计算形态，使用原始成交量比较放量，原始开盘价与原始涨跌停价检查可成交性：

1. 平台突破代理：首板前20个交易日的最高价/最低价不超过1.35，末板收盘价超过该段最高价3%。这个35%区间是刻意宽松的程序筛选，不能替代对箱体边缘和换手平台的人工形态判断。
2. 长期上行：**首板前一交易日**的MA20或MA30至少已经连续10个交易日严格上升，避免把首板自身的上涨算进事前均线趋势。
3. 回踩：末板后第2—15个交易日内，首个符合条件的回踩日最低价不高于MA20的102%，收盘不低于MA20的98%；回踩前若收盘低于MA20的97%，该次段落提前失效。同一连板段只评价首次回踩，不在后续反复挑选较好的触点。
4. 基本多头：从首板至回踩日，至少70%的交易日满足MA10≥MA20≥MA30；至少75%的相邻日满足MA20或MA30继续上行，且回踩日MA20>MA30。允许短线MA5回落。
5. 活跃成交：首板至回踩日的**日均原始成交量**至少是首板前20日均量的1.5倍，同时记录单独的回调段量比，避免只看涨停当日的放量。

一旦第5步成立，回踩当日收盘即可识别候选。两种执行方案分别测试：

- **回踩后买**：回踩收盘后，下一交易日开盘买入。
- **再次转强后买**：回踩当日及随后8个交易日内，收盘较前一日涨至少5%、超过前三日最高收盘且在MA5上方；只使用该日收盘后已知的信息，下一交易日开盘买入。若转强发生于9月，则不计入6—8月的确认买入样本。

两者都在收盘低于当日MA20的99%时发出退出决定；买入后的前三日，最高收盘仍未达到买价的103%也退出。为让盈利单有确定卖点，最高收盘曾达到买价的108%后回落5%退出；最长第15个持有交易日退出。所有决定在**下一交易日开盘**尝试成交，买入当日不能卖（参见[上交所对现货股票T+1的说明](https://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20150912_3988692.shtml)）。开盘封涨停的买单剔除；跌停锁住的卖单延后到下一个可卖开盘。计入往返合计0.4%的费用和滑点假设。开盘成交是日线代理，仍不能模拟竞价排队和真实冲击成本。

“10日内最高收盘比回踩日高10%”与“10日内再次涨停”是**事后标签**，绝不参与候选或买入决策。

## 稳健性与目前认识

只改变一个阈值时，均线连续上行门槛从10日改为5日，回踩交易从26增至40，平均+1.64%、中位-0.84%、最差-11.08%；改为15日仅16笔，平均+0.83%、中位-2.41%。放量门槛从1.5倍改为1.2倍有27笔，平均+0.38%、中位-2.30%；改为2倍有23笔，平均+1.25%、中位-0.72%。这些**不是**调参后的策略版本：均值依赖少数大赢家，中位数和尾部仍弱。大涨确认买法在这些敏感性运行中的平均收益也均未转正。

因此，这个形态适合作为少量候选的**观察池生成器**：结构出现后，的确经常能看到第二次10%上冲；但日线MA20回踩后立刻买容易被短期跌破洗出，等收盘涨5%再买又可能过晚。补做的题材审计显示，当日题材宽度与首轮成员同步回板都不能单独判定该股会有第二波；应固定这批候选，再检验更精细的题材分支归因和15分钟低点抬高、量价确认是否能够提前区分两类走势。不能用后来的新闻归因或赢家名单反推条件。再用独立月份检验实际分钟级成交、组合资金占用与损失尾部。
