# 每日复盘思路与写作契约

## 1. 主轴

每日复盘的稳定主轴是：

> 高标梯队 -> 板块涨停宽度与晋级 -> 中位股反馈 -> 资金迁移 -> 次日验证 -> 是否交易

报告不是行情罗列。每一个数字都应回答“今天的短线结构发生了什么变化”。

## 2. 推荐章节顺序

### 2.1 一句话定性

开头先写当天最重要的结论和矛盾，例如“指数修复但短线情绪未同步”“涨停宽度增加但封板质量下降”。不要用数据来源和方法论开场。

### 2.2 指数、流动性与市场宽度

只保留理解当天结构所需的指数涨跌、成交额变化、上涨/下跌家数、涨跌停和封板率。详细数据口径放在短附注。

### 2.3 高标路线

- 最高板、4板及以上、3板、2板；
- 昨日高标今日晋级、断板、反包；
- 断板后是否出现批量亏钱效应；
- 中位股是集体掉队还是仍有承接；
- 一字高度是否真正可交易。

N天M板另表展示，不进入连续梯队。

### 2.4 题材结构

每个主要题材按同一逻辑写：

1. 涨停宽度、触板未封、梯队和成交活跃度；
2. 最早启动和核心股票；
3. 为什么今天被交易；
4. 与昨日和过去主线的关系；
5. 定性；
6. 下一交易日最有信息量的验证点。

题材分为：已确认主线、主线候选、轮动支线、刚启动待验证、一日游或明显退潮。

### 2.5 资金迁移

按时间顺序描述旧方向退出、新方向承接和日内二次加强。避免“某板块净流入X亿元，所以资金流入”的机械结论。

结尾用一句箭头路线压缩全天：

```text
旧主线分歧 -> 早盘新方向承接 -> 容量分支保留 -> 午后二次加强 -> 低位轮动
```

### 2.6 过去三周主线追踪

记录过去15个交易日主要方向的活跃天数、峰值宽度、最高板、当日表现和当前状态。宽泛属性标签不自动算作主线。

### 2.7 首板后首次回调再启

候选模式必须区分：

- 紧平台：首板后横盘1至2日，价格靠近首板收盘，量能收敛；
- 浅回调：缩量回踩但主要结构保持；
- 深回撤修复：曾大阴线、跌停或破坏短期结构，后续重新修复；
- 已完成再启：当天已经重新封板，只能评价延续；
- 连续涨停：属于接力池，不属于首次回调。

缩量阴跌本身不是买点；盘后看到涨停也不能倒推盘前必然可选。

### 2.8 明日验证与行动

不用 `If-Then` 模板。用自然语言写3至5项最重要的验证：谁代表高度，谁代表容量，首板群能否产生2板，炸板股是否继续负反馈。

最终明确：竞价可参与、盘中确认、仅观察或不交易。没有合格候选时允许空仓。

## 3. 事实、推断和行动分层

| 层级 | 示例 | 来源 |
|---|---|---|
| 事实 | 102只收盘涨停、医药21只主标签涨停 | 数据包 |
| 推断 | 存量资金从科技高弹性转向低位政策线 | GPT综合判断 |
| 行动 | 次日默认空仓，等待分歧承接 | 风险与可交易性判断 |

不得把推断写成接口直接返回的事实，也不得用行动结论反向修改事实。

## 4. 网络搜索范围

允许搜索：政策、公司公告、澄清公告、产业事件、最终候选的业务与股东背景。

禁止重复搜索：数据包已经提供的指数、成交额、涨停数量、梯队、晋级率、个股当日价格与成交额。

## 5. 文风

- 先结论、后证据；
- 重点是“为什么重要”，不是把所有字段念一遍；
- 对缺失数据直接写缺失；
- 数据修正集中放在简短口径说明；
- 不强行制造主线，不强行推荐股票；
- 结论可以是“今天没有值得交易的机会”。

## 6. 周复盘扩展

周复盘只能聚合一周内已经通过验收的日包，不重新用周末最新标签改写历史事实。按周一至周五整理每日最高板、2板以上梯队、题材峰值宽度、晋级和负反馈，还原旧方向退潮与新方向承接，并复盘首次回调模式的成功、失败和未触发样本。当前仓库尚未提供自动周聚合脚本。
